# 风险评估诊断（rd-risk-diagnosis）

> 属「R&D Expenses」技能族。**通用 SOP**——总则、六步工作流、交付要求、交付前自检——见 [`../../SKILL.md`](../../SKILL.md)。本文件只写**本任务的特有环节**。
> 知识底座：[`../../policy/`](../../policy/README.md)、[`../../cases/`](../../cases/README.md)。

## 边界

- 本技能管**主动**的风险体检与诊断（事前 / 事中）。
- **被动**的稽查 / 核查应对 → [`../rd-audit-response/SKILL.md`](../rd-audit-response/SKILL.md)。
- 整改若落到制度层面 → [`../rd-internal-control/SKILL.md`](../rd-internal-control/SKILL.md)。

## 典型问法

- 我们研发费用归集有没有风险？
- 帮我做一次研发费用自查 / 体检。
- 研发费用加计扣除的稽查重点有哪些？
- 研发人员占比、工时分配有没有问题？
- 我们申报的研发费和账面能对上吗？

## 需收集信息清单

| 类别 | 需收集 |
|:---|:---|
| 申报与归集数据 | 研发费用归集与申报金额 |
| 证据链 | 辅助账、备查资料、人员 / 工时 / 领料 / 产出记录 |
| 勾稽数据 | 申报研发费、期间费用、专项审计报告、纳税申报表 |
| 线索 | 是否已有风险线索、被查迹象、异常指标 |
| 目标 | 全面体检 / 专项体检 |

## 专属 SOP（在通用六步之上）

1. **对照稽查手法清单逐项自查**：虚列 / 虚增研发费用、虚构研发项目、人员不实、活动不属研发、跨期加计、逻辑矛盾、产出处理不当、领料混同、股份支付、委外不合规等。
2. **数据勾稽核对**：申报研发费 vs 期间费用 vs 辅助账 vs 专项审计报告 vs 纳税申报表，逐项比对是否自洽。
3. **风险点分级排序**：按发生概率与后果分高 / 中 / 低。
4. **出具整改建议**：每项标注依据强度（明文条款 / 类比案例 / 库内无据）。

## 交付物

- 风险体检报告（风险点 + 依据 + 分级）
- 整改建议清单
