# 实操工具：研发费用分配表模板集

涵盖研发费用分摊所需的核心工具表。

## 一、模板组成

| 编号 | 模板名称 | 适用场景 |
|------|---------|---------|
| AL-07 | 工资分配表 | 研发人员工资按项目分摊 |
| AL-08 | 材料分配表 | 研发材料领用按项目归集 |
| AL-09 | 折旧分配表 | 设备折旧按工时分摊 |
| AL-10 | 仪器设备分配表 | 研发仪器设备使用分配 |
| AL-11 | 设备使用工时统计表 | 设备总工时与研发工时统计 |

## 二、AL-07 工资分配表

### 2.1 列结构

| 列 | 内容 | 说明 |
|----|------|------|
| 序号 | 行号 | 1, 2, 3... |
| 姓名 | 研发人员姓名 | |
| 部门 | 所属部门 | 研发部/技术部/其他 |
| 岗位 | 技术岗位 | 工程师/技术员/实验员等 |
| 工资总额 | 当月应付工资 | 包含基本工资、绩效、津贴 |
| 社保单位部分 | 单位承担社保 | |
| 公积金单位部分 | 单位承担公积金 | |
| 薪酬合计 | 工资+社保+公积金 | 分配基数 |
| 工时合计 | 当月总工时 | 考勤记录 |
| 项目1工时 | 项目1投入工时 | 对应项目编号 |
| 项目1分配金额 | 按工时比例分配 | 薪酬合计 × (项目1工时/工时合计) |
| 项目2工时 | 项目2投入工时 | |
| 项目2分配金额 | 按工时比例分配 | |
| ... | ... | 按实际项目数扩展 |
| 备注 | 专职/兼职等 | |

### 2.2 稽查风险警示

- 全员100%工时都做研发，显然不合理
- 管理人员工资计入研发费用，口径错误
- 工资分配表与考勤记录不一致，稽查重点

## 三、AL-08 材料分配表

### 3.1 列结构

| 列 | 内容 | 说明 |
|----|------|------|
| 领用日期 | 材料领用日期 | |
| 材料名称/规格 | 材料明细 | |

| 领用用途 | 具体研发环节 | 打样/测试/实验等 |
| 领用人 | 签字确认 | |
| 备注 | 是否可加计扣除 | |

### 3.2 稽查风险警示

- 研发领料与生产领料无区分标识
- 材料领用数量与研发活动产出不匹配
- 研发废料销售未冲减研发费用
- 大规模通用材料领用无详细用途说明

### 6.2 稽查风险警示

- 工时记录为固定比例（如每月都是30%），被质疑真实性
- 研发工时与生产工时无区分，无法验证

## 七、使用说明

1. 分配表是辅助账的基础支撑，**没有分配表就没有分摊依据**
2. 工资分配表按月编制，材料分配表按领用批次编制，折旧分配表按设备编制
3. 所有分配表需保留原始数据（考勤、领料单、工时记录）以备稽查
4. 用 `{{企业名称}}`、`{{年度}}`、`{{月度}}` 等占位符填充
