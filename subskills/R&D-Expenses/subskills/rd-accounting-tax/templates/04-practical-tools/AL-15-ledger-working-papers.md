# 实操工具：研发台账底稿与凭证序时簿模板

用于辅助账数据与财务系统的对接验证。

## 一、模板组成

| 编号 | 模板名称 | 适用场景 |
|------|---------|---------|
| AL-15 | 研发台账底稿 | 辅助账编制的工作底稿 |
| AL-16 | 凭证序时簿 | 费用凭证与研发项目的对照 |
| AL-17 | 外部费用导入模板 | 外部研发费用/其他费用导入 |

## 二、AL-15 研发台账底稿

### 2.1 用途

台账底稿是编制辅助账前的工作底稿，用于汇总各来源数据并验证一致性。

### 2.2 列结构

| 列 | 内容 | 说明 |
|----|------|------|
| 项目编号 | 研发项目编号 | |
| 项目名称 | 研发项目名称 | |
| 费用类别 | 人员/材料/折旧/其他 | |
| 费用明细 | 具体费用描述 | |
| 总账科目 | 财务系统科目 | 如：研发支出-费用化支出 |
| 借方金额 | 借方发生额 | |
| 贷方金额 | 贷方发生额 | |
| 发生日期 | 凭证日期 | |
| 凭证号 | 会计凭证号 | 与财务系统对应 |
| 是否可加计扣除 | 是/否 | |
| 不可扣除原因 | 说明 | 若为否则填写原因 |
| 数据来源 | 工资表/领料单/折旧表/发票 | |
| 底稿核对 | 已核对/未核对 | 与原始凭证核对确认 |
| 备注 | 调整说明 | |

### 2.3 使用流程

1. 从财务系统导出研发支出明细账
2. 按项目+费用类别分类填入底稿
3. 逐笔与原始凭证核对（工资表、领料单、折旧表、发票）
4. 标注可加计扣除性
5. 汇总后填入辅助账

## 三、AL-16 凭证序时簿

### 3.1 用途

凭证序时簿按时间顺序记录所有研发费用凭证，建立凭证号与研发项目的关联。

### 3.2 列结构

| 列 | 内容 | 说明 |
|----|------|------|
| 凭证日期 | 记账日期 | |
| 凭证号 | 会计凭证编号 | |
| 摘要 | 凭证摘要 | |
| 总账科目 | 科目名称 | |
| 明细科目 | 明细科目 | |
| 借方金额 | 借方金额 | |
| 贷方金额 | 贷方金额 | |
| 研发项目编号 | 对应研发项目 | |
| 费用类别 | 人员/材料/折旧/其他 | |
| 可加计扣除 | 是/否 | |
| 附件张数 | 原始凭证附件数 | |

### 3.3 稽查应对

- 稽查时通常要求提供"凭证-科目-项目"对照表
- 凭证序时簿可快速定位每笔研发费用的原始凭证
- 建议按月度编制，与财务系统月结同步

## 五、使用说明

1. 台账底稿是辅助账编制的"工作底稿"，建议每月编制一次
2. 凭证序时簿直接与财务系统数据对接，确保数据一致性
3. 外部费用单独管理，注意委托研发80%计入的规则
4. 用 `{{企业名称}}`、`{{年度}}` 等占位符填充
