# 财税处理（rd-accounting-tax）

> 属「R&D Expenses」技能族。**通用 SOP**——总则、六步工作流、交付要求、交付前自检——见 [`../../SKILL.md`](../../SKILL.md)。本文件只写**本任务的特有环节**。
> 知识底座：[`../../policy/`](../../policy/README.md)、[`../../cases/`](../../cases/README.md)。

## 边界

- 本技能管**账怎么做、税怎么处理、辅助账怎么建、四口径怎么协调**。
- **优惠能不能享受** → [`../rd-tax-benefit/SKILL.md`](../rd-tax-benefit/SKILL.md)。
- **IPO 发行口径问题**（研发人员 50% 工时认定、研发投入六类支出、研发费用率与同行对比、问询答复范式）→ 改按 [`../../policy/README.md`](../../policy/README.md) 第二章（四）「IPO 研发投入与监管口径」执行，并参考 `cases/` 41–44、46–51、57–61、63–67、74–87 及两篇专题；本技能沿用其会计处理部分，不重复发行口径的作业流程。
- 本技能是全族最常用的一条线，覆盖多数日常"研发费用怎么入账 / 怎么归集"的问题。

## 典型问法

- 研发费用怎么入账？费用化还是资本化？
- 研发样机 / 样品 / 副产品对外销售，账务怎么处理？
- 研发辅助账怎么设置？有没有官方样式？
- 会计、加计扣除、高企认定、R&D 统计四套口径差在哪？
- 资本化时点怎么确定？研究 / 开发阶段怎么分？

## 专属 SOP（在通用六步之上）

1. **会计定性**：费用化 vs 资本化（研究 / 开发阶段划分、五项资本化条件）；研发产出物**去向判断**（存货 / 固定资产 / 费用化 / 废料）。
2. **账务处理**：按 1704 开发支出、5301 研发支出、6605 研发费用 等科目组织；资本化支出经"研发支出——资本化支出"归集。
3. **辅助账 / 台账编制**：按项目设辅助账（2021 版 / 2015 版样式，企业可自设）；其他相关费用限额；共用资源按工时分摊。
4. **税务处理**：按 40 号公告归集；研发与生产经营**分别核算**，划分不清不得加计；特殊收入与材料费冲减。
5. **四口径差异协调**：会计口径 / 加计扣除口径 / 高企认定口径 / R&D 统计口径逐项比对，出具差异说明（如资本化摊销、股份支付、委外 80%、统计口径与会计口径的差异等）。
