# 稽查审查应对（rd-audit-response）

> 属「R&D Expenses」技能族。**通用 SOP**——总则、六步工作流、交付要求、交付前自检——见 [`../../SKILL.md`](../../SKILL.md)。本文件只写**本任务的特有环节**。
> 知识底座：[`../../policy/`](../../policy/README.md)、[`../../cases/`](../../cases/README.md)。

## 边界

- 本技能管**已被查 / 有异议**的应对与举证（被动）。
- **主动体检** → [`../rd-risk-diagnosis/SKILL.md`](../rd-risk-diagnosis/SKILL.md)。
- 程序性事项、定性口径以官方与主管机关为准；本技能输出为应对方案草稿，不替代专业人士判断。

## 典型问法

- 税务局来查研发费用加计扣除，怎么办？
- 我们的研发项目被质疑不属于研发活动，怎么办？
- 异议鉴定怎么申请？由谁提出？
- 会不会被定性偷税？要补多少、罚多少？
- 高企资格被撤了还能救吗？
- 复议 / 诉讼怎么走？追征期多久？

## 需收集信息清单

| 类别 | 需收集 |
|:---|:---|
| 程序与阶段 | 稽查 / 核查 / 专项审计；所处阶段、是否已出具文书 |
| 涉事范围 | 涉及项目、期间、金额 |
| 已有资料 | 现有举证材料、辅助账、合同登记、凭证 |
| 定性倾向 | 对方是否已定性（偷税 / 编造虚假计税依据）、依据 |
| 程序进展 | 是否进入异议鉴定 / 复议 / 诉讼 |
| 目标 | 期望结果与底线 |

## 专属 SOP（在通用六步之上）

1. **判断程序与性质**：税务稽查 / 高企核查 / 专项审计；是否可能进入**异议鉴定**（对研发项目有异议的，由税务机关转请科技部门鉴定）。
2. **事实梳理与举证**：研发项目资料、辅助账、工时记录、委托研发合同登记、产出物处理凭证。
3. **对照定性依据**：是否属研发活动（119 号）、归集是否准确；定性走向——**偷税**（《税收征收管理法》第 63 条）还是**编造虚假计税依据**（第 64 条），直接决定后果量级。
4. **应对策略**：补正资料 / 陈述申辩 / 申请异议鉴定 / 复议与诉讼；关注**追征期**（符合条件未享受的可追溯 3 年）与滞纳金。
5. **复盘整改**：回连 [`../rd-internal-control/SKILL.md`](../rd-internal-control/SKILL.md) 修补制度，避免复发。

## 交付物

- 应对方案（含程序判断与策略）
- 举证清单
- 后果与风险评估
