# 优惠享受（rd-tax-benefit）

> 属「R&D Expenses」技能族。**通用 SOP**——总则、六步工作流、交付要求、交付前自检——见 [`../../SKILL.md`](../../SKILL.md)。本文件只写**本任务的特有环节**。
> 知识底座：[`../../policy/`](../../policy/README.md)、[`../../cases/`](../../cases/README.md)。

## 边界

- 本技能管**税收优惠能不能享受、享受多少、何时享受、资料怎么留**。
- **认定 / 资格** → [`../rd-proj-application/SKILL.md`](../rd-proj-application/SKILL.md)；**账务与辅助账** → [`../rd-accounting-tax/SKILL.md`](../rd-accounting-tax/SKILL.md)。
- **易混点**：先进制造业**增值税加计抵减**（按进项税额加计抵减增值税）与研发费用**加计扣除**（企业所得税）是两回事，须区分，勿混用。

## 典型问法

- 研发费用能不能加计扣除？比例是多少？
- 我们是高新技术企业，加计扣除和 15% 税率能叠加吗？
- 集成电路 / 工业母机企业是不是 120%？
- 预缴时能享受加计吗，还是等汇算？
- 加计扣除要留哪些备查资料？
- 委托境内 / 境外研发怎么加计？
- 先进制造业增值税加计抵减和研发加计是一回事吗？

## 需收集信息清单

| 类别 | 需收集 |
|:---|:---|
| 优惠种类与年度 | 拟享受的优惠（加计扣除 / 高企税率 / 120% / 委托境外）、所属年度 |
| 企业与征收 | 所属行业、是否负面清单、征收方式（查账 / 核定）、核算是否健全 |
| 清单资格 | 是否集成电路 / 工业母机清单内企业（决定 100% 还是 120%） |
| 研发费用 | 六类费用归集结果、其他相关费用、特殊收入 / 材料费冲减 |
| 委外研发 | 委托 / 合作研发合同及登记、境外委托支付凭证 |
| 享受时点 | 预缴（7 月 / 10 月）还是汇算清缴 |
| 目标 | 测算金额 / 备查清单 / 申报口径 |

## 专属 SOP（在通用六步之上）

1. **判定优惠种类与适用条件**：加计扣除 / 高企税率 / 集成电路与工业母机 120% / 委托境外 / 增值税加计抵减。
2. **确定适用口径与比例**：费用化 100%、资本化按成本 200%；集成电路与工业母机 120%、220%；委托境内按实际发生额 80%，委托境外 80% 且不超过境内符合条件研发费用的三分之二。
3. **确定享受时点与办理方式**：7 月 / 10 月预缴可就当年上半年 / 前三季度享受，以及汇算清缴；遵循"自行判别、申报享受、留存备查"。
4. **填报申报表**：研发费用加计扣除优惠明细表（A107012）等；注意 **2024 年度起**依国家税务总局公告 2025 年第 1 号，取消 A107010、修订 A107012。
5. **列明留存备查资料清单**：计划书与决议、研发人员名单、委托研发合同登记、费用分配说明、辅助账、汇总表等。

## 速算表（研发费用 → 加计 / 节税）

设研发费用（费用化）为 X 万元、企业有足够应纳税所得额：

| 企业类型 | 加计比例 | 加计扣除额 | 适用税率 | 节税额 | 依据 |
|:---|:---|:---|:---|:---|:---|
| 一般企业 | 100% | X | 25% | 0.25X | 2023 年第 7 号 |
| 高新技术企业 | 100% | X | 15% | 0.15X | 2023 年第 7 号 + 高企税率 |
| 集成电路 / 工业母机（清单内） | 120% | 1.2X | 25% | 0.30X | 2023 年第 44 号 |
| 小型微利企业 | 100% | X | 5%（实际税负） | 0.05X | 2023 年第 7 号 + 小微优惠 |
| 负面清单行业 | — | 0 | — | 0 | 119 号 → 四、不适用行业 |

**代入 X = 500 万元**：一般 125 万 · 高新 75 万 · IC/母机 150 万 · 小微 25 万 · 负面清单 0。

> 口径提示：节税额 = 加计扣除额 × 适用税率；企业**无所得（亏损）**时，加计先扩大亏损、经以后年度弥补体现。**资本化**情形按 200%（IC/母机 220%）摊销。数字随政策变化，以官方最新为准。
