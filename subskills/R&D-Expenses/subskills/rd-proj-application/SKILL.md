# 项目申报（rd-proj-application）

> 属「R&D Expenses」技能族。**通用 SOP**——总则（口径一致、实质合规·制度先行等）、六步工作流、交付要求、交付前自检——见 [`../../SKILL.md`](../../SKILL.md)。本文件只写**本任务的特有环节**。
> 知识底座：[`../../policy/`](../../policy/README.md)（法规与指引原文）、[`../../cases/`](../../cases/README.md)（真实案例）。

## 边界

- 本技能管**认定 / 资格 / 项目申报**这件事：条件核对、材料编制、材料整理、材料审核。
- **税收优惠的适用与享受** → [`../rd-tax-benefit/SKILL.md`](../rd-tax-benefit/SKILL.md)；**账务与辅助账** → [`../rd-accounting-tax/SKILL.md`](../rd-accounting-tax/SKILL.md)。
- 划界规则：**"认定 / 资格"归本技能；"认定后带来的优惠怎么享受"归优惠享受技能**（例：高企认定 → 本技能；高企税率优惠 → 优惠享受）。
- 本技能还管**高企认定评分自检**：八条一票否决 + 四项指标 100 分（71 达标）+ 补齐路径——规则见 [`references/hitech-scoring.md`](references/hitech-scoring.md)。

## 专属 SOP（在通用六步之上）

1. **定申报类型与年度口径**：确认属于高企认定 / 科小评价 / 专精特新 / 科技计划项目中的哪一类，并锁定**当年度**的认定办法、工作指引与申报通知（政策具时效性，以官方最新为准）。
2. **条件核对**：逐条对照申报条件（如高企八项条件：年限、知识产权、技术领域、科技人员占比、研发费用占比、高新收入占比等），先判是否够格。
3. **材料编制**：按官方清单组织——研发项目立项 / 结题资料、研发费用辅助账、科技人员名单与工时、知识产权、高新收入说明、专项审计报告。
4. **材料整理**：按目录归档，并**交叉核对数据一致性**（申报表、专项审计报告、辅助账、纳税申报表之间口径与数字必须能相互印证）。
5. **材料审核（门禁）**：先形式审查（齐全、格式、签章），再实质审查（数据能否支撑结论、有无硬伤，如人员占比 / 研发费用占比临界、归集边界不清）；**不通过先补，不带病提交**。
6. **评分自检（可选）**：按 [`references/hitech-scoring.md`](references/hitech-scoring.md) 先判八条一票否决（排在评分前），再按四项指标打分——主观项（技术先进程度、核心支持作用）以**保守—乐观区间**呈现；输出自评得分与按性价比排序的补齐路径。
