# 流程：研发项目管理流程与内控节点

> 用法：按企业实际裁剪阶段，填充责任人/控制点。每节点产出即工作流 B 证据链的来源。

## 研发全生命周期流程（文本图）

```
[立项] → [预算] → [实施] → [资本化判定] → [费用归集核算] → [阶段/结题验收] → [资料归档]
   │         │         │         │              │                  │              │
   ▼         ▼         ▼         ▼              ▼                  ▼              ▼
立项决议   预算批复   工时/领料  资本化审批   辅助账/凭证        验收报告       证据链PDF
```

## 关键控制点说明
- **资本化判定**：必须逐条核对《企业会计准则第6号》6 条件（见 `references/rd-mgmt-methodology.md` 第 4.5 节），留存技术可行性论证与测试报告。
- **费用归集**：每笔费用佐证编号不得为空；无佐证不得计入。
- **归档**：项目结题后资料保管不少于{{年限}}年，证据链可导出 PDF 存档。
