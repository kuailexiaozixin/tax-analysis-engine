# 模板：研发项目立项管理办法

> 用法：工作流 A（治理/内控制度）的专项制度。根据企业实际裁剪后，转为 Word/PDF 交付归档。{{占位符}} 由 Agent 基于企业现状与系统数据填充。
> 与 `01-regulations/internal-control-system.md`（第三章·立项控制）和 `03-forms/forms.md`（表单1·立项书）衔接，构成"立项申请→评审→审批→变更→中止"的完整管理流程。

---

## 第一章 总则

**第一条 目的**
为规范公司研发项目的立项申请、评审、审批、变更与中止管理，确保研发项目立项有据、预算可控、研发活动可追溯，为后续实施管理、费用归集与加计扣除申享受提供合规基础，特制定本制度。

**第二条 适用范围**
适用于公司所有研发项目的立项管理，包括：
1. 自主研发项目；
2. 委托研发项目（委托外部机构研发）；
3. 合作研发项目（与其他单位合作研发）；
4. 集中研发项目（集团集中研发）。

**第三条 归口管理**
研发部负责立项申请的组织与初审；研发管理委员会（或技术委员会）负责立项评审与审批；财务部负责预算审核与费用归集口径确认。

## 第二章 立项申请

**第四条 立项条件**
研发项目立项须满足以下条件之一：
1. 具有明确的创新目标（新技术、新产品、新工艺）；
2. 具有系统性和组织性（有项目计划、资源配置、过程管理）；
3. 具有不确定性（存在技术风险、研发结果不确定）；
4. 市场驱动或客户需求（针对特定技术问题或市场需求的研发活动）。

**第五条 立项申请材料**
申请人填写《研发项目立项书》（见 03-forms/forms.md 表单1），须包含以下内容：
1. 项目名称与编号（格式 `RD{年份}-{序号}`）；
2. 技术目标与创新点（说明研发活动的新颖性与创造性）；
3. 现有技术基础与可行性分析；
4. 研发周期（起止时间）；
5. 预算总额与费用构成（按人员人工/直接投入/折旧摊销/设计费/其他分类）；
6. 项目负责人与参与人员；
7. 研发性质（自主研发/委托研发/合作研发/集中研发）；
8. 预期成果（专利/样机/工艺/技术报告）。

**第六条 研发活动判定自检**
立项时须逐条对照以下不属于研发活动的情形（财税〔2015〕119号第一条第(二)款），确保项目不属于排除范围：
- [ ] 常规升级或直接应用现有技术
- [ ] 对科研成果的直接应用（如直接采用公开的新工艺）
- [ ] 技术支持、技术服务的重复性活动
- [ ] 对现有产品的简单改变或外观变化
- [ ] 市场调查、商业竞争研究
- [ ] 质量控制、测试、检验的常规活动
- [ ] 社会科学、人文科学研究

## 第三章 立项评审

**第七条 技术评审**
研发管理委员会组织技术评审，评审内容包括：
1. 技术目标的创新性与可行性；
2. 研发团队的资质与技术能力；
3. 技术路线的合理性与风险；
4. 预期成果的市场价值或技术贡献。

**第八条 预算评审**
财务部组织预算评审，评审内容包括：
1. 预算编制的合理性与完整性；
2. 费用归集口径的合规性（是否符合加计扣除/高企认定要求）；
3. 与公司年度研发预算的匹配性。

**第九条 评审结论**
评审结论分为三种：
1. 通过：准予立项，进入实施阶段；
2. 有条件通过：须补充材料或修改方案后重新提交；
3. 不通过：项目不符合研发活动条件，退回申请。

## 第四章 立项审批

**第十条 审批权限**
1. 预算总额 ≤ {{阈值，如50万元}}：由研发管理委员会审批；
2. 预算总额 > {{阈值，如50万元}}：须经总经理/董事会审批；
3. 涉及重大技术方向或跨部门协作的：须经总经理审批。

**第十一条 审批流程**
立项申请 → 研发部初审 → 技术评审（研发管理委员会）→ 预算评审（财务部）→ {{审批层级}}审批 → 登记入研发项目台账（项目编号、名称、负责人、预算、归集口径）。

**第十二条 系统录入**
立项审批通过后，须登记至研发项目台账，包含立项决议、预算、技术方案等附件。立项信息作为后续费用归集与证据链的源头。

## 第五章 项目变更管理

**第十三条 变更范围**
以下变更须重新审批：
1. 项目技术目标或技术路线的重大调整；
2. 预算总额变动超过 {{阈值，如20%}}；
3. 项目周期延长超过 {{阈值，如6个月}}；
4. 项目负责人变更。

**第十四条 变更流程**
填写《项目变更申请单》，说明变更原因、变更内容、对预算和周期的影响，经原审批层级审批后生效，同时在研发项目台账中更新。

## 第六章 项目中止与终止

**第十五条 项目中止**
因技术风险、市场变化、资金不足等原因暂时无法继续推进的，经研发管理委员会批准后中止。中止期间停止费用归集。

**第十六条 项目终止**
以下情况须终止项目：
1. 技术可行性论证失败，无法实现预期目标；
2. 市场环境发生重大变化，研发成果失去商业价值；
3. 公司战略调整，项目不再符合发展方向。

**第十七条 终止处理**
项目终止后：
1. 编制《项目终止报告》，说明终止原因、已发生费用、已形成成果；
2. 已发生的研发费用仍可享受加计扣除（失败研发活动可加计扣除，参照财税〔2015〕119号）；
3. 项目档案归档，在研发项目台账中标记状态为"已终止"。

## 第七章 立项档案管理

**第十八条 归档内容**
每个立项项目须建立完整的立项档案，包含：
1. 《研发项目立项书》及附件；
2. 技术评审报告；
3. 预算评审报告；
4. 立项审批文件（含决议文件）；
5. 如有变更/中止/终止，须附变更/中止/终止审批文件。

**第十九条 保管要求**
立项档案按项目归档，保管期限不少于 {{年限，如10年}}。作为加计扣除留存备查资料（税务总局公告2018年第23号第二条）和高企认定申报材料（32号文第十二条）。

## 第八章 监督与责任

**第二十条**
研发部对立项材料的真实性负责，研发管理委员会对技术评审的客观性负责，财务部对预算评审的合规性负责。

**第二十一条**
对将非研发活动包装为研发项目立项套取加计扣除优惠的，按公司责任追究办法处理。情节严重的，参照稽查案例七（性能改善包装为研发项目，锡税稽罚〔2022〕53号）的处罚后果告知相关人员。
