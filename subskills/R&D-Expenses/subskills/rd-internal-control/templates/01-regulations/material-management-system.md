# 模板：研发物料管理制度

> 用法：工作流 A（治理/内控制度）的专项制度。根据企业实际裁剪后，转为 Word/PDF 交付归档。{{占位符}} 由 Agent 基于企业现状与系统数据填充。
> 与 `03-forms/forms.md`（表单4·材料领用单）和 `01-regulations/mold-management-system.md`（模具管理）衔接，共同构成研发直接投入的完整管理闭环。

---

## 第一章 总则

**第一条 目的**
为规范公司研发过程中物料（含原材料、辅料、试制件、样品样机等）的领用、使用、退库、废料处理与费用归集，确保研发物料支出真实准确、研发与生产物料边界清晰、加计扣除与高企认定口径合规，特制定本制度。

**第二条 适用范围**
适用于公司所有研发项目涉及的物料管理，包括：
1. 研发领用原材料（直接消耗的材料、燃料、动力）；
2. 研发试制件/样品样机（含外购样品、自制样品）；
3. 研发过程中形成的下脚料、残次品、中间试制品；
4. 研发活动直接形成产品或作为组成部分形成产品。

**第三条 归口管理**
研发部为物料需求提出与使用管理责任部门；仓库/物控部门负责物料入库、出库与库存管理；财务部负责物料费用归集与核算；质检部负责试制件/样品验收。

## 第二章 物料分类与编码

**第四条 分类**
1. 按用途：研发直接消耗材料 / 研发试制件 / 外购样品样机 / 自制样品 / 研发用低值易耗品；
2. 按来源：自制 / 外购 / 委外加工；
3. 按资产属性：消耗性物料 / 可回收物料（模具、工装） / 样机样品。

**第五条 编码规则**
物料编码沿用公司现有ERP/进销存系统编码规则，在单据中增加"研发项目编号"字段，实现按项目归集。

## 第三章 领料管理

**第六条 领料审批**
研发领料须填写《材料领用单》（见 03-forms/forms.md 表单4），注明：日期、项目编号、材料名称、规格、数量、金额、用途说明、领用人。单次领料金额 ≥ {{阈值，如5000元}} 的，须经研发部门负责人审批。

**第七条 领料边界（关键）**
以下物料不得计入研发费用：
1. 生产车间领用的物料（即使项目名称相似，须以领料单标明的"项目类别"为准）；
2. 非研发项目（如技改、维保、行政）领用的物料；
3. 研发领料后转作生产使用的物料（须办理退库或转库手续）。

**第八条 研发与生产共用物料**
研发与生产共用的物料（如燃料、动力），按以下方法之一分摊：
1. 仪表计量法：安装独立计量表，按实际用量分摊；
2. 工时占比法：`研发用量 = 总用量 × 研发工时 / 总工时`；
3. 产量占比法：`研发用量 = 总用量 × 研发样机数量 / 总产量`。

## 第四章 试制试产领料管理

**第九条 试制领料**
研发试制阶段领用的物料，在领料单上标注"试制"字样，归入对应研发项目的直接投入费用。

**第十条 小批量试产领料**
小批量试产阶段的领料，如属于研发活动（验证工艺可行性、测试产品性能），可归入研发费用；如属于批量生产前的生产准备，则归入生产成本。须在领料单上明确标注"研发试产"或"生产试产"。

**第十一条 试模物料**
模具试模领用的物料（如试模料、调试料），在 `mold-management-system.md` 框架下管理，归入对应研发项目的直接投入费用。

## 第五章 样品样机管理

**第十二条 外购样品**
为研发活动采购的外部样品/样机/竞品，填写《样品采购申请单》，注明分析目的、与研发项目的关联性，归入直接投入费用（高企口径）或设计费（加计口径）。

**第十三条 自制样品**
研发过程中自制的样品/样机，按实际成本归集，完工后登记《样品/样机台账》，入库管理。

**第十四条 样品处置**
1. 研发过程中形成的下脚料、残次品、中间试制品对外销售的，按财税〔2015〕119号规定，在计算加计扣除时应冲减可加计扣除的研发费用；
2. 研发活动直接形成产品或作为组成部分形成产品对外销售的，按企业会计准则解释第15号处理，试运行销售收入冲减研发费用。

## 第六章 废料与回料管理

**第十五条 废料处理**
研发过程中产生的废料（下脚料、残次品等），按以下流程处理：
1. 废料入库：登记《废料回收台账》，注明来源项目、数量、预计处置方式；
2. 废料处置：对外销售的，在特殊收入台账中确认收入，按加计扣除口径冲减可加计扣除费用；
3. 内部回收：回料移交车间生产部门使用的，从研发费用中扣除相应金额。

**第十六条 回料管理（关键）**
研发领料形成回料后移交车间生产部门使用的，其实质系产品生产成本，不得归集到研发费用支出。参照案例十一（甬税稽二罚〔2022〕279号）的处理方式：每月末根据研发领料回料率，从研发费用中调减对应金额。

## 第七章 盘点与对账

**第十七条 定期盘点**
每月末对研发物料库存进行盘点，核对《材料领用单》与研发费用记录的一致性。差异须编制《研发物料盘点差异表》，说明原因并调整。

**第十八条 三方对账**
每月末由研发部、仓库/物控、财务部三方对账：研发领料单 → 物料出库单 → 费用归集表，确保"三单一致"。

## 第八章 费用归集与核算

**第十九条 归集口径**
1. 研发直接消耗材料 → 直接投入费用（加计/高企均可归集）；
2. 研发试制件/样品 → 直接投入费用；
3. 外购样品/竞品 → 设计费（加计）/ 直接投入（高企）；
4. 回料/废料收入 → 冲减可加计扣除费用（加计口径）；
5. 试运行产出 → 按解释第15号处理（冲减研发费用）。

**第二十条 辅助账登记**
按费用记录与科目台账口径登记，确保与辅助账、加计归集表、高企归集表三方一致。每笔领料须有佐证编号（佐证附件），无佐证不得归集。

## 第九章 监督与责任

**第二十一条**
研发部对物料领用真实性负责，仓库对物料出入库准确性负责，财务部对费用归集合规性负责，审计/内控部门定期抽查领料单与项目关联性。

**第二十二条**
对违反本制度造成研发费用归集错误、税务风险的，按公司责任追究办法处理。
