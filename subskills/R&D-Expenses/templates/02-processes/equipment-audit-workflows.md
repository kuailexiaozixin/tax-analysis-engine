# 流程：研发设备共用分摊流程

> 研发与生产共用设备时，折旧分摊的核心操作流程。

---

## 一、流程总览

```
[设备台账登记] → [使用记录填报] → [工时统计] → [分摊计算] → [财务入账]
```

## 二、详细流程

| 步骤 | 责任部门 | 工作内容 | 交付物 |
|------|---------|---------|-------|
| 1 | 设备管理部门 | 建立研发设备台账，标注"研发/共用/生产专用" | 设备台账 |
| 2 | 研发项目组 | 按月填报《研发设备使用登记表》 | 使用登记表 |
| 3 | 设备管理部门 | 汇总设备总使用工时（含研发+生产） | 工时汇总表 |
| 4 | 财务部 | 计算研发工时占比 = 研发工时/总工时 | 分摊计算表 |
| 5 | 财务部 | 按研发工时占比分摊折旧/租赁费 | 入账凭证 |

**分摊公式：**
```
设备应归集研发折旧额 = 设备月折旧额 × (研发工时 / 总工时)
```

# 流程：外部核查应对流程

> 税务稽查、高企复核、IPO尽调等外部核查的应对流程。

---

## 一、流程总览

```
[收到通知] → [内部预审] → [组织会议] → [现场配合] → [整改闭环] → [资料归档]
```

## 二、详细流程

| 阶段 | 责任部门 | 工作内容 | 关键点 |
|------|---------|---------|-------|
| 收到通知 | 财务部 | 记录核查类型、范围、时间要求 | 第一时间通知相关部门 |
| 内部预审 | 财务部+科技创新部 | 核对备查资料齐全性，预判风险点 | 对照《稽查准备清单》逐项检查 |
| 组织会议 | 财务部牵头 | 明确分工（财务+研发+人事+法务） | 指定对接人 |
| 现场配合 | 财务部+科技创新部 | 提供资料+解释说明 | 只提供被要求的资料，不主动扩展 |
| 整改闭环 | 财务部 | 如有问题，限期整改 | 整改报告须经审批 |
| 资料归档 | 财务部 | 核查记录归档，完善制度 | 经验教训沉淀 |

**核查常见问题应对：**
| 核查问题 | 应对要点 |
|---------|---------|
| 研发活动真实性 | 提供立项决议、过程记录、验收报告、成果证明 |
| 费用归集准确性 | 提供辅助账、分摊计算表、凭证 |
| 人员身份认定 | 提供研发人员名单、工时记录、岗位说明 |
| 设备共用分摊 | 提供设备使用登记表、工时统计表 |
| 委外研发 | 提供技术合同登记证明 |
