# {{企业名称}} 研发成果管理制度

**版本**：v{{版本}}　**生效日期**：{{生效日}}　**编制部门**：{{知识产权部/科技创新部}}

## 第一章 总则

**第一条** 为规范公司研发成果（专利、软著、技术秘密、技术标准等）的申报、登记、维护、转化、许可管理，确保研发成果与研发项目的关联性，满足高新技术企业认定和加计扣除政策要求，制定本制度。

**第二条** 本制度适用于公司全部研发活动产生的成果管理。

## 第二章 成果类型与归属

**第三条** 研发成果分类：
- **发明专利**：对产品、方法或其改进所提出的新的技术方案
- **实用新型专利**：对产品的形状、构造或其结合所提出的适于实用的新技术方案
- **外观设计专利**：对产品的形状、图案或其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计
- **软件著作权**：计算机软件著作权
- **技术秘密/专有技术**：不为公众所知悉、具有商业价值的技术信息
- **技术标准**：企业标准、行业标准、国家标准

**第四条** 研发成果归属：
- 自主研发：成果归公司所有
- 委托研发：按合同约定，未约定的归受托方
- 合作研发：按合同约定或按各方贡献度共有

## 第三章 成果申报流程

**第五条** 专利申报流程：
```
研发成果形成 → 专利检索评估（填写《专利文献检索评估表》）
→ 专利申请（捆绑项目编号） → 专利受理 → 审查 → 授权/驳回
→ 专利证书归档 → 专利维护（年费缴纳）
```

**第六条** 专利命名规则：`项目编号 + 产品型号 + 专利号 + 专利名称`
- 示例：`RD2026-001-XXX-202610123456.7-一种智能温控装置`

**第七条** 专利与高企项目关联：
- 专利须通过高企项目（RD编号）与对应研发项目项目编号捆绑
- 开展项目时，《专利文献检索评估表》与《专利申请》须捆绑该项目的对应项目编号
- 专利证书与专利权利说明书存于同一物理地址，按年度区分存放

## 第四章 成果台账管理

**第八条** 建立研发成果台账（含专利看板），字段包括：

| 字段 | 说明 |
|------|------|
| 项目编号 | 关联研发项目 |
| 产品型号 |  |
| 专利号/登记号 |  |

| 成果类型 | 发明/实用新型/外观设计/软著/技术秘密 |
| 申报主体 | 所属公司 |
| 申请状态 | 受理中/已出证书 |
| 保护状态 | 保护中/已过期 |
| 申请日 |  |
| 授权日 |  |
| 年费缴纳情况 |  |
| 关联研发项目 | 捆绑的RD编号 |
| 存放位置 | 纸质/电子档案路径 |

**第九条** 权限管理：
- 知识产权部：查阅、下载、编辑全部成果台账
- 高企项目统筹负责人：查阅、下载
- 事业部研发部门：查阅已授权成果及本部门申请的成果

## 第五章 成果转化与运用

**第十条** 研发成果转化形式：
- 应用于新产品/新工艺
- 许可/转让给其他方
- 作为高企认定核心知识产权
- 作为加计扣除研发活动成果证明

**第十一条** 成果转化记录须在项目结项报告中体现，作为研发活动真实性的证据链组成部分。

## 第六章 维护与年费管理

**第十二条** 知识产权部负责专利年费缴纳的统一管理，建立年费缴纳台账，防止因未缴年费导致专利失效。

**第十三条** 对于不再具有商业价值的专利，经评估后可按程序放弃，但须记录放弃原因。

## 第七章 附则

**第十四条** 本制度由知识产权部负责解释和修订。

## 稽查风险警示
> - 高企认定中"知识产权与研发项目关联性"是专家评审重点，无关联的知识产权不计分
> - 专利未捆绑项目编号，无法证明该专利来源于对应研发项目，高企认定被质疑
> - 专利年费逾期导致失效，高企认定时该知识产权不计入评分
