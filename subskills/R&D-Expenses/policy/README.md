# 研发费用政策文件库 · 总说明与索引

> **本目录是什么**：研发费用相关法规原文、官方解读、监管规则、协会答疑、行业指引与整本书的存放处。所有文件按**政策口径**归类，法规原文按**条款**建立行号索引，便于按条引用、按章取读。
> **文件形态**：法规原文为官方页面逐字转录，文首列明标题、文号、成文日期、效力状态与官方链接；官方解读、协会答疑、行业指引各有独立格式；整本书保留未拆分全文，另配章节树。
> **行号约定**：本 README 标注的行号指对应 `.md` 文件的行号（第 1 行为首行，含文首元数据块），用于快速跳转，不是法律条文编号。文件正文若有改动，行号须复核。
> **核验**：2026-10-22 起逐件从官方页面转录；2026-10-23 复核本索引全部行号，更正《企业所得税法及实施条例-研发费用加计扣除条款》编者注表中集成电路、工业母机企业资本化摊销比例（240% 改为 220%，依 2023 年第 44 号公告第一条）。
> **实务案例**：真实案例不入本目录，统一存放于 [`../cases/`](../cases/)，一案一文件，索引、风险点与政策映射见 [`../cases/README.md`](../cases/README.md)。

## 五、使用与维护

1. **按条引用**：先查第三章的条款索引，拿到“文件名＋条款＋行号”，再从对应文件读取原文；引用时不要只写行号，行号会随文件修订变化。
2. **先看效力状态**：每个法规文件文首都有“效力状态”和“效力提示”，被废止或修改的条款在文末单独说明，引用前先读这两处。
3. **分清三套口径**：会计口径看第二章第（三）节，高企口径看第（二）节，加计扣除口径看第（一）节；同一笔支出在三套口径下的金额不同，属正常，不是错误。
4. **别把增值税加计抵减当研发加计**：第（七）节两份文件讲的是增值税进项税额加计抵减，与研发费用企业所得税加计扣除无关。
5. **案例看 `cases/`**：真实案例的官方通报、处罚文书内容、风险点、违规手法与政策映射统一在 [`../cases/`](../cases/)，索引见 [`../cases/README.md`](../cases/README.md)，本目录不再另存案例原文。
6. **行业指引只作参考**：第（六）节的广东省税务局指引是 2022 年版，其中的比例、表单与最新政策不一致处，以第（一）节的现行文件为准。
7. **维护约定**：新增或替换法规文件时，同步更新第二章清单与第三章行号；新增真实案例时，只写入 `../cases/` 并按编号续编，同步更新其 README；整本书若重新分页，第四章章节树须重做。
