# 案例集 1｜虚构研发项目与虚假交易虚增研发费用（3 案）

> **分类依据（问题性质）**：加计扣除的**前提——研发项目本身不成立**。三案的违法事实均指向"没有真实研发活动，却编造出研发项目或直接虚增费用金额"，属于研发费用造假链条中**最上游、性质最重**的一类。
> **原单案编号**：08（上海同腾生物）、09（安徽大渝智能科技）、10（青海青美生物资源）
> **来源类型**：国家税务总局官网"曝光台"案件通报（官方原文，逐字收录）
> **共同定性**：均按《税收征收管理法》第六十三条第一款**偷税**处理，其中 10 号案另将虚开线索移送公安机关

---

## 一、分类说明：为什么这三案归为一类

| 判别维度 | 本类特征 |
| --- | --- |
| 造假环节 | **立项环节**——项目压根不存在，或虽存在但费用金额凭空编造 |
| 与后几类的区别 | 案例集 3（归集超范围）是"真研发、多归费"；本类是"**无研发、编费用**" |
| 稽查切入点 | 税收大数据精准分析线索（三案均由"精准分析线索"触发，非随机选案） |
| 典型手法 | ①虚构**委托外包**研发项目（08）；②虚构研发项目＋虚报费用（09）；③虚假交易虚开发票＋虚构研发项目（10） |
| 后果 | 追缴税款＋滞纳金＋罚款；涉及虚开的移送公安（10） |

**实务价值**：这三案是总局在不同时点（2023-10、2024-04、2024-10）连续发布的同类通报，说明"**虚构项目**"是税务机关最优先打击的研发造假形态。企业在做研发合规自查时，第一道防线应是"**项目真实性证据链**"（立项决议、计划书、预算、阶段报告、结题验收、成果载体），而非费用分摊细节。

## 二、分案详述

### （一）08 上海同腾生物科技有限公司

| 项目 | 内容 |
| --- | --- |
| 查处机关 | 国家税务总局上海市税务局第五稽查局 |
| 发布时间 | 2024-10-17 |
| 手法 | **虚构委托外包研发项目** |
| 金额 | 虚报研发费用加计扣除，**偷税 206 万元** |
| 处理结果 | 追缴税款、加收滞纳金并处罚款，**共计 376 万元** |
| 原文链接 | http://www.chinatax.gov.cn/chinatax/n810219/c102025/c5235298/content.html |

**手法要点**：委托研发是研发费用造假的高发通道——因为在"自主研发"模式下，人员、工时、领料都有内部痕迹可查；而**委托外包**只需一纸合同与一张发票即可形成支出，外部证据难以核实。08 号案与 01 号案（西藏慧业医药将**外购技术**伪装成委托研发，骗享加计少缴 999 万元）构成同一手法的两个量级样本。

> **交叉参照**：01（外购技术伪装委托研发，999 万）——本库同类手法中金额最大、有深度解读的案例，可与 08 对照阅读。

### （三）10 青海青美生物资源研究开发有限公司

| 项目 | 内容 |
| --- | --- |
| 查处机关 | 国家税务总局西宁经济技术开发区税务局稽查局（青海省税务局稽查局指导） |
| 发布时间 | 2023-10-27 |
| 手法 | **利用虚假交易虚开发票**＋**虚构研发项目**（双重手法） |
| 金额 | 虚增研发费用 260.91 万元，骗取加计扣除 211.22 万元，**合计虚增费用 472.13 万元** |
| 处理结果 | 调减虚增的研发费用及加计扣除金额；**虚开发票线索移送公安机关** |
| 原文链接 | http://www.chinatax.gov.cn/chinatax/n810219/c102025/c5215726/content.html |

**手法要点**：本集内**唯一叠加"虚开"**的案例。注意金额口径：通报分别列出"虚增研发费用 260.91 万元"与"骗取加计扣除 211.22 万元"，二者相加 472.13 万元——即**账面虚增数**与**加计扣除数**是两个不同口径，引用时不可混用。

> **交叉参照**：案例集 2（11 四川德阳、16 无锡某生物）同为"虚开发票"手法，但那两案是**以虚开凭证虚增已有研发项目的费用**，本案则是**同时虚构项目**，性质更重。

## 三、原文（逐字摘录）

### （一）08 号案官方通报全文

> 国家税务总局上海市税务局第五稽查局根据精准分析线索，依法查处上海同腾生物科技有限公司虚报研发费用加计扣除偷税案件。

> 国家税务总局上海市税务局第五稽查局有关负责人表示，10月份企业可以申报享受前三季度研发费用加计扣除，提醒广大纳税人依法如实申报。税务机关将进一步加大查处虚报研发费用骗取税收优惠的工作力度，坚持依法依规对骗取税收优惠政策等涉税违法行为开展检查。同时，加强对各类享受税费优惠政策企业的税费服务和税收监管，护航税费优惠政策落实落地。

## 五、风险提示

1. **委托研发是最高危通道**：08 与 01 两案均以"委托/外包研发"为造假载体。核查委托研发时，除合同与发票外，必须取得**受托方的研发过程证据**（阶段报告、交付成果、知识产权归属约定），仅凭合同发票不足以支撑加计。
2. **"精准分析线索"是主要案源**：三案均非举报或随机检查，而是税收大数据模型筛出。常见触发指标包括：研发费用占比突然跳升、研发人员人均费用异常、委托研发占比畸高、研发费用与期间费用勾稽矛盾（参见案例集 3 的 14 号案）。
3. **两个金额口径不要混用**：10 号案"虚增研发费用 260.91 万元"是账面口径，"骗取加计扣除 211.22 万元"是加计口径，合计 472.13 万元是通报的表述方式，引用时须注明口径。
4. **虚开必然触发行刑衔接**：涉及虚开发票的（10、11），税务部门一律将线索移送公安机关，不再止步于税务处理。
