# 研发费用实务案例库 · 总说明与索引

> **本目录是什么**：围绕「研发费用／研发支出／研发投入／高企认定研发费用」四个主题汇集真实实务案例。一个案例一个文件，文件名带出主体、事由与风险点，在文件管理器或全局检索中可直接定位。
> **组织方式**：每个案例的正文、官方原文、风险点与出处合并写在同一个 `编号_主体_事由_风险点.md` 文件中；`cases/` 内每个案例只出现一次。本 README 统一承担索引、来源说明与跨案例映射。
> **两类衍生文件**（不重复收录案例正文，只做横向归纳，案例正文仍以单案文件为准）：
> - `案例集N_问题性质_N案.md`——原 08–21 共 14 件按**问题性质**合并为 5 集，各集内仍保留每案的完整原文与对比表；
> - `专题_主题_N案_必读详读.md`——跨案例横向研究（研发产出确认时点 11 案、研发阶段划分与资本化时点 22 案），用于沉淀规则与实务自查清单。
> **原文收录**：01–25 已并入官方通报、税务行政处罚文书内容或项目鉴定意见；26–32 为项目鉴定与高企专项审计案例；**33–40、53–56、62、68–73 含"〇、案例原文（逐字摘录）"章节；41–44、46–51、57–61、63–67、74–76 共 23 个 IPO 问询案例含"〇、问答原文（逐字摘录）"章节**，完整保留问询问题、企业答复、数据表格与中介机构意见，未作删节。
> **IPO 问询案例的原文口径（2026-10-23 全面重取）**：23 个 IPO 问询案例的"〇、问答原文"已**全部重新抓取并重建**。此前抓取误用了 iposeek 的"搜索命中片段"模式（URL 带 `?q=`），dump 出的是以 `…` 截断、彼此重叠的碎片，导致内容残缺混乱；现一律改用**连续正文模式**取全文，并按"研发主题段落"精准定位摘录。当前 23 案**各只有 1 个问答原文章节、无重复、无碎片**，合计约 27.9 万字，表格已转为 Markdown 表格以便阅读（文字内容未改动）。
> **编号**：01–76 为全局统一编号，共 **60 个单案文件**（缺 45、52 两个已移除编号；原 08–21 共 14 件已按问题性质合并为 5 个 `案例集N_` 文件）。新增案例续编在后，已有编号不重排；**当前真正空置且不再使用的编号只有两个**：原 45（微容电子，系招股书披露而非 IPO 问询答复，不符合收录口径）、原 52（九目化学，与 58／59 研发产出主题重复且论证最薄弱）。29–35 号段**现已在用**（29–32 为项目鉴定案例、33–35 为高企稽查案例），历史沿革见第一章第（四）节。
