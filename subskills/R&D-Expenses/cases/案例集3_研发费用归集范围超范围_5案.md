# 案例集 3｜研发费用归集范围超范围（5 案）

> **分类依据（问题性质）**：研发项目真实、支出真实、发票真实，但**归错了科目**——把不属于研发的人员人工、直接投入、其他相关费用计入了研发费用。这是研发费用违规中**最高频、最容易被企业忽视**的一类。
> **原单案编号**：14（深圳某智能系统）、15（宁波某半导体）、19（宁波某汽车）、20（宁波某电子）、21（宁波永佳汽车）
> **来源类型**：税务行政处罚文书（隐名处理）
> **共同定性**：均按《税收征收管理法》第六十三条第一款**偷税**处理（14 号案为处罚事项告知阶段）

---

## 一、分类说明：按三个归集口径再细分

研发费用加计扣除的归集范围由**财税〔2015〕119 号**与**国家税务总局公告 2017 年第 40 号**界定，分为人员人工费用、直接投入费用、折旧费用、无形资产摊销、新产品设计费等、其他相关费用六大类。本集 5 案可按"**错在哪个口径**"再分三层：

| 细分层次 | 具体违规形态 | 对应案号 |
| --- | --- | --- |
| **① 人员人工** | 非研发人员工资计入研发；未完全参与研发人员工资**未按工时比例分摊**；与研发无关人员工资列支 | 19、20 |
| **② 直接投入** | 生产领料计入研发；共用材料、人员、设备**未按实际研发工时或用量分摊**；研发领料形成回料移交车间生产仍留在研发；生产车间耗用的模具计入研发 | 15、21 |
| **③ 其他相关费用** | 购车服务费、佣金咨询费等与研发无关的费用计入研发 | 21 |
| **④ 数据勾稽异常** | 申报研发费大于同期期间费用，逻辑矛盾（稽查最易发现的表层指标） | 14 |

**实务价值**：本集是**稽查口径最完整的一组**，几乎覆盖了 40 号公告归集范围的每一类高频错误。对企业而言，这一组是可直接对照自查的清单；对中介而言，这一组是专项审计程序的重点。

## 二、分案详述

### （一）14 深圳某智能系统有限公司——申报数与账面数勾稽矛盾

| 项目 | 内容 |
| --- | --- |
| 查处机关 | 国家税务总局深圳市税务局第二稽查局 |
| 文书号 | 深税二稽告〔2023〕1391 号 |
| 发布时间 | 2023-03-30 |
| 企业 | 深圳***智能系统有限公司（隐名，公告送达） |
| 违法事实 | 2020 年申报研发费 **521,357.93 元**（人员人工 516,022.93 元、直接材料 5,335.00 元），据此享受 75% 加计 391,018.45 元；但同期企业所得税申报表期间费用合计中列支的研发费用**仅 322,914.83 元** |
| 处理结果 | 公告送达《税务行政处罚事项告知书》 |

**手法要点**：本案的稽查突破口是**报表勾稽**——加计扣除申报的研发费（52.14 万元）大于账载期间费用中的研发费（32.29 万元），差额 19.84 万元。这是**最容易通过系统自动比对发现**的指标，企业在申报前应自行核对"研发费用加计扣除优惠明细表（A107012）"与"期间费用明细表（A104000）"的一致性。

| 项目 | 内容 |
| --- | --- |
| 查处机关 | 国家税务总局宁波市税务局第三稽查局 |
| 文书号 | 甬税稽三罚〔2022〕415 号 |
| 发布时间 | 2022-12-26 |
| 违法事实 | 2019—2021 年，通过列支**与研发工作无关**以及**未完全参与研发工作**的员工工资（**按工时参与百分比计算调减**）虚报研发，三年合计多申报 2,754,464.49 元，导致少缴企业所得税 611,177.60 元 |

### （四）20 宁波某电子有限公司——非研发人员工资＋收用虚开专票

| 项目 | 内容 |
| --- | --- |
| 查处机关 | 国家税务总局宁波市税务局第三稽查局 |
| 文书号 | 甬税稽三罚〔2022〕425 号 |
| 发布时间 | 2022-12-26 |
| 违法事实 | ①2009—2010 年收用虚开增值税专用发票 **27 份**，价税合计 2,043,821.40 元，进项已抵扣、成本已税前扣除；②2010—2017 年，将**非研发人员工资**计入当年研发费用，文书列举 2010 年 1.35 万元、2017 年 31.67 万元 |
| 处罚结果 | 对事实②所偷企业所得税 229,592.49 元处 **100% 罚款**（229,592.49 元）；事实①涉及的增值税等**因超过追征期不予处罚** |

**手法要点**：本案有两个独立价值：
1. **追征期抗辩成立**：虚开专票部分因超过追征期不予处罚，是本库**唯一体现追征期保护**的案例，可与 62 号案（北京天下图，追征期争议败诉）对照——同样是追征期争议，本案成立、62 号案不成立，差别在于是否被认定为偷税（偷税无追征期限制）。
2. **100% 罚款**（而非 50%）：说明非研发人员工资混同被认定为**情节较重**，与 19 号案同类事实却只罚 50% 形成裁量差异，值得关注。

### （五）21 宁波永佳汽车零部件有限公司——多类费用混入研发（最全面）

| 项目 | 内容 |
| --- | --- |
| 查处机关 | 国家税务总局宁波市税务局第二稽查局 |
| 文书号 | 甬税稽二罚〔2022〕279 号 |
| 发布时间 | 2022-10-28 |
| 违法事实（研发费用部分） | ①未用于研发的**购车服务费** 548,845.27 元计入研发；②与研发无关的**佣金咨询费** 280,572.78 元计入研发；③研发领料形成**回料后移交车间生产**（实质为生产成本）889,00.50 元计入研发（原文数字如此，位数疑有脱漏）；④研发**模具报废后出售未确认收入** 72,300.90 元，未冲减研发；⑤生产车间耗用的**模具** 463,008.86 元计入研发支出享受加计 |
| 从轻情节 | 检查期间已预缴税款、主动减轻危害后果 |
| 处罚结果 | 增值税 80% 罚款 106,666.86 元；城建税 80% 罚款 5,333.34 元；房产税 80% 罚款 2,745.49 元；企业所得税 80% 罚款 958,556.93 元；**合计 1,073,302.62 元** |

**手法要点**：本案是本集**覆盖面最广**的案例，单案同时触及五项违规，其中两项特别值得注意：
- **第③项**：研发领料形成回料移交生产 → 实质是生产成本。这与**研发产出专题**直接相关：按修订征求意见稿 1704（二）与解释 15 号，研发过程中产出物若满足资产确认条件应转库存商品，其对应成本不再属于研发费用。21 号案从**税务稽查**角度印证了同一规则。
- **第④项**：研发模具报废后**出售未确认收入、未冲减研发**。这与 2017 年第 40 号公告第七条"特殊收入扣减"（研发过程中形成的下脚料、残次品、中间试制品等特殊收入，应从已归集研发费用中扣减）直接对应，与 43 号案（菊乐食品中试产品销售冲减）互证。

> **交叉参照**：本项是**税务口径的"特殊收入扣减"**与**会计口径的解释 15 号"分别确认收入与成本"**的交汇点，详见《研发产出确认时点专题（必读）》。

## 五、风险提示

1. **勾稽比对是第一道筛子**：14 号案说明，A107012 与 A104000 的差异会被系统自动捕捉。申报前的表内表间勾稽自检成本极低、收益极高。
2. **工时分摊是产研共线企业的生命线**：15 号案"未按实际研发工时计算"是稽查表述，意味着企业**拿不出工时记录**。参照 65 号案（国电电缆理论工时分摊）、68 号案（鑫通机械研发工时专属打卡＋门禁记录比对），工时记录的可验证程度直接决定能否通过核查。
3. **罚款比例 50%／80%／100% 的裁量逻辑**：19 号案 50%、21 号案 80%、20 号案 100%。差异来自是否配合、是否预缴、情节轻重。21 号案因"检查期间已预缴税款、主动减轻危害后果"从轻至 80%（低于通常的 100% 上限但高于 50% 下限），提示**主动补缴能有效降低罚款比例**。
4. **追征期只对"非偷税"有效**：20 号案虚开部分因超追征期免罚，但工资混同部分被认定偷税、照罚。对比 62 号案（天下图）追征期争议败诉——**一旦定性偷税，追征期保护即不适用**。
5. **研发产出的税务侧处理别漏**：21 号案第③④项是税务口径对研发产出物的处理要求（回料转生产成本、报废出售收入冲减研发），与会计口径的解释 15 号并行适用，两者不可互相替代。
