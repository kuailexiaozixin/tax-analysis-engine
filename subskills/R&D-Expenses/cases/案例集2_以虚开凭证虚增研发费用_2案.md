# 案例集 2｜以虚开凭证虚增研发费用（2 案）

> **分类依据（问题性质）**：研发项目可能真实存在，但**费用凭证是假的**——以支付手续费方式取得虚开增值税专用发票或普通发票，计入研发费用并税前扣除／违规适用加计。
> **原单案编号**：11（四川德阳某技术有限公司）、16（无锡某生物科技有限公司）
> **来源类型**：11 为国家税务总局官网曝光台通报；16 为税务行政处罚文书（隐名）
> **定性差异**：11 按偷税追缴并移送公安；16 定性为"编造虚假计税依据"（征管法第六十四条第一款），因限期内改正从轻，仅罚 5 千元

---

## 一、分类说明：为什么这两案归为一类，又为什么定性不同

| 判别维度 | 本类特征 |
| --- | --- |
| 造假环节 | **凭证环节**——项目可真可假，但发票一定无真实交易支撑 |
| 与案例集 1 的区别 | 集 1 是"无项目编费用"；本集是"**凭假票入账**"，落脚点在发票 |
| 与案例集 3 的区别 | 集 3 是"真票、真支出、但归错科目"；本集是"**假票**" |
| 定性关键 | 是否同时造成少缴税款且无从轻情节——11 造成少缴且移送公安；16 因**限期内自行改正**按 64 条 1 款轻罚 |
| 行刑衔接 | 涉及虚开的一律移送公安机关（11 明示移送；16 由芜湖市税务局稽查局证实发票为虚开） |

**实务价值**：本集揭示了研发费用造假中**唯一会直接触发刑事风险**的形态。企业自查时，对"其他相关费用"中的外购技术服务、材料采购、检测费等**从外部取得发票**的支出，应优先核验"合同—发票—付款—交付成果"四流一致。

## 二、分案详述

### （一）11 四川德阳某技术有限公司

| 项目 | 内容 |
| --- | --- |
| 查处机关 | 国家税务总局德阳市税务局稽查局 |
| 发布时间 | 2023-07-28 |
| 案源 | **实名检举线索** |
| 手法 | 生产研发过程中**多列支成本费用**违规享受加计；同时**接受虚开增值税专用发票**违规抵扣进项 |
| 金额 | 违规加计 **290.35 万元**；追回少缴企业所得税等税款 **233.91 万元** |
| 处理结果 | 追回税款；**虚开增值税专用发票线索移送公安机关** |
| 原文链接 | http://www.chinatax.gov.cn/chinatax/n810219/c102025/c5210225/content.html |

**手法要点**：本案是"**违规加计**＋**虚开抵扣**"的双重违法。注意通报用词是"多列支成本费用"而非"虚构项目"——说明稽查认定的是**费用金额不实**，而非项目不存在，这使它区别于案例集 1。

### （二）16 无锡某生物科技有限公司

| 项目 | 内容 |
| --- | --- |
| 查处机关 | 国家税务总局无锡市税务局第一稽查局 |
| 文书号 | 锡税一稽罚〔2022〕55 号 |
| 发布时间 | 2022-02-28 |
| 企业 | 无锡***生物科技有限公司（隐名） |
| 手法 | 无真实货物交易，**以支付手续费方式**取得安徽***商贸有限公司虚开的增值税普通发票 12 份（品名：\*谷物加工品\*玉米粉、麸皮） |
| 金额 | 金额合计 1,165,173.78 元、价税合计 1,200,129 元，于 2018 年 10 月计入研发费用并税前扣除 |
| 定性依据 | 《税收征收管理法》第六十四条第一款（编造虚假计税依据）；江苏省税务行政处罚裁量基准——**限期内改正，处 5,000 元以下罚款** |
| 处罚结果 | **罚款 5,000 元** |

**手法要点**：本案是**本库处罚金额最低**的案例（5 千元），其价值不在金额，而在两点：
1. **定性不按偷税**：因企业在限期内改正，税务机关适用征管法第 64 条第 1 款"编造虚假计税依据"而非第 63 条"偷税"，**未影响纳税信用等级的偷税定性**——这是实务中争取从轻的关键路径；
2. **品名与研发的不匹配**：玉米粉、麸皮作为生物科技企业的研发材料本属合理，说明**品名合理性不能代替交易真实性**的核验，"四流一致"才是根本。

> **交叉参照**：12（吉林某化学工业未留存备查资料）、13（江苏某电气跨期加计）同按征管法第 64 条第 1 款处理，三案构成"**程序性/计税依据瑕疵**"系列，与 63 条偷税系列形成定性对照。

## 三、原文（逐字摘录）

### （一）11 号案官方通报全文

> 近期，四川省德阳市税务局稽查局根据实名检举线索，依法查处某技术有限公司涉嫌接受虚开增值税专用发票并违规适用研发费用加计扣除案件。
>
> 经查，该公司在生产研发过程中，通过多列支成本费用违规享受研发费用加计扣除290.35万元。同时，该公司还存在接受虚开增值税专用发票，违规抵扣增值税进项税额等涉税违法问题。德阳市税务局稽查局依据《中华人民共和国税收征收管理法》等相关规定，依法追回该公司少缴企业所得税等税款233.91万元。目前，税务部门已将该案虚开增值税专用发票线索移送公安机关。
>
> 德阳市税务局稽查局有关负责人表示，将进一步发挥税务、公安、检察、法院、海关、人民银行、外汇管理等七部门联合打击机制作用，坚持以零容忍的态度对虚开发票等涉税违法犯罪行为重拳出击、严惩不贷。同时，加强对享受各类税收优惠政策企业的税费服务和税收监管，依托税收大数据分析，对存在涉税风险的依法处理，不断提升企业税法遵从度，护航税费支持政策落准落好。


### （二）16 号案处罚文书要点（转录）

> 违法事实：
> 接受安徽***商贸有限公司开具的 12 份增值税普通发票（*谷物加工品*玉米粉、麸皮），金额合计 1,165,173.78 元、价税合计 1,200,129 元。上述发票经芜湖市税务局稽查局证实为虚开。公司于 2018 年 10 月计入研发费用并税前扣除 1,200,129 元；经查无真实货物交易，系以支付手续费方式取得虚开发票。
>
> 处罚依据：
> 《中华人民共和国税收征收管理法》第六十四条第一款；江苏省税务行政处罚裁量基准（限期内改正，处 5000 元以下罚款）。
>
> 处罚结果：
> 罚款 5000 元（已在限期内改正，从轻）。

## 五、风险提示

1. **从轻定性的关键是"限期内改正"**：16 号案罚款 5 千元而非按偷税处 50% 罚款，核心在于企业在检查期间已自行改正。这是研发费用问题被查出后的**首要应对策略**。
2. **专票与普票的后果差异**：涉及增值税专用发票（11 号案）必然触发进项抵扣问题与行刑衔接；普票（16 号案）停留于所得税扣除层面，处理空间更大。
3. **品名合理不等于交易真实**：玉米粉、麸皮对生物科技企业是合理研发材料，但无真实货物交易仍构成虚开。核验必须落到"合同—发票—付款—成果"四流。
4. **与其他"其他相关费用"风险的衔接**：研发费用中的外购技术服务、检测费、咨询费等**外购类支出**是虚开高发区（参见 21 号案中与研发无关的佣金咨询费 28.06 万元计入研发）。
