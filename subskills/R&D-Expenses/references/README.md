# 参考规则索引（方法与规则）

> `references/` 存放本技能的**方法与规则**（不含原始政策与案例——那些在 `policy/`、`cases/`）。主要在「二、六步标准工作流」第 4 步取用；口径取值一律以 `subject-caliber-baseline.md` 为**唯一基准**。

| 文件 | 是什么 | 用在哪 |
|:---|:---|:---|
| `subject-caliber-baseline.md` | 科目级口径基准（会计 / 高企认定 / 加计扣除 + R&D 统计 / IPO 逐科目取值与限额）——**唯一基准** | 3.4 财税处理；任何口径判定 |
| `hitech-scoring.md` | 高企认定评分自检（K1–K8 一票否决 + 四项指标 100 分 / 71 达标 + 报告结构） | 3.2 项目申报 |
| `rd-mgmt-methodology.md` | 研发费用管理方法论（口径基准原稿、辅助账、内控要点） | 3.4 / 3.5 |
| `workflow-governance.md` | 制度侧工作流（立项 / 工时 / 领料 / 结项等） | 3.5 内控建设与流程优化 |
| `workflow-evidence.md` | 证据 / 资料包工作流（三套资料包、证据链） | 3.5 / 3.6 / 3.7 |

> 政策原文与认定办法等以 [`../policy/`](../policy/README.md) 为准；真实案例见 [`../cases/`](../cases/README.md)；可交付模板见 [`../templates/`](../templates/README.md)。
