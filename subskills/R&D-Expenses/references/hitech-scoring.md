# 高企认定评分自检（八条一票否决 + 四项指标 100 分 / 71 分达标）

> 用途：申报前逐项核算——八条一票否决过不过、四项指标能得多少分、差的分先补哪一块最划算。
> 依据：《高新技术企业认定管理办法》（国科发火2016-32号，第十一条）、《高新技术企业认定管理工作指引》（国科发火2016-195号）。评分细则原文见 `../policy/高新技术企业认定管理工作指引-国科发火2016-195号.md`。
> ⚠️ 各省市材料口径、受理批次存在差异，报告须提示**以当地认定管理机构当期公布的指引为准**。数据一律来自用户提供，缺失标「（待补）」，**绝不虚构**。

## 一、八条一票否决（K1–K8）

| 项 | 条件 | 标准 | 判定 |
|:--|:--|:--|:--|
| K1 | 注册成立时间 | 注册成立满一年（以营业执照成立日计至申报时） | 不满一年直接终止，不再评分 |
| K2 | 核心知识产权所有权 | 对主要产品在技术上发挥核心支持作用的知识产权所有权 ≥ 1 项 | 0 项一票否决 |
| K3 | 技术领域 | 主要产品核心技术属于《国家重点支持的高新技术领域》 | 不在范围内一票否决 |
| K4 | 科技人员占比 | 科技人员 ÷ 当年职工总数 ≥ 10%；科技人员为累计实际工作 **183 天以上**的在职/兼职人员 | 不足一票否决 |
| K5 | 研发费用占比 | 按最近一年销售收入分档：≤5000 万 ≥5%；5000 万–2 亿 ≥4%；>2 亿 ≥3%（近三个会计年度研发费用总额 ÷ 同期销售收入总额） | 不足一票否决 |
| K6 | 境内研发费用占比 | 中国境内发生研发费用 ÷ 全部研发费用 ≥ 60% | 不足一票否决 |
| K7 | 高新技术产品收入占比 | 近一年高新技术产品（服务）收入 ÷ 同期总收入 ≥ 60% | 不足一票否决 |
| K8 | 重大事故与违法 | 申请认定前一年内无重大安全、重大质量事故或严重环境违法行为 | 有其一即一票否决 |

**输出纪律**：一票否决结论**必须排在评分明细之前**。任一否决条件不满足时，先说「评分再高也不能通过」，再给分数。

## 二、四项评分指标（满分 100，71 分达标）

### 2.1 知识产权（30 分）

| 评分项 | 满分 | 判定 |
|:--|--:|:--|
| 技术先进程度 | 8 | 高 8 / 较高 7 / 一般 5 / 较低 3 / 无 0 |
| 对主要产品的支撑作用 | 8 | 强 8 / 较强 6 / 一般 4 / 较弱 2 / 无 0 |
| 数量 | 8 | Ⅰ类 ≥1 项：7–8；Ⅱ类 ≥5 项：5–6；Ⅱ类 1–5 项：3–4；均为 0：0 |
| 获得方式 | 6 | 自主研发 6 / 受让、受赠、并购 3 |
| 参与编制国家/行业标准等（加分） | 2 | 参与编制国家标准、行业标准、检测方法、技术规范：+1 或 +2 |

**Ⅰ类**：发明专利（含国防专利）、植物新品种、国家级农作物品种、国家新药、国家一级中药保护品种、集成电路布图设计专有权。**Ⅱ类**：实用新型、外观设计、软件著作权（不含商标）。**Ⅱ类在申请高企时仅限使用一次**。

### 2.2 科技成果转化能力（30 分）

按近三个会计年度转化总数 ÷ 3 得年平均转化数：

| 年平均转化数 | 分值区间 |
|:--|--:|
| ≥ 5 项 | 25–30 |
| ≥ 4 项 | 19–24 |
| ≥ 3 项 | 13–18 |
| ≥ 2 项 | 7–12 |
| ≥ 1 项 | 1–6 |
| 0 项 | 0 |

同一成果转化为多个产品只算一项；每项需有证明材料（技术合同、销售合同与发票、检测报告、用户使用报告、新产品证书、样品样机等）。

### 2.3 研究开发组织管理水平（20 分）

四项各按「制度健全且实际执行」判定，**只能满分或 0 分**（不存在中间分）；只有制度文件而无执行记录的不算健全。

| 评分项 | 满分 |
|:--|--:|
| 研发组织管理制度、研发投入核算体系、研发费用辅助账 | 6 |
| 内部研发机构、科研条件、产学研合作 | 6 |
| 科技成果转化的组织实施与激励奖励制度、开放创新创业平台 | 4 |
| 科技人员培养进修、职工技能培训、优秀人才引进、人才绩效评价奖励制度 | 4 |

### 2.4 企业成长性（20 分）

净资产增长率、销售收入增长率各 10 分，共用加权公式：

```
增长率 = 1/2 ×（第二年 ÷ 第一年 + 第三年 ÷ 第二年）− 1
```

| 增长率 | 分值区间 |
|:--|--:|
| ≥ 35% | 9–10 |
| ≥ 25% | 7–8 |
| ≥ 15% | 5–6 |
| ≥ 5% | 3–4 |
| ≥ 0% | 1–2 |
| < 0% | 0 |

**注意**：任一期基数 ≤ 0 时该项无法计算，按 0 分计并标注原因；实际经营期不满三年按实际经营时间计算。**成长性不能当可补分项**——它由近三年财务数据算出，补材料改不了，只能在其他三项上补。

### 主观项以区间呈现

**技术先进程度**与**对主要产品的核心支持作用**属**专家主观评价**：请用户按 高/较高/一般/较低/无（强/较强/一般/较弱/无）自评并说明理由，报告中以**保守—乐观区间**呈现，不单点断言。

## 三、数据采集与校验纪律

1. **比例一律填小数**：用户说「5%」转成 `0.05`；说「5」须追问是 5% 还是 5 倍。
2. **金额一律以元为单位**：用户说「8000 万」转成 `80000000`。
3. **时间序列必须正序且长度为 3**：倒序或只给两年时，先补齐再计算。
4. **基数 ≤ 0 的处理**：净资产为负或首年营收为 0，该项按 0 分计并标注原因。
5. **未提供 ≠ 不达标**：用户「不清楚」记为缺失并**单列**，不得当作「不达标」直接判一票否决失败。
6. **缺失过半先补齐**：决定性字段大面积缺失（>半数）时，评分结论价值有限，先补齐再算。

## 四、评分报告结构

```markdown
## 高企认定评分自检报告

**总体结论**：当前自评 XX 分，距 71 分达标线还差 XX 分
**规则基线**：{规则整理日期}

## 一票否决检查
> 共 8 项，通过 X 项，不通过 X 项，待确认 X 项
（K1–K8 逐项：条件 / 标准 / 当前 / 结论）

## 评分明细
（四项指标逐项：满分 / 得分 / 失分 + 各评分项得分原因；主观项以区间呈现）

## 补齐路径（按提升性价比排序）
距达标线还差 XX 分。以下按「每提升 1 分所需代价」从低到高排列：
1. {补齐项}（可补 X 分，难度：低/中/高/不可通过补材料改变）
   - {具体做法，只能指向真实的制度建设、真实的知识产权申请、真实的成果转化}

## 未覆盖与免责
- 本报告为申报前自评，不替代认定机构的评审结论，不承诺通过结果。
- 以当地认定管理机构当期公布的指引为准。
```

## 五、差距整改优先级

按「每提升 1 分所需代价」从低到高排序：

1. **补制度**（研究开发组织管理水平 20 分）——补制度文件 + 执行记录即可得满，见效最快；
2. **补成果转化证明**（30 分）——补齐合同/发票/检测报告等，凭**真实转化**；
3. **补知识产权**（30 分）——真实申请/受让，注意Ⅱ类只能用一次、突击申请易被否。

**成长性（20 分）不可补**。补齐路径只能指向真实行为，不得虚增。

## 六、常见被否原因

- 知识产权与主要产品关联性弱、Ⅱ类专利临近申报突击申请。
- 科技人员名单与社保 / 工资表不一致；183 天口径未留痕。
- 研发费用专项审计报告与年度审计、纳税申报数据不一致。
- 成果转化证明只有合同没有发票、检测报告。
- 高新收入归类与领域不匹配，或贸易性收入占比过高。
- 制度文件为申报前突击编写、无执行记录。

## 八、红线与停止条件

- **不承诺**认定通过或下证结果，只说「自评得分」与「存在哪些不达标项」。
- **不代编 / 不代交**申报材料；**不提供**专项审计或鉴证（须由资质中介机构出具）。
- **不得**建议通过虚增研发费用、虚构科技成果转化来满足指标；补齐路径只能指向真实行为。
- 用户要求「包装材料 / 借用专利」等造假 → **拒绝并说明后果**（取消资格、追缴税款、5 年内不得再申请）。
- 各省市材料口径、受理批次有差异，须提示以当地认定管理机构当期公布的指引为准。
