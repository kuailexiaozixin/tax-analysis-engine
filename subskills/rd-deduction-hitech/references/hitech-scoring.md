# 高企认定评分自检（八条一票否决 + 四项指标 100 分）

> 本文件整合自「高企认定评分自检台」的公开评分规则，用于在申报高新技术企业认定前逐项核算：八条一票否决过不过、四项指标能得多少分、差的分先补哪一块最划算。按本文件规则由 Agent 直接核算，无外部服务依赖。
> 政策口径依据：国科发火〔2016〕32 号（认定办法）、国科发火〔2016〕195 号（工作指引）。各省市材料口径、受理批次存在差异，报告必须提示以当地认定管理机构当期公布的指引为准。

## 一、八条一票否决（K1–K8）

| 项 | 条件 | 标准 | 判定 |
|---|---|---|---|
| K1 | 注册成立时间 | 注册成立满一年（以营业执照成立日期计至申报时） | 不满一年直接终止，不再评分 |
| K2 | 核心知识产权所有权 | 对主要产品在技术上发挥核心支持作用的知识产权所有权 ≥ 1 项 | 0 项一票否决 |
| K3 | 技术领域 | 主要产品核心技术属于《国家重点支持的高新技术领域》规定范围 | 不在范围内一票否决 |
| K4 | 科技人员占比 | 科技人员数 ÷ 当年职工总数 ≥ 10%；科技人员为累计实际工作时间 **183 天以上**的在职/兼职人员 | 不足一票否决 |
| K5 | 研发费用占比 | 按最近一年销售收入分档：≤5000 万元 ≥5%；5000 万–2 亿元 ≥4%；>2 亿元 ≥3%（近三个会计年度研发费用总额 ÷ 同期销售收入总额） | 不足一票否决 |
| K6 | 境内研发费用占比 | 中国境内发生研发费用 ÷ 全部研发费用 ≥ 60% | 不足一票否决 |
| K7 | 高新技术产品收入占比 | 近一年高新技术产品（服务）收入 ÷ 同期总收入 ≥ 60% | 不足一票否决 |
| K8 | 重大事故与违法 | 申请认定前一年内无重大安全、重大质量事故或严重环境违法行为 | 有其一即一票否决 |

**输出纪律**：一票否决结论必须排在评分明细之前。任一否决条件不满足时，先说「评分再高也不能通过」，再给分数。

## 二、四项评分指标（满分 100，71 分达标）

### 2.1 知识产权（30 分）

| 评分项 | 满分 | 判定 |
|---|---:|---|
| 技术先进程度 | 8 | 高 8 / 较高 7 / 一般 5 / 较低 3 / 无 0（按证明档次） |
| 对主要产品的支撑作用 | 8 | 强 8 / 较强 6 / 一般 4 / 较弱 2 / 无 0 |
| 数量 | 8 | Ⅰ类 ≥1 项：7–8；Ⅱ类 ≥5 项：5–6；Ⅱ类 1–5 项：3–4；均为 0：0 |
| 获得方式 | 6 | 自主研发 6 / 受让、受赠、并购 3 |
| 参与编制国家/行业标准等（加分） | 2 | 参与编制国家标准、行业标准、检测方法、技术规范：+1 或 +2 |

**Ⅰ类**：发明专利（含国防专利）、植物新品种、国家级农作物品种、国家新药、国家一级中药保护品种、集成电路布图设计专有权。
**Ⅱ类**：实用新型专利、外观设计专利、软件著作权等（不含商标）。

### 2.2 科技成果转化能力（30 分）

按近三个会计年度转化总数 ÷ 3 得年平均转化数：

| 年平均转化数 | 分值区间 |
|---|---:|
| ≥ 5 项 | 25–30 |
| ≥ 4 项 | 19–24 |
| ≥ 3 项 | 13–18 |
| ≥ 2 项 | 7–12 |
| ≥ 1 项 | 1–6 |
| 0 项 | 0 |

### 2.3 研究开发组织管理水平（20 分）

四项各按「制度健全且实际执行」判定，只能满分或 0 分（不存在中间分）；只有制度文件而无执行记录的不算健全。

| 评分项 | 满分 |
|---|---:|
| 研发组织管理制度、研发投入核算体系、研发费用辅助账 | 6 |
| 内部研发机构、科研条件、产学研合作 | 6 |
| 科技成果转化的组织实施与激励奖励制度、开放创新创业平台 | 4 |
| 科技人员培养进修、职工技能培训、优秀人才引进、人才绩效评价奖励制度 | 4 |

### 2.4 企业成长性（20 分）

两项各 10 分（净资产增长率、销售收入增长率），共用加权公式：

```
增长率 = 1/2 ×（第二年 ÷ 第一年 + 第三年 ÷ 第二年）− 1
```

| 增长率 | 分值区间 |
|---|---:|
| ≥ 35% | 9–10 |
| ≥ 25% | 7–8 |
| ≥ 15% | 5–6 |
| ≥ 5% | 3–4 |
| ≥ 0% | 1–2 |
| < 0% | 0 |

**注意**：任一期基数 ≤ 0 时该项无法计算，按 0 分计并标注原因；实际经营期不满三年按实际经营时间计算并在报告中说明。**成长性不能当可补分项**——它由近三年财务数据算出，补材料改不了，只能在其他三项上补。

## 三、数据采集纪律

1. **比例一律填小数**：用户说"5%"转成 `0.05`；说"5"要追问是 5% 还是 5 倍。
2. **金额一律以元为单位**：用户说"8000 万"转成 `80000000`。
3. **不得估算缺失数据**：用户说"大概百分之五"时，记为 `0.05` 并在报告中标注为估算值。
4. **时间序列必须正序且长度为 3**：倒序或只给两年时，先补齐再计算。
5. **未提供与不满足必须区分**：用户说"不清楚"记为缺失，不能当成"不达标"直接判一票否决失败。未提供的数据必须单列，不得因为没提供就当作"不达标"。

## 六、合规红线（不可逾越）

- 不得承诺认定通过或下证结果，只说"自评得分"与"存在哪些不达标项"。
- 不得代用户编制申报材料或代为提交，本技能只做自评与补齐建议。
- 不得提供专项审计或鉴证服务；研发费用与高新技术产品收入需由资质中介机构出具专项审计或鉴证报告，本技能不替代，仅按用户提供的既有数据核算。
- 不得建议通过虚增研发费用、虚构科技成果转化来满足指标；补齐路径只能指向真实行为。
- 各省市在材料口径、受理批次上存在差异，报告必须提示以当地认定管理机构当期公布的指引为准。
