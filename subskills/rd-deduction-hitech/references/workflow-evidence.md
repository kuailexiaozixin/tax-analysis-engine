# 工作流 B — 研发佐证、证据链与三套资料包（资料侧剧本）

**目标**：让每一分研发费用"说得清来源、拿得出证据、经得起核查"，一次性产出加计扣除、高新技术企业认定、IPO 申报三套研发费用全套资料。

> 政策口径见 `regulatory-basis.md`；清单/报表模板见 `references/templates/03-forms/evidence-checklist.md` 与 `references/templates/03-forms/reports.md`；方法论见 `rd-mgmt-methodology.md`。
>
> **📚 实务手册参考**：加计扣除优惠内容与费用归集详见 `book-rd-deduction-hightech/rd-deduction-benefits.md`（第二章）；申报流程与留存备查资料详见 `book-rd-deduction-hightech/rd-deduction-filing-risk.md`（第五章）；高企认定8项条件与研发费用归集详见 `book-rd-deduction-hightech/hightech-certification-conditions.md`（第七章）；高企税收优惠详见 `book-rd-deduction-hightech/hightech-tax-benefits.md`（第六章）；IPO研发投入监管详见 `book-rd-deduction-hightech/ipo-rd-supervision.md`（第三章）；研发费用财务处理与辅助账详见 `book-rd-deduction-hightech/rd-financial-control.md`（第四章）；认定程序与监督管理详见 `book-rd-deduction-hightech/hightech-supervision-risk.md`（第八章）。**涉及政策引用时务必检查 `book-rd-deduction-hightech/policy-updates-2024-2026.md` 时效性标注。**

---

## 阶段 1 · 资料采集（真实数据）

**动作**：基于用户提供的企业数据（企业台账 / 财务明细 / 用户口述），结构化以下数据（缺什么明确列"待补资料清单"）：
- 项目清单（编号、名称、起止、负责人、阶段、归集口径）
- 费用按科目归集（人员人工/直接投入/折旧摊销/设计费/装备调试试验费/其他）
- 人员与工时（研发人数、占比、工时记录、薪酬归集）
- 设备与材料（研发设备折旧、材料领用）
- 委外研发（合同、费用、成果归属）
- 既有证据与风险记录

**注意**：无佐证编号的费用属高风险，必须在证据链阶段补齐。

**口径基准**：费用归集的"三大口径对比"（加计扣除 / 高企认定 / 会计）及各科目边界以 `references/rd-mgmt-methodology.md` 第 4.1 节为准；若企业需填报 R&D 投入统计，参照该文件第 7 章（统计范围 / 指标 / 原则）。

---

## 阶段 2 · 证据链组装（系统可查）

**动作**：对每个项目/费用，归集佐证并**登记入证据台账**（按项目编号维度）：

| 证据类别 | 典型佐证 | 来源 |
|---|---|---|
| 立项类 | 立项决议、可研报告、预算批复 | 研发项目台账 / 政策规则台账 |
| 合同类 | 研发合同、委外协议、知识产权归属 | 委外合同台账 |
| 投入类 | 发票、领料单、设备折旧表、工时记录 | 研发费用台账 / 材料领用台账 / 设备台账 / 工时台账 |
| 过程类 | 阶段评审、实验记录、检测报告 | 研发项目台账（节点记录） |
| 验收类 | 结题验收报告、成果证明 | 研发项目台账（节点记录） |
| 资本化类 | 资本化审批、测试报告 | 资本化审批记录 |

**归档**：证据链按项目整理为清单（模板见 `references/templates/03-forms/evidence-checklist.md`），导出 PDF 作为申报附件。完成后证据链可查、可导出、可审计。

## 阶段 3 · 三套资料包映射

统一骨架见 `references/templates/03-forms/reports.md` 报告大纲 7 章 + `references/templates/03-forms/evidence-checklist.md`。三套口径差异：

### 3.1 加计扣除资料包
- **政策**：财税〔2015〕119 号、国家税务总局公告 2015 年第 97 号、2017 年第 40 号、2023 年第 7 号（全行业 100%，制度性安排）、2023 年第 44 号（集成电路/工业母机 120%）、2023 年第 11 号（预缴三次享受）。详见 `book-rd-deduction-hightech/rd-deduction-benefits.md` 与 `book-rd-deduction-hightech/policy-updates-2024-2026.md`。
- **核心产出**：
  - 可加计扣除研发费用归集表（人员人工/直接投入/折旧摊销/无形资产摊销/新品设计费等/其他相关费用，注意其他相关费用 10% 限额）
  - 研发费用辅助账（按项目、按科目）
  - 加计扣除优惠明细表（A107012 口径）
  - 佐证清单（立项、合同、发票、工时、成果）
- **口径提醒**：委外研发按 80% 计入（境外部分不超过境内符合条件研发费用 2/3）；其他相关费用不得超过可加计总额的 10%；允许加计的 6 项费用明细与委托研发规则见 `references/rd-mgmt-methodology.md` 第 5 章。

### 3.2 高新技术企业认定资料包
- **政策**：国科发火〔2016〕32 号（认定办法）、国科发火〔2016〕195 号（工作指引）。**⚠️ 2024-2026年更新**：认定管理已划归工信部；现行仍按 2016 版办法执行，修订稿尚未发布，以官方正式文件为准。详见 `book-rd-deduction-hightech/hightech-certification-conditions.md` 与 `book-rd-deduction-hightech/policy-updates-2024-2026.md`。
- **核心产出**：
  - 近三年研发费用专项审计/归集表（占比是否达标：销售收入≤5000 万≥5%；5000 万–2 亿≥4%；>2 亿≥3%）
  - 科技人员占比（≥10%）、研发人员工时分配
  - 研发费用与知识产权关联性说明
  - 高企申报书研发费用章节
- **口径提醒**：境内研发费用占比≥60%；归集口径与加计略有差异（高企含装备调试费、试验费，其他费用不超研发费用总额 20%），需分别列示；高企 8 类费用归集范围见 `references/rd-mgmt-methodology.md` 第 6.3 节。

### 3.3 IPO 申报资料包
- **政策**：证监会《监管规则适用指引——发行类第9号：研发人员及研发投入》、《首次公开发行股票并上市管理办法》、《首发业务若干问题解答》（2020）。详见 `book-rd-deduction-hightech/ipo-rd-supervision.md`。
- **核心产出**：
  - 研发费用真实性核查底稿（合同—发票—工时—领料—验收 五流合一）
  - 内控制度有效性说明（引用工作流 A 制度）
  - 核算规范性（资本化判定依据、分摊方法、同行业可比）
  - 研发费用占收入比、变动合理性分析
  - 中介机构核查程序与结论支持性文件清单
- **口径提醒**：重点核查费用跨期、资本化合规性、关联方交易、研发人员认定。

## 阶段 4 · 资料包草稿生成

**动作**：套用 `references/templates/` 模板生成三套资料包草稿 + 证据清单草稿（骨架见 `references/templates/03-forms/reports.md` 与 `references/templates/03-forms/evidence-checklist.md`）：
1. 基于阶段 1 数据填充归集表与占比测算表；
2. 套 `references/templates/` 制度/表单模板补齐说明性章节；
3. 产出 Markdown 草稿，由 Agent 按企业实情润色、补定性说明、核对政策引用。

---

## 阶段 5 · 交付与归档

**交付形态**（通用交付规则）：
- 三套资料包正文 → Word/PDF
- 证据链 → 证据台账 + PDF 归档
- 报表 → `references/templates/03-forms/reports.md` 对应表格，可 Excel/PDF

**收尾提示**：资料为申报草稿，最终以税务师、保荐机构、监管机构口径为准；证据链务必真实、完整、可回溯。

---

## 与工作流 A 的衔接

- 工作流 A 建立的制度与流程，是工作流 B "内控有效性""核算规范性"章节的依据。
- 工作流 B 暴露的证据缺口（如某项目佐证编号为空），应反馈到工作流 A 的日常规范，补强表单与归档要求。
- 两工作流共用同一套企业数据台账与 `references/templates/03-forms/forms.md`/`references/templates/03-forms/reports.md`。
