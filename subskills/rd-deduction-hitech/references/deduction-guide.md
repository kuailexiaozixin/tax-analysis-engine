# 研发费用加计扣除归集与口径协同

> 加计扣除归集规则与口径协同要点，与 `rd-mgmt-methodology.md`（费用归集方法论）配套使用。政策引用须同步核对 `book-rd-deduction-hightech/policy-updates-2024-2026.md` 时效性标注。

## 一、加计扣除比例与适用

| 情形 | 比例 | 依据 |
|---|---|---|
| 一般企业 | 100%（制度性安排） | 财政部 税务总局公告 2023 年第 7 号 |
| 集成电路、工业母机企业 | 120%（至 2027-12-31） | 财政部等四部门公告 2023 年第 44 号 |
| 资本化形成无形资产 | 按摊销额 100% 加计（不是原值） | 2023 年第 7 号 |
| 预缴享受时点 | 7 月、10 月预缴申报及汇算清缴三次 | 国家税务总局 财政部公告 2023 年第 11 号 |

**负面清单行业**（烟草、住宿餐饮、批发零售、房地产、租赁商务服务、娱乐等）主营且收入占比 >50% 不得加计；研发活动须符合财税〔2015〕119 号第一条第（一）款界定，非研发活动（如技术改造、常规升级）不得加计。

## 二、六类费用归集范围

| 类别 | 内容要点 |
|---|---|
| 1. 人员人工费用 | 直接从事研发活动人员（含外聘）的工资薪金、五险一金，以及外聘劳务费 |
| 2. 直接投入费用 | 材料、燃料、动力；用于研发的仪器设备租赁费、运行维护费、调整检验费；试制产品的检验费 |
| 3. 折旧费用 | 用于研发活动的仪器、设备折旧费 |
| 4. 无形资产摊销 | 用于研发活动的软件、专利权、非专利技术摊销费 |
| 5. 新产品设计费等 | 新产品设计费、新工艺规程制定费、新药研制的临床试验费、勘探开发技术现场试验费 |
| 6. 其他相关费用 | 与研发活动直接相关的技术图书资料费、资料翻译费、专家咨询费、高新科技研发保险费、研发成果的检索分析评议论证鉴定评审评估验收费、知识产权的申请费注册费代理费、差旅费、会议费（**受 10% 限额**） |

**委托研发**：委托境内机构按实际发生额 80% 计入加计基数；委托境外机构按实际发生额 80% 计入且不超过境内符合条件的研发费用 2/3。委托关联方的，须按规定留存备查。

## 三、其他相关费用 10% 限额

```
限额 =（可加计扣除研发费用总额 − 其他相关费用）× 10% ÷ (1 − 10%)
```

- 其他相关费用**超过限额部分不得加计**，也没有结转以后年度重新计算的条款；多项研发活动
  自 2021 年度起统一计算限额，资本化项目的其他费用在形成无形资产年度统一纳入
  （按 2021 年第 28 号）。
- **口径提醒**：高企认定的其他费用上限是 20%，加计扣除是 10%，两口对"其他费用"的列举
  也不相同——同一费用不得在高新与加计中重复归集享受，避免被调减补税。

## 四、扩展口径对照（R&D 统计与 IPO 披露）

会计／高企／加计三套口径的**科目级取值、限额与差异争点**以
`rd-mgmt-methodology.md` 第 4.1 节为唯一基准，本节不再重复，只补两套本技能会碰到的扩展口径。

| 维度 | R&D 统计口径 | IPO 披露口径 |
|---|---|---|
| 其他费用上限 | 按统计口径归集，不设税务式比例上限 | 无统一上限，含研发机构管理费 |
| 委托研发 | 按统计口径处理，委托方与受托方不重复计入 | 委外按合同约定全额计入 |
| 人员口径 | 研发人员全时当量（按实际从事 R&D 活动的时间折算，计量单位为人年） | 范围较宽，含参与研发的中高层、项目经理与研发支持人员，含研发管理人员薪酬与股权激励费用 |
| 资本化处理 | 按 R&D 投入统计 | 与会计准则衔接，作专项披露调整 |
| 失败项目 | 计入 | 按会计准则处理并披露 |

**IPO 上市研发投入门槛（披露场景）**：
- 科创板：最近三年研发投入占营业收入比例 **≥5%**（或最近三年研发投入金额累计 ≥8000 万元），并满足研发人员占比等科创属性指标（依据《科创属性评价指引》证监会公告〔2024〕6 号，见 `policy-docs/科创属性评价指引-试行-证监会2024年修改.md`）。
- 创业板：最近两年研发投入 ≥1000 万元且占营业收入比例 ≥15%（依上市规则，以最新版为准）。
- IPO 口径通常为最宽口径（含股权激励、人员范围更广），与税务口径差异最大，上市申报须做专项披露调整。

**协同要点**：
1. 建立"多口径辅助账"统一数据源，一套归集数据支撑高企认定、加计扣除、会计、R&D 统计、IPO 披露多套口径。
2. 同一笔支出在不同口径下范围和限额可能不同，逐项对照，不得混用。典型错误有三类：
   套用高企 20% 上限算加计限额；把高企八类直接等同加计六类；把只有高企口径能归集的
   房屋折旧与长期待摊费用并入加计基数（逐科目差异见 `rd-mgmt-methodology.md` 第 4.1 节）。
3. 高企认定与加计扣除可叠加享受；企业技术中心认定（如成经信发〔2024〕4 号）与高企"组织管理水平"指标可直接对应。
4. 对外出具任何口径的报表或材料前先声明口径来源；加计与高企都是正列举，
   会计账上已计入研发费用不等于可以加计或可以高企归集（口径隔离纪律见
   `rd-mgmt-methodology.md` 第 4.1 节末"三条只有口径隔离才能看出的规则"）。

## 五、归集测算流程（Agent 执行）

1. **界定**：先按 `rd-mgmt-methodology.md` 第 2 章判定研发活动（5 条件 / 3 类型 / 4 形式 / 负面清单），项目命名避免"改造/升级/技改"等易混淆词汇。
2. **采集**：向用户逐项采集六类费用金额、委托研发合同与境外/境内分类、其他相关费用明细、收入与人员数据（一次只问一个关键项，缺什么列"待补资料清单"）。
3. **测算**：按第二、三节规则计算加计基数（委托按 80%、其他费用按限额），产出归集表与测算结论。
4. **输出**：
   - 可加计扣除研发费用归集表（六类分列）
   - 其他相关费用 10% 限额测算（基数、其他费用、限额、超限判定）
   - 研发费用辅助账（按项目、按科目；模板见 `templates/03-forms/forms.md` 表单 8，须与费用台账一致）
   - 申报表口径（A107012 加计扣除优惠明细表）
5. **佐证**：每笔费用须有发票/合同/领料单/工时记录/验收报告等佐证（模板见 `templates/03-forms/evidence-checklist.md`）；无佐证编号的费用不得计入。

## 六、测算结论的输出纪律

- 数据缺失时标「（待补）」并提示补录，不得虚构；没有真实费用数据时不得给出"未超出限额"等合规结论。
- 结论表述：如"可加计基数 ¥X / 其他相关费用 ¥Y / 10% 限额 ¥Z / ⚠ 已超出限额，超出部分不得加计（或 ✓ 未超出，可全额加计）"。
- 资料为申报草稿，最终以税务师、税务机关口径为准；政策时效性强，具体适用核验最新文件与主管税务机关口径。
