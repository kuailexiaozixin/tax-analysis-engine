## 2. 研发活动界定

### 2.1 研发活动定义

研发活动是指企业为获得科学与技术新知识，创造性运用科学技术新知识，或实质性改进技术、产品（服务）、工艺而持续进行的具有明确目标的系统性活动。

### 2.2 研发活动的五个条件

根据国家统计局《研究与试验发展（R&D）投入统计规范》，R&D活动应当满足五个条件：

1. **新颖性** — 不是常规性活动，而是追求新知识或新应用
2. **创造性** — 基于原有知识或技术进行创新性突破
3. **不确定性** — 结果不确定，存在失败可能性
4. **系统性** — 有明确目标、计划和组织形式
5. **可转移性（可复制性）** — 成果可被记录、转移或复用

### 2.3 研发活动三种类型

| 类型 | 定义 | 成果形式 |
|------|------|---------|
| **基础研究** | 不预设特定应用或使用目的的实验性或理论性工作，为获得基本原理、规律和新知识 | 论文、著作、研究报告 |
| **应用研究** | 为获取新知识，达到特定实际目的或目标而开展的初始性研究 | 论文、著作、研究报告、原理性模型、发明专利 |
| **试验发展** | 利用科学研究和实际经验中的知识，开发新产品、新工艺或改进现有产品、工艺 | 专利、专有技术、产品原型、原始样机及装置 |

### 2.4 研发活动的形式

1. **自主研发** — 依靠自身资源、技术、人力独立进行研究
2. **委托研发** — 委托外部机构或个人进行研发
3. **合作研发** — 与其他企业共同投入、共同参与、共同完成
4. **集中研发** — 集团企业统筹管理的研发项目，在受益成员单位间分摊

### 2.5 负面清单（不适用加计扣除的行业）

根据财税〔2015〕119号，以下行业不适用研发费用加计扣除政策：
- 烟草制造业
- 住宿和餐饮业
- 批发和零售业
- 房地产业
- 租赁和商务服务业
- 娱乐业
- 财政部和国家税务总局规定的其他行业

> 应用：工作流 A 立项阶段、工作流 B 加计口径判断均应先确认企业不在负面清单；项目命名须避免"改造""升级""技改"等易混淆词汇。

## 3. 研发费用预算管理

### 3.1 预算编制流程

```
科技创新部制定研发计划 → 研发项目组编制研发项目资金预算 → 研发部审核
→ 财务主管审核 → 总经理审核 → 董事会审批 → 财务部备案并提前准备研发经费
```

### 3.2 预算经费构成

**技术开发费（费用化）：**
- 人员人工费
- 材料费
- 试制设备费
- 安装调试费
- 测试化验加工费
- 燃料动力费
- 研发差旅费
- 研发会议费
- 国际合作与交流费
- 出版/文献/信息传播/知识产权事务费
- 折旧费
- 专家咨询费
- 无形资产摊销
- 管理费
- 委托外部研究开发费
- 其他费用

**资本性支出：**
- 为开发新技术、新工艺、研制新产品所购置的设备、测试仪器、软件等

### 3.3 预算管理原则

1. **专款专用** — 项目费用单独列账，按预算控制
2. **月度分解** — 将年度预算分解为月度预算
3. **预算内优先** — 超出预算的费用需按流程申请追加或变更
4. **预算误差率** — 新材料价格不明时可按市场同类产品价格预估，允许一定误差率

## 4. 研发费用归集与核算

### 4.1 三大口径对比

研发费用归集涉及三个口径，适用范围和范围存在差异：

| 费用项目 | 加计扣除口径 | 高新技术企业认定口径 | 会计口径 |
|---------|-------------|-------------------|---------|
| **人员人工费用** | 直接从事研发活动人员的工资薪金、五险一金、外聘研发人员劳务费用 | 企业科技人员的工资薪金、五险一金、外聘科技人员劳务费用 | 在职研发人员的工资、奖金、津贴、补贴、社保、公积金、外聘研发人员劳务费用 |
| **直接投入费用** | 材料、燃料、动力；中间试验和产品试制的模具/工艺装备/样品样机/检验费；仪器设备运行维护维修费及经营租赁费 | 同加计扣除，但固定资产租赁费含房屋 | 同加计扣除，含房屋租赁费 |
| **折旧费用** | 仪器、设备的折旧费（不含房屋） | 仪器、设备和在用建筑物的折旧费 | 仪器、设备、房屋的折旧费 |
| **无形资产摊销** | 软件、专利权、非专利技术的摊销费用 | 同加计扣除 | 同加计扣除 |
| **设计试验等费用** | 新产品设计费、新工艺规程制定费、新药研制的临床试验费、勘探开发技术的现场试验费 | 设计费用、装备调试费用、试验费用 | — |
| **其他相关费用** | 与研发活动直接相关的其他费用（有比例限制） | 同加计扣除（有比例限制） | 范围最广，含会议费、差旅费、办公费、培训费等 |

> **关键差异：** 会计核算范围最广；房屋折旧费和租赁费不计入加计扣除范围；高新技术企业人员人工费用归集对象是"科技人员"而非仅"直接从事研发活动人员"；其他相关费用在加计扣除和高新认定中均有比例限制（通常不超过可加计扣除研发费用总额的10%）。

### 4.2 研发支出科目设置

```
研发支出（一级科目）
├── 费用化支出（二级）
│   ├── 人员人工费用
│   ├── 直接投入费用
│   ├── 折旧与摊销费用
│   ├── 设计试验费用
│   ├── 委托外部研究开发费用
│   └── 其他费用
└── 资本化支出（二级）
    ├── 人员人工费用
    ├── 直接投入费用
    ├── 折旧与摊销费用
    ├── 设计试验费用
    ├── 委托外部研究开发费用
    └── 其他费用
```

### 4.3 费用归集流程

#### 人员人工费用归集流程

```
项目负责人编制研发人员基本信息表 → 与人力资源部门信息交互
→ 项目经理按月填报研发人员月度工时 → 项目管理部门确认
→ 人力资源部门按项目归集生成人工成本明细表
→ 财务部门完成人工费用归集
```

**分配方法：** 同时从事研发和非研发活动的人员，按实际工时占比等合理方法在研发费用和生产经营费用间分配。

#### 直接投入费用归集流程

```
研发部门登记试验研究领用材料 → 编制领用清单
→ 财务部门根据领用清单入账研发支出科目
```

#### 折旧摊销费用归集流程

```
财务部门导出当月资产清单及折旧金额
→ 生产科技部门按设备使用记录汇总研发设备工时表
→ 财务部门按研发工时占比计算应归集的折旧金额
→ 复核无误后入账研发支出科目
```

### 4.4 辅助台账管理

每个研发项目应按以下科目设置辅助台账：
1. 人员人工费
2. 直接投入费
3. 折旧费和长期摊销费
4. 无形资产摊销费
5. 设计费
6. 装备调试与试验费
7. 委托外部研究开发费用
8. 其他费用

辅助台账形式包括：自主研发、委托研发、合作研发、集中研发四种。

### 4.5 研究阶段与开发阶段的区分

| 阶段 | 会计处理 | 说明 |
|------|---------|------|
| 研究阶段 | 全部费用化（计入当期损益） | 探索性研究，成果不确定 |
| 开发阶段（满足资本化条件） | 资本化（计入无形资产） | 技术上可行、有完成意图、能产生经济利益、有足够资源、支出能可靠计量 |
| 开发阶段（不满足资本化条件） | 费用化（计入当期损益） | — |
| 无法区分研究阶段和开发阶段 | 费用化（计入当期损益） | — |

### 4.6 研发过程中试运行销售的会计处理

根据《企业会计准则解释第15号》，企业将研发过程中产出的产品或副产品对外销售的，应按照《企业会计准则第14号——收入》等规定进行会计处理。

## 5. 研发费用加计扣除

### 5.1 政策要点

**加计扣除比例（当前政策）：**
- 一般企业：实际发生研发费用的 **100%** 加计扣除（未形成无形资产），或按 **200%** 摊销（形成无形资产）——制度性安排长期实施（财政部 税务总局公告2023年第7号）
- 集成电路和工业母机企业：**120%** 加计扣除 / **220%** 摊销（执行至2027年12月31日，财政部 税务总局 国家发展改革委 工业和信息化部公告2023年第44号）
- 预缴申报三次享受：7月申报期、10月申报期、年度汇算清缴期（国家税务总局 财政部公告2023年第11号）

> **⚠️ 失效内容**：科技型中小企业此前享有的75%→100%特殊比例优势已不存在，2023年第7号公告后全行业统一100%。详细政策变化见 `book-rd-deduction-hightech/rd-deduction-benefits.md` 和 `book-rd-deduction-hightech/policy-updates-2024-2026.md`。
>
> **📚 详细内容**：加计扣除优惠内容、费用归集范围、研发形式税务处理详见 `book-rd-deduction-hightech/rd-deduction-benefits.md`（第二章）；申报流程与风险应对详见 `book-rd-deduction-hightech/rd-deduction-filing-risk.md`（第五章）。

**计算公式：**
```
减税金额 = 可加计研发费用金额 × 加计比例 × 企业所得税税率

例（高新技术企业）：减税金额 = 1000万 × 100% × 15% = 150万
例（非高新技术企业）：减税金额 = 1000万 × 100% × 25% = 250万
```

### 5.2 允许加计扣除的六项费用

1. **人员人工费用** — 直接从事研发活动人员的工资薪金、五险一金、外聘研发人员劳务费用（含股权激励支出）
2. **直接投入费用** — 材料、燃料、动力；模具/工艺装备/样品样机/检验费；仪器设备运行维护维修费及经营租赁费
3. **折旧费用** — 用于研发活动的仪器、设备的折旧费（不含房屋建筑物）
4. **无形资产摊销** — 软件、专利权、非专利技术的摊销费用
5. **设计试验费用** — 新产品设计费、新工艺规程制定费、新药研制的临床试验费、勘探开发技术的现场试验费
6. **其他相关费用** — 技术图书资料费、资料翻译费、专家咨询费、高新科技研发保险费等（总额不超过可加计扣除研发费用总额的10%）

### 5.3 委托研发加计扣除规则

| 委托类型 | 加计扣除基数 | 限制条件 |
|---------|-------------|---------|
| 委托境内机构或个人 | 实际发生额的80% | 受托方不得再进行加计扣除 |
| 委托境外机构 | 实际发生额的80% | 不超过境内符合条件的研发费用三分之二的部分可扣除 |
| 关联方委托 | 实际发生额的80% | 受托方需提供研发项目费用支出明细情况 |

### 5.4 加计扣除操作流程

```
1. 研发立项 → 确定研发项目，准备立项资料
2. 费用归集 → 按项目归集研发费用，准备留存备查资料
3. 汇算清缴 → 在汇算清缴期内申报享受优惠
4. 科技鉴定 → 配合科技部门对研发项目进行鉴定（约30%抽查率）
5. 税局核查 → 配合税务机关核查，准备留存备查资料
```

### 5.5 留存备查资料清单

1. 研发项目立项文件（立项决议、项目计划书等）
2. 研发人员名单及工时记录
3. 研发费用辅助账及汇总表
4. 研发支出凭证（领料单、工资表、设备使用记录等）
5. 研发成果证明（专利、技术标准、产品说明书等）
6. 委托研发合同及相关凭证
7. 其他相关证明材料

## 6. 高新技术企业认定

### 6.1 认定条件

依据《高新技术企业认定管理办法》（国科发火〔2016〕32号）：

> **⚠️ 2024-2026年更新**：高新技术企业认定管理工作已从科技部划归**工业和信息化部**（2024年起）。现行认定仍按2016版办法执行；修订稿尚未发布，网络流传的"2026年修订"消息不实，以官方正式文件为准。详见 `book-rd-deduction-hightech/policy-updates-2024-2026.md`。
>
> **📚 详细内容**：8项认定条件详解、研发费用归集8类范围、三口径差异比较表详见 `book-rd-deduction-hightech/hightech-certification-conditions.md`（第七章）；高企税收优惠内容详见 `book-rd-deduction-hightech/hightech-tax-benefits.md`（第六章）；认定程序与监督管理详见 `book-rd-deduction-hightech/hightech-supervision-risk.md`（第八章）。

1. **企业注册成立时间** — 申请认定时须注册成立一年以上
2. **知识产权** — 通过自主研发、受让、受赠、并购等方式，获得对其主要产品（服务）在技术上发挥核心支持作用的知识产权所有权
3. **技术领域** — 对企业主要产品（服务）发挥核心支持作用的技术属于《国家重点支持的高新技术领域》规定的范围
4. **科技人员占比** — 企业从事研发和相关技术创新活动的科技人员占企业当年职工总数的比例不低于10%
5. **研发费用占比** — 企业近三个会计年度的研究开发费用总额占同期销售收入总额的比例符合要求：
   - 最近一年销售收入 < 5,000万元 → 比例不低于5%
   - 5,000万元 ≤ 最近一年销售收入 ≤ 2亿元 → 比例不低于4%
   - 最近一年销售收入 > 2亿元 → 比例不低于3%
6. **高新收入占比** — 近一年高新技术产品（服务）收入占企业同期总收入的比例不低于60%
7. **无重大事故** — 企业申请认定前一年内未发生重大安全、重大质量事故或严重环境违法行为

### 6.2 认定流程

```
企业自我评价 → 网上注册登记 → 提交认定申请材料
→ 专家评审 → 认定机构审查认定 → 公示 → 备案、公告、颁发证书
```

### 6.3 认定中研发费用归集范围

高新技术企业认定中的研发费用归集范围包括八类：
1. 人员人工费用（科技人员）
2. 直接投入费用
3. 折旧费用与长期待摊费用
4. 无形资产摊销费用
5. 设计费用
6. 装备调试费用与试验费用
7. 委托外部研究开发费用
8. 其他费用（不超过研发费用总额的20%）

## 7. 研发投入统计（R&D统计）

### 7.1 统计范围

R&D投入统计范围为R&D活动相对密集的行业，包括：农、林、牧、渔业，采矿业，制造业，电力、热力、燃气及水生产和供应业，建筑业，信息传输、软件和信息技术服务业，科学研究和技术服务业等。

### 7.2 统计指标

- **R&D人员** — 从事R&D活动的人员数量
- **R&D经费** — 为实施R&D活动而实际发生的全部经费支出
  - 以项目归集的研发经费投入（项目直接成本）
  - 其他研发经费投入（购买新技术/新设备支出、直属研发机构日常性支出、间接服务人员经费等）

### 7.3 统计原则

1. **法人单位在地统计** — 按法人单位所在地原则统计
2. **条块结合** — 统计、科技、教育等部门按职责分工实施
3. **依托科技统计** — 在科技统计框架内进行
4. **多种调查方式结合** — 年度重点调查和全面调查为主

## 8. 常见风险与合规建议

### 8.1 常见问题

1. **研发活动界定不清** — 将技改、常规生产活动误判为研发活动
2. **项目名称不规范** — 使用"改造""升级""技改"等易混淆词汇
3. **制度与执行"两张皮"** — 有制度但缺乏配套流程表单，操作不规范
4. **费用分配不合理** — 研发与生产共用人员/设备时未按合理方法分配
5. **辅助台账不完整** — 未按项目设置辅助账或记录不完整
6. **留存备查资料缺失** — 应对税局核查时无法提供充分证据

### 8.2 合规建议

1. **建立"制度+流程图+表单"标准化文件包** — 确保制度可操作、可执行
2. **规范项目命名** — 避免使用"改造""技改"等非研发导向词汇
3. **实行工时记录制度** — 对同时从事研发和非研发活动的人员做好工时记录
4. **建立研发支出辅助台账** — 按项目、按费用类别逐月归集
5. **定期自查** — 对照加计扣除和高新认定要求定期检查归集情况
6. **跨部门协作机制** — 研发、财务、人事部门密切配合，建立常态化沟通机制
