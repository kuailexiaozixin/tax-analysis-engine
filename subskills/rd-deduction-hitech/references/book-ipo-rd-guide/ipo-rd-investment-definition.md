(二)研发投入界定  
1.具体要求  
(1)研发内部控制完善且得到执行，研发投入归集准确、披露完整  
公司应当根据相关法律法规具体规定，结合公司实际研发活动特点，制定《研发费用核算管理办法》相关制度，区分研发阶段和研究阶段的核算处理方法，明确具体研发投入的支出范围及相关依据文件。  
(2)研发投入计算口径合理，归集准确，不同口径存在差异有合理原因  
1)研发投入计算口径合理、归集准确  
根据《监管规则适用指引——发行类第9号》,研发投入为企业研发活动直接相关的支出，通常包括研发人员职工薪酬、直接投入费用、折旧费用与长期待摊费用、设计费用、装备调试费、无形资产摊销费用、委托外部研究开发费用、其他费用等。公司应按照企业会计准则相关规定，通过“研发支出”科目准确核算相关支出。  
研发投入的归集和计算应当以相关资源实际投入研发活动为前提。本期研发投入的计算口径原则上为本期费用化的研发费用与本期资本化的开发支出之和。  
2)研发投入与高新技术企业申请口径、加计扣除口径存在差异有合理原因  
高新技术企业认定办法、国家税务总局的研发费用税前加计扣除规定等法律法规对研发投入归集作出了规范，尽管相关规范仅服务于特定监管目标，但公司在日常经营管理过程中，要重点关注相关不同口径、文件下的研发投入的一致性情况，确保能够相互验证，如存在差异，一定要有合理的原因。  
2.典型问题  
(1)公司是否建立了完善的研发费用开支相关内部控制制度并且得到执行，是否明确研发费用的开支范围和标准，设立台账归集核算研发费用，研发投入归集是否准确、相关数据来源及计算是否可验证。  
(2)公司研发投入定义是否明确，计算范围是否合理，认定是否恰当，与高新技术企业认定时所申报的研发投入、所得税加计扣除时的研发投入是否存在差异，如有差异，是否有合理原因。  
3.核查重点  
(1)获取公司《研发费用核算管理办法》等相关制度，了解公司研发阶段和研究阶段的核算处理方法，研发投入的具体支出范围与统计口径情况，结合公司具体的研发活动内容、过程和阶段，复核研发投入和研发费用的会计处理是否符合企业会计准则及相关监管规定。相关研发投入的具体范围、核算依据应当包括：  
| 项目   | 内容   | 核算依据   |
| --- | --- | --- |
| 职工薪酬   | 企业在职、兼职研发人员的工资、奖金、津  <br>贴、补贴、社会保险费、住房公积金等人工  <br>费用以及外聘研发人员的劳务费用   | 考勤表、工时统计  <br>表、人员工资表、  <br>股权支付费用计入  <br>研发支出的合理依  <br>据等   |
| 物料消耗   | 研发活动直接消耗的材料、燃料和动力费用   | 材料出库单   |
| 折旧及摊销   | 用于研发活动的仪器、设备、房屋等固定资  <br>产的折旧费以及相关固定资产的运行维护、  <br>维修等费用   | 设备工时表、折旧  <br>分摊计算表   |
| 房租及物业费   | 用于研发活动的建筑物、设备的租赁费、物  <br>业费   | 租赁合同、发票、  <br>分摊计算表等   |
| 委外研发   | 通过外包、合作研发等方式，委托其他单位、  <br>个人或者与之合作进行研发而支付的费用   | 委托服务合同、发  <br>票、成果资料等   |
| 其他费用   | 包括技术图书资料费、资料翻译费、会议  <br>费、差旅费、办公费、外事费、研发人员培  <br>训费、培养费、专家咨询费、高新科技研发  <br>保险费用等   | 合同、费用报销  <br>单、发票等   |

(2)对于研发过程中形成的产品或副产品的，检查是否按照《企业会计准则第14号——收入》《企业会计准则第1号—一存货》《企业会计准则解释第15号》等规定准确归集核算有关产品或副产品的成本，并确认为存货，在对外销售时，对销售相关的收入和成本分别进行会计处理。同时，重点关注，上述研发过程中产出的产品或副产品的成本是否从研发投入中剔除。  
(3)研发投入金额、占比或构成发生显著变化的，重点关注变化原因及合理性，是否符合行业变动趋势。  
(4)取得并检查发行人每年的所得税汇算清缴报告及年度纳税申报表、《研究开发费税前加计扣除审核报告》等资料，获取并查看其报送给主管税务机关的《研发项目可加计扣除研究开发费用情况归集表》,与账面研发投入进行核对分析，核实加计扣除金额是否得到主管税务机关的认可，复核经鉴证的加计扣除项目及金额是否满足相关法律法规的规定。  
(5)查阅并逐条对照《财政部国家税务总局科技部关于完善研究开发费用税前加计扣除政策的通知》(财税〔2015〕119号)及《国家税务总局关于研发费用税前加计扣除归集范围有关问题的公告》(国税〔2017〕40号)等税收法规的规定，核实发行人研发费用可加计扣除金额和发行人申报报表研发费用金额的差异情况、差异原因及合理性。  
(6)获取报告期内发行人高新技术企业认定申报材料、所得税纳税申报表，列示报告期内研发费用及其构成情况与高新技术企业认定申报资料和所得税纳税申报表加计扣除内容之间的差异情况，并结合相关法律法规，分析说明相关差异的合理原因，对于高新技术企业来说，在高新企业认定过程中，已经将相关产品试制成本认定为研发投入，IPO财务口径的研发投入与高新技术企业申请的研发投入口径保持一致，相互验证。  
4.审核案例  

| 典型企业   | 具体问题   |
| --- | --- |
| 天合光能   | 请发行人说明研发投入的具体定义及统计口径，定量列示与研发费用  <br>的差异情况，研发投入的相关会计处理，研发投入计入非流动资产的  <br>具体情况，结合企业会计准则及同行业可比公司的会计政策，逐项说  <br>明上述事项是否符合研发费用资本化的相关条件   |
| 凝固力   | 结合研发投入定义、试生产成本具体情况、试生产成本的会计处理，  <br>说明研发投入是否准确且符合规定；报告期内试生产成本金额与研发  <br>费用变动趋势不匹配的原因   |
| 晶丰明源   | 请发行人说明研发投入的确认依据、核算方法，税务加计扣除金额和  <br>研发费用金额是否存在较大差异，相关内部控制制度是否健全有效   |
