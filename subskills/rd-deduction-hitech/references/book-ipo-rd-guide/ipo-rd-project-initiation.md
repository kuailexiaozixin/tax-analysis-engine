(四)研发立项管理  
1.具体要求  
(1)研发项目具有科技属性，符合研发活动定义，具备实施条件  
公司应当根据实际需要，结合研发计划，提出研发项目立项申请，相关研发项目相关研发方向、研究领域，研究内容和目标应该明确、具体，与公司主营业务相关，拟采取的研究技术路线和研究方法可行，并有创新和科技属性，且具备相关实施条件。同时，相关研发项目应当符合研发活动定义，具体详见  
“二、研发活动与研发投入界定”相关内容。  
(2)研发项目立项应当经过恰当审批  
研发项目应当按照规定的权限和程序进行审批，研发管理内部制度应当规定研发立项的审批层级和对应的审批人员，并且明确各审批层级的职责范围，可结合项目预算金额大小、科研意义(国家级)等情况，区分重大、重点和一般项目进行分级管理并明确对应的业务管理与审批权限。研发项目以“小组制”形式成立，或以主管研发部门发起其他相关部门签批意见形式立项，完成立项后，要进行项目立项编号，备案管理。  
(3)研发项目立项需要包含恰当、完整内容  
公司审批申请用的立项文件包括以下内容：1)研发项目立项名称；2)研发的意义与必要性；3)研发项目目标及成果；4)项目具体实施周期；5)项目负责人、项目参与人员及投入工时；6)研发预算：包括但不限于研发人员工资、材料费、折旧费、试验费、第三方费用及其他费用等；7)项目拟投入物料、固定资产清单。  
2.典型问题  
(1)研发项目是否已按公司的内部控制要求执行项目立项工作，项目立项资料是否真实合理，拟投入的人员、物资、资产是否与实际研发活动相关，是否经过恰当审批。  
(2)研发项目后续执行情况、预算支出是否与研发立项内容存在重大偏离，相关偏离是否合理，是否与研发活动相关，是否履行了相应审批和调整程序。  
(3)研发项目立项数量、预算支出内容、实施情况是否与公司研发费用变动趋势、费用结构相匹配。  
3.核查重点  
(1)获取公司研发管理相关制度文件，了解研发活动相关业务流程及内部控制活动，并测试相关研发内控制度的有效性及执行性，获取研发项目台账及相关项目研发立项文件(包括项目计划书、研发立项申请以及决议文件等),核查相关研发项目是否已按公司的内部控制要求执行项目立项工作，项目立项资料内容是否完整，对于内容的完整性，建议应当包括以下基本要素：  

| 项目   | 备注   |
| --- | --- |
| 研发目标   | 包括研发意义、国内外现状、预期研发成果、预期实现的技术指标、  <br>预期应用价值等   |
| 研发内容   | 包括技术难点或拟解决的关键技术问题、创新点、技术路线等   |
| 研发条件   | 包括研发基础、项目人员编制、经费预算、拟投入物料、固定资产清  <br>单等   |
| 项目进度安排   | 包括研发准备、技术攻关、试验测试等进度安排   |
| 成果形式与考核  <br>指标   | 论文、专利、样品等   |

对于申报市级、省级、国家级可研项目补助资金的项目，应当在完成内部  
立项后，按照相关当地科技项目管理办法要求履行立项、备案和审批手续，并同步作为立项文件进行归档。  
(2)了解报告期内各研发项目的具体实施情况及内容，包括实施进展、人员安排、材料领用、资产使用以及项目实施周期等方面，关注相关内容是否合理，拟投入的人员、物资、资产是否与实际研发活动相关，是否与立项文件中记录的内容存在重大偏离，如存在差异，要求公司提供相关预算调整、人员变更、资产领用等过程资料，复核相应审批手续的完整性。  
(3)获取并查阅报告期研发项目立项及进展、成果报告，获取公司报告期内各研发项目投入情况的相关资料；查阅并复核研发费用立项文件、费用预算、研发成果及专利；了解并核查公司研发项目数量变动、研发费用变动趋势与营业收入变动趋势的一致性，结合研发项目情况分析报告期内研发费用变动的原因。  
4.审核案例  

| 典型企业   | 具体问题   |
| --- | --- |
| 芯谷微   | 请发行人说明研发项目立项时的周期与实际进展，报告期内研发项目  <br>时间较长的原因，研发项目目前均未完成的原因，研发项目是否存在  <br>主要工作停滞的情形   |
| 思必驰   | 请发行人说明不同业务条线的业务规划和研发计划、研发项目预算金  <br>额及比例；报告期内，研发项目与核心技术间的具体关系，研发项目  <br>立项过程、研发目的、投入金额、研发进度、是否创收及预计创收情  <br>况、是否与计划存在出入，是否有订单支持   |
| 京浜光电   | 请发行人结合研发项目立项、进展、完成、成果等情况说明报告期内  <br>研发费用持续大幅上升原因   |
