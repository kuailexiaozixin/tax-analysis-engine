(一)企业研发活动界定  
根据《企业会计准则——无形资产》相关规定，研究是指为获取并理解新的科学或技术知识而进行的独创性的有计划调查。开发是指进行商业性生产或使用前，将研发成果或其他知识应用于某项计划或设计，以生产出新的或具有实质性改进的材料、装置、产品等。  
根据财政部、国家税务总局、科技部《关于完善研究开发费用税前加计扣除政策的通知》(财税〔2015〕119号)相关规定，研发活动是指企业为获得科学与技术新知识，创造性运用科学技术新知识，或实质性改进技术、产品(服务)、工艺而持续进行的具有明确目标的系统性活动。  
1.具体要求  
(1)研发活动有明确创新目标，相关研发内容及性质符合相关法律法规规定对研发活动的定义  
根据《企业会计准则——无形资产》及相关法律法规文件的规定，研发活动应当是指：企业综合考虑未来产业及技术发展方向、市场需求及公司发展战略，为保持公司技术先进性、提升公司核心竞争力而进行的，具有创新性且为提升公司产品性能、拓宽产品应用领域、提升工艺技术水平等而进行的研究和开发活动。公司研发活动应当有明确创新目标，有系统组织形式，且研发结果存在一定的不确定性，相关研发活动的具体内容、性质应当符合相关法律法规对研发活动的定义和范围。  
根据国家税务总局于2023年7月发布的《研发费用加计扣除政策执行指引》,研发活动的相关判断要点及内涵如下：  
①有明确创新目标。研发活动一般具有明确的创新目标，如获得新知识、新技术、新工艺、新材料、新产品、新标准等。可通过以下问题予以明确。例如，该活动是否要探索以前未发现的现象、结构或关系?是否在一定范围要突破现有的技术瓶颈?研发成果是否不可预期?如果回答为“是”,则说明该活动具有明确的创新目标。  
②有系统组织形式。研发活动以项目、课题等方式组织进行，围绕具体目标，有较为确定的人、财、物等支持，经过立项、实施、结题的组织过程，因此是有边界的和可度量的。  
③研发结果不确定。研发活动的结果是不能完全事先预期的，必须经过反复不断的试验、测试，具有较大的不确定性，存在失败的可能。  
(2)公司研发活动划分清晰，与生产活动等其他非研发活动严格区分  
公司在生产经营过程中，不同研发活动类型较多，既存在基于对技术发展方向、市场需求的预判市场调研进行的前瞻性研发，也存在基于具体客户需求进行的新产品定制化研发，以及基于现有技术工艺进行实质改进与革新的工艺研发，而相关研发活动的结果通常是新产品、新技术或新服务的开发和推出，因此相关研发活动往往与生产活动等其他非研发活动较为紧密，实务中往往出现较难区分的情形，因此，公司应当建立严格、清晰、有效的研发活动内部控制，要结合具体研发项目目标、具体开发过程、内容性质、证据、成本承担及成果归属情况，明确研发与生产活动的具体分界点。  
根据国家税务总局于2023年7月发布的《研发费用加计扣除政策执行指引》,研发活动与其他产业活动之间的边界说明如下，可结合公司实际业务情况，作为实务中区分研发活动和非研发活动的参考：  

| 项目   | 处理方式   | 备注   |
| --- | --- | --- |
| 原型   | 研发活动   | 原型的设计、制造和测试都属于研发活动；但为了进行批量生  <br>产而试生产的首批产品不是原型，其制造不属于研发活动   |
| 小试   | 研发活动   | 为了验证新产品、新工艺等能否正常运行的研发活动   |
| 中试   | 研发活动   | 为了验证新产品、新工艺等在大规模投产前能否正常运行的研  <br>发活动   |
| 中试工厂(中试设  <br>施)   | 区别对待   | 主要目的是研发活动，其建造与运行则属于研发活动，包括为  <br>了对假设进行评估、编写新产品方案、确定新成品规则、设计  <br>新工艺所需要的专用设备和建筑物、编制工艺操作说明书或手  <br>册等搜集数据，或者获得经验；否则，不属于研发活动   |
| 工业设计   | 区别对待   | 为研发活动开展的设计属于研发活动，如设计程序、制定技术  <br>规格、开发其他用途等；为生产进行的设计不属于研发活动   |
| 工业工程和工装准  <br>备   | 区别对待   | “反馈”研发及与创新过程中的工装准备和工程属于研发活  <br>动；为产品流程而进行的工作不属于研发活动   |

| 项目   | 处理方式   | 备注   |
| --- | --- | --- |
| 软件开发   | 区别对待   | 在不以软件为最终产品的情况下，如果软件开发是研发项目整  <br>体组成的一部分，属于研发活动；否则，需要进一步判断   |
| 试生产   | 区别对待   | 为新产品、新工艺全面测试及随后进一步的设计和工程化进行  <br>的试生产属于研发活动；否则，不属于研发活动   |
| 售后服务和故障排  <br>除   | 非研发活动   | “反馈”研发除外   |
| 专利与许可证工作   | 非研发活动   | 与研发项目直接相关的专利工作除外   |
| 常规测试   | 非研发活动   | 即使由R&D人员进行的常规测试也不属于研发活动   |

2.典型问题  
(1)公司是否建立了完善的研发活动相关内部控制制度，是否明确了研发活动的划分标准，是否符合《企业会计准则》及其他相关法规的规定。  
(2)公司研发活动类型有哪些，对于存在定制化研发、受托研发等特殊研发活动的，相应研发成果的表现形式、权利归属情况如何，是否能用于其他合同，公司是否能控制相关研发成果，相关特殊研发活动认定为研发活动的依据、原因是否合理，是否符合行业惯例。  
3.核查重点  
(1)了解、评估公司研发管理相关内部控制的设计，测试关键控制执行的有效性，通过检查相关研发活动业务流程相关资料及与公司管理层访谈，关注公司是否结合自身研发活动特点，建立了完善的研发相关内控制度并且得到执行，相关制度是否明确了研发活动、生产活动的具体划分标准、划分时点及依据，研发活动的界定是否符合《企业会计准则》及其他相关法规的规定。  
(2)访谈公司管理层及主要业务人员，从研发项目立项至最终实现产品量  
产前涉及的产品调研、设计、试制、测试等多个环节出发，了解公司各类研发活动的具体情况(包括自主研发活动、受托研发活动及定制化研发活动等),结合公司研发项目的类型、目标、性质、具体内容、风险承担以及形成或预期形成的研发成果情况，关注公司研发活动与非研发活动划分标准是否恰当。  
(3)查阅同行业公司公开披露资料，对公司相关研发活动组织形式、界定标准、管理情况是否与同行业公司相似进行了解，核查公司研发活动界定标准是否合理，是否符合行业惯例。  
4.审核案例  

| 典型企业   | 具体问题   |

| 益诺思   | 请发行人说明研发活动定义及与生产活动的划分标准，发行人对研发  <br>活动的界定是否符合《企业会计准则》及其他相关规定，是否符合行  <br>业惯例，6个国家和地方科研课题相关受托研发项目具体情况，与科  <br>研课题的相关性和直接对应关系，认定为研发活动的原因及依据，相  <br>应研发成果的表现形式、权利归属、是否能用于其他合同，发行人是  <br>否能控制相关研发成果   |
