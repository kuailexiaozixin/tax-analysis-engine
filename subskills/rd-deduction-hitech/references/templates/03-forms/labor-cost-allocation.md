# 模板 + 算法：研发人员人工费用分配明细表 & 汇总明细表

> 用法：工作流 B（证据链/三套资料）之"人员人工费用分配"。依据企业提供的工时台账与薪酬台账（含社保公积金）数据，按研发工时占比分摊人工费用，生成两张表交付。
> 数据来源：企业人员台账（研发标识）、工时台账（研发工时）、人工费用台账（工资薪酬、社保、公积金、总工时、非研发工时）。

---

## 一、分配算法

对每位研发人员、每个成本月：

```
研发工时 = 工时台账中该人员当月研发工时合计
总工时 = 人工费用台账当月总工时（作为分摊分母）
非研发工时 = 人工费用台账非研发工时
研发占比 = 研发工时 / 总工时（总工时为 0 时占比=0，须提示补录工时）

可归集研发人工 =（工资薪金 + 社保 + 公积金）× 研发占比
其中分项：
  工资薪酬归集 = 工资薪金 × 研发占比
  社保归集 = 社保 × 研发占比
  公积金归集 = 公积金 × 研发占比
```

> 口径提醒：
> - 加计扣除口径：人员人工费用含"工资薪金 + 五险一金（含个人与单位，按税法口径）"，须与个税申报、社保缴纳记录一致。
> - 高企口径：科技人员（含研发）累计实际工作时间须 ≥ 183 天；研发人员费用按项目归集。
> - 若有非研发工时记录，可用（总工时−非研发工时）作为研发工时近似，二选一并在表中注明方法。

## 四、交付要求

1. 数据取自企业提供的工时台账与薪酬台账；缺工时或缺社保公积金数据时，在表尾 `（待补）` 标注并提示补录，不得臆造数值。
2. 两表（分配明细表、分配汇总表）生成后作为交付文件产出。
3. 汇总表的"研发人工归集合计"应等于各明细行之和（勾稽校验）。
4. 仅输出"已分摊"状态的记录纳入正式归集；"待分摊"记录提示补录。
