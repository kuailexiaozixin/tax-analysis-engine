# 模板：补充表单（研发费用管理专用表单集）

> 用法：补充 `03-forms/forms.md` 中未覆盖的9个新增表单。可转为 Word/Excel/HTML 交付。字段名对应研发项目台账/费用台账口径，便于录入。

---

## 表单 9 · 研发费用报销单（专用）

> 区别于普通费用报销单，含"研发项目关联性审核"字段，是稽查中判断费用是否可加计扣除的关键凭证。

| 字段 | 说明 | 必填 |
|------|------|:----:|
| 报销人 |  | 是 |
| 所属部门 |  | 是 |
| 研发项目编号 | 关联 PLM/科数平台项目编号 | **是** |
| 研发项目名称 | 与系统内名称一致 | 是 |
| 研发阶段 | 研究阶段 / 开发阶段 | 是 |
| 费用类别 | 人员人工/直接投入/折旧摊销/设计试验/委托研发/其他 | 是 |
| 金额（不含税） |  | 是 |
| 金额（含税） |  | 是 |
| 关联性说明 | 说明该费用与研发活动的直接关联性（稽查重点） | **是** |
| 附件清单 | 发票/合同/领料单/检测报告等 | 是 |
| 项目负责人签字 | 确认费用归属项目 | 是 |
| 部门负责人审核 | 审核研发属性 | 是 |
| 财务部审核 | 审核预算+口径 | 是 |
| 总经理审批 | 超权限时 | 按权限 |

**关联性说明撰写示例：**
- 正确："用于智能传感研发项目（RD2026-001）第二阶段样机试制的温湿度传感器采购，共20件，用于样机功能测试验证"
- 错误："研发用材料"（过于笼统）
