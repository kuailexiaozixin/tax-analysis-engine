# 实操工具：研发项目流转表模板

用于研发项目从立项到结题的全过程跟踪。

## 一、模板用途

| 用途 | 说明 |
|------|------|
| 项目台账 | 记录所有研发项目的基本信息与预算执行情况 |
| 费用归集依据 | 按项目归集各项研发费用，作为辅助账的前置数据 |
| 稽查应对 | 快速提供项目全貌，应对税务稽查的项目真实性核查 |

## 二、AL-05 研发项目汇总表

### 2.1 表头

| 字段 | 内容 | 示例 |
|------|------|------|
| 制表单位 | 企业全称（公章） | {{企业名称}} |
| 年度 | 所属年度 | {{年度}} |
| 符合领域 | 高企技术领域 | {{技术领域}} |

### 2.2 列结构

| 列 | 内容 | 说明 |
|----|------|------|
| 序号 | 项目序号 | 1, 2, 3... |
| 项目编号 | 企业自定义编号 | {{企业缩写}}RD{{年份}}{{序号}} |
| 项目名称 | 项目全称 | 如：高精度自动压提技术及装置的开发 |
| 项目起止时间 | 起止年月 | 如：2024.01-2025.04 |
| 技术来源 | 自主研发/合作研发/委托研发 | 默认自主研发 |
| 主要参与项目人员姓名 | 核心研发人员 | 姓名列表 |
| 项目总预算（万元） | 项目总投资预算 | 各项目预算金额 |
| 项目年度决算（万元） | 各年度实际支出 | 按年分列，跨年项目需多列 |

| 2 | {{企业缩写}}RD{{年份}}02 | {{项目名称B}} | {{开始日期}}-{{结束日期}} | {{预算B}} | {{年度1金额}} | {{年度2金额}} |
| 合计 | | | | {{预算合计}} | {{年度1合计}} | {{年度2合计}} |

### 2.4 稽查风险警示

- 项目名称与研发活动相关性：名称含糊不清（如"技术改进"）被质疑
- 项目起止时间与费用发生时间匹配：费用发生在项目期间外，需说明
- 人员名单与工时记录对应：项目人员应在考勤和工资表中有记录
- 年度决算与辅助账数据一致：两个数据源交叉验证

## 三、AL-06 项目费用明细流转表

### 3.1 列结构

| 列 | 内容 | 说明 |
|----|------|------|
| 项目编号 | 对应项目汇总表编号 | 关联字段 |
| 项目名称 | 对应项目名称 | |
| 费用类别 | 人员人工/直接投入/折旧/其他 | 按七大类分类 |
| 费用明细 | 具体费用名称 | 如：王XX 1月工资 |
| 发生日期 | 费用发生日期 | |
| 凭证号 | 会计凭证编号 | 可追溯至总账 |
| 金额 | 发生金额 | |
| 是否可加计扣除 | 是/否 | 区分可扣除与不可扣除 |
| 备注 | 特殊说明 | 分摊依据/调整原因等 |

### 3.2 使用场景

- 月度编制：每月更新各项目费用发生明细
- 年度汇总：作为辅助账的数据来源
- 稽查配合：按项目+费用类别快速定位凭证

### 3.3 稽查风险警示

- 凭证号缺失或模糊，无法追溯至原始凭证
- 可加计扣除标识错误，将不可扣除费用计入
- 分摊费用无分配依据说明

## 四、常见项目编号格式

| 格式 | 示例 | 说明 |
|------|------|------|
| 企业缩写+RD+年份+序号 | {{企业缩写}}RD{{年份}}{{序号}} | 推荐格式，清晰标识研发项目 |
| 企业缩写+年份+序号 | {{企业缩写}}{{年份}}{{序号}} | 简化格式 |
| 纯序号 | RD{{年份}}-{{序号}} | 通用格式 |

## 五、使用说明

1. 用 `{{企业名称}}`、`{{年度}}` 等占位符填充
2. 每年的项目汇总表单独编制，跨年项目在后续年度延续记录
3. 项目费用明细流转表按月更新，与财务系统凭证号关联
4. 项目编号规则建议统一，便于多年度对比
