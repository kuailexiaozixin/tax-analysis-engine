# 流程：研发费用报销审批流程

> 用法：工作流 A 的日常报销管理规范。参照企业研发项目费用财务管理办法和研发费用归集统计实践编制。可转为流程图交付。

---

## 一、流程总览

```
[研发人员发起报销] → [部门负责人审核(研发属性)] → [财务部初审(预算+口径)]
→ [财务总监审批] → [总经理审批(超权限)] → [出纳付款] → [财务入账归集]
```

## 二、报销类型与审批权限

| 费用类型 | 预算内 ≤X万 | 预算内 >X万 | 超预算 | 审批流程 |
|---------|:----------:|:----------:|:-----:|---------|
| 材料费/试制费 | 部门负责人 | 部门负责人+财务总监 | +总经理 | 部门→财务→(总经理) |
| 委外研发费 | 部门负责人+财务总监 | +总经理 | +董事会 | 部门→财务→总经理→(董事会) |
| 差旅费/会议费 | 部门负责人 | +财务总监 | +总经理 | 部门→财务→(总经理) |
| 设备购置费 | 部门负责人+财务总监 | +总经理 | +董事会 | 部门→财务→总经理→董事会 |
| 其他费用 | 部门负责人 | +财务总监 | +总经理 | 部门→财务→(总经理) |

## 三、报销单填写规范

### 3.1 研发费用报销单（专用）字段

| 字段 | 必填 | 说明 |
|------|:---:|------|
| 报销人 | 是 |  |
| 所属部门 | 是 |  |
| 研发项目编号 | **是** | 关联 PLM/科数平台项目编号，无项目编号不得报销 |
| 研发项目名称 | 是 | 与系统内项目名称一致 |
| 研发阶段 | 是 | 研究阶段 / 开发阶段（区分费用化/资本化） |
| 费用类别 | 是 | 按加计扣除6类科目选择 |
| 金额 | 是 | 含税/不含税 |
| 关联性说明 | **是** | 说明该费用与研发活动的直接关联性（稽查重点） |
| 附件清单 | 是 | 发票/合同/领料单/检测报告等 |
| 项目负责人签字 | 是 | 确认费用归属项目 |

### 3.2 关联性说明撰写规范

关联性说明是稽查中判断费用是否可加计扣除的关键依据，须包含：
- 该费用用于哪个研发项目的哪个具体环节
- 该环节与研发目标的关系
- 如涉及材料，说明材料在研发中的具体用途（而非笼统写"研发用"）

**正确示例：**"用于智能传感研发项目（RD2026-001）第二阶段样机试制的温湿度传感器采购，共20件，用于样机功能测试验证"
**错误示例：**"研发用材料"（过于笼统，无法证明与研发活动的直接关联性）

## 四、报销审核要点

### 4.1 部门负责人审核（研发属性审核）

- [ ] 费用是否真实发生于研发活动
- [ ] 项目编号是否正确，项目是否在有效期内
- [ ] 费用类别选择是否准确
- [ ] 关联性说明是否充分、具体
- [ ] 附件是否齐全（发票/合同/领料单等）

### 4.2 财务部审核（预算+口径审核）

- [ ] 是否在预算范围内（超预算须先走预算调整流程）
- [ ] 预算科目余额是否充足
- [ ] 费用归集口径是否正确（区分费用化/资本化）
- [ ] 凭证合规性（发票真伪、合同签署、审批完整）
- [ ] 加计扣除口径合规性（是否属于可加计范围）

### 4.3 特殊情形处理

| 情形 | 处理方式 |
|------|---------|
| 超预算 | 先走预算调整审批流程，审批通过后再报销 |
| 无项目编号 | 退回补充，补充前不得入账 |
| 关联性说明不充分 | 退回补充，要求写明具体用途 |
| 跨期费用 | 须填写《跨期调整审批单》说明原因 |
| 共用设备/人员 | 须附工时/使用记录及分摊计算依据 |

## 五、研发费用与经营费用区分规则

| 费用类型 | 属于研发费用 | 属于经营费用 | 判断依据 |
|---------|:----------:|:----------:|---------|
| 研发人员薪酬 | 是 | 否 | 研发工时占比 |
| 生产人员参与研发 | 是（按工时占比） | 是（剩余部分） | 工时记录 |
| 研发材料领用 | 是 | 否 | 项目领用单 |
| 生产材料领用 | 否 | 是 | 生产领料单 |
| 研发设备折旧 | 是（按研发工时占比） | 否 | 设备使用记录 |
| 生产设备折旧 | 否 | 是 | 设备归属 |
| 研发差旅费 | 是（有项目关联） | 否 | 关联性说明 |
| 管理部门差旅费 | 否 | 是 | 部门归属 |
| 研发会议费 | 是（有项目关联） | 否 | 会议纪要+项目关联 |
| 公司年会费 | 否 | 是 | 与研发无关 |

## 六、入账与归档

**第六条** 财务部在报销完成后：
1. 按项目编号归集至 ERP 系统"研发支出"科目
2. 根据研发阶段区分费用化/资本化支出
3. 按月登记研发支出辅助账
4. 将报销单及附件与项目档案对应归档

**第七条** 归档要求：
- 报销单 + 发票 + 合同 + 领料单 + 关联性说明 + 审批记录
- 按项目编号 + 月份归档，便于后续稽查调阅

## 稽查风险警示

> **研发费用报销常见问题**
> - 研发费用与经营费用混用报销单，无法区分，被全额调减（某电子企业真实案例）
> - 关联性说明过于笼统，税务机关认定"无法证明与研发活动的直接关联性"
> - 无项目编号的报销直接入研发费用，稽查时被剔除
> - 共用设备/人员无分摊依据，全额不得加计扣除
