# 模板：研发项目验收结项管理办法

> 用法：工作流 A（治理/内控制度）的专项制度。根据企业实际裁剪后，转为 Word/PDF 交付归档。{{占位符}} 由 Agent 基于企业现状与系统数据填充。
> 与 `02-processes/rd-process.md`（节点控制表·阶段验收/结题验收）和 `03-forms/forms.md`（表单6·验收报告）衔接，构成"阶段验收→结题验收→成果确认→归档"的完整交付流程。

---

## 第一章 总则

**第一条 目的**
为规范公司研发项目的阶段验收、结题验收、成果确认与档案归档，确保研发过程可追溯、研发成果可验证、研发费用归集有依据，为加计扣除、高企认定与IPO申报提供完整的证据链，特制定本制度。

**第二条 适用范围**
适用于公司所有研发项目的验收结项管理，包括：
1. 阶段验收（里程碑节点验收）；
2. 结题验收（项目完成验收）；
3. 成果确认（技术成果、知识产权、样机样品的确认）；
4. 项目档案归档。

**第三条 归口管理**
研发部负责验收申请的组织与验收材料的准备；研发管理委员会（或技术委员会）负责验收评审与结论确认；财务部负责研发费用结算与归集确认；档案管理部门负责项目档案归档。

## 第二章 阶段验收

**第四条 阶段划分**
研发项目按研发周期划分为若干阶段（里程碑），每个阶段设定明确的交付物与验收标准。常见阶段划分：
1. 立项阶段→（立项决议、立项书、预算）；
2. 研究阶段→（可行性报告、技术方案、实验记录）；
3. 开发阶段→（样机/样品、测试报告、工艺文件）；
4. 结题阶段→（验收报告、成果证明、费用结算）。

**第五条 阶段验收流程**
每阶段完成后，项目组提交《阶段验收申请》，附本阶段交付物，经项目负责人审核、研发管理委员会评审通过后，进入下一阶段。阶段验收结论作为费用归集与资本化判断的依据。

**第六条 资本化判定节点**
开发阶段开始时，须按《企业会计准则第6号》6项条件逐条判断是否满足资本化条件（见 `03-forms/forms.md` 表单7·资本化申请审批单），留存技术可行性论证与测试报告。满足条件的，开发阶段支出资本化；不满足的，继续费用化。

## 第三章 结题验收

**第七条 结题条件**
研发项目满足以下条件之一时，可申请结题验收：
1. 已达到立项书设定的技术目标；
2. 已完成全部研发计划任务；
3. 因技术原因或市场变化经批准终止（见 `project-initiation-management.md` 第六章）。

**第八条 结题申请材料**
项目组提交《结题验收报告》（见 03-forms/forms.md 表单6），须包含：
1. 项目基本信息（编号、名称、起止时间、负责人）；
2. 技术目标完成情况（对照立项书逐项说明）；
3. 研发成果清单（专利/样机/工艺/技术报告/样品）；
4. 研发费用汇总（按项目、按科目，与辅助账一致）；
5. 研发人员参与情况（人员名单、工时汇总）；
6. 资本化/费用化处理说明；
7. 技术档案清单（实验记录、测试报告、图纸等）。

**第九条 验收评审**
研发管理委员会组织结题验收评审，评审内容包括：
1. 技术目标达成情况；
2. 研发成果的真实性与完整性；
3. 研发费用归集的准确性与合规性；
4. 证据链的完整性（见 `evidence-checklist.md`）。

**第十条 验收结论**
验收结论分为三种：
1. 通过：项目完成，准予结题；
2. 有条件通过：须补充材料或修改后重新提交；
3. 不通过：项目未完成预期目标，须继续整改或按规定终止。

## 第四章 成果确认

**第十一条 成果类型**
研发成果包括但不限于：
1. 知识产权（专利、软著、技术秘密）；
2. 样机/样品/试制品；
3. 技术报告/工艺文件/设计图纸；
4. 测试数据/实验记录/技术标准。

**第十二条 成果登记**
研发成果须在系统中登记，关联对应的研发项目，作为高企认定"科技成果转化能力"的佐证材料。

**第十三条 样机/样品处置**
结题后形成的样机/样品，按以下方式处理：
1. 入库管理，登记《样品/样机台账》；
2. 对外销售的，收入冲减研发费用（按解释第15号处理）；
3. 转入生产使用的，办理资产移交手续，从研发费用中转出。

## 第五章 研发费用结算

**第十四条 费用结算**
项目结题时，财务部对项目研发费用进行最终结算，确认：
1. 按项目归集的费用总额（与辅助账一致）；
2. 加计扣除口径的可加计金额；
3. 高企认定口径的研发费用占比；
4. 资本化/费用化金额。

**第十五条 费用差异处理**
如辅助账归集金额与研发费用台账存在差异，须编制《研发费用差异调整表》，说明原因并经审批后调整。

## 第六章 项目档案归档

**第十六条 归档内容**
项目结题后 {{30}} 日内完成归档，档案包含以下内容：
1. 立项文件（立项书、评审报告、审批文件、决议）；
2. 过程文件（合同、领料单、工时记录、测试报告、实验记录）；
3. 验收文件（阶段验收报告、结题验收报告、验收评审意见）；
4. 费用文件（辅助账、归集表、结算表、发票凭证）；
5. 成果文件（专利证书、样机照片、技术报告、测试数据）；
6. 证据链文件（见 `evidence-checklist.md`，含佐证编号）。

**第十七条 保管要求**
项目档案保管期限不少于 {{年限，如10年}}。证据链导出 PDF 存档。

## 第七章 项目后评估

**第十八条 后评估周期**
项目结题后 {{6~12个月}}，研发部组织项目后评估，评估内容包括：
1. 技术目标实现程度（与立项目标对比）；
2. 研发成果转化效果（专利实施、样机投产、工艺应用）；
3. 研发费用使用效率（预算执行率、投入产出比）；
4. 经验教训总结（供后续项目参考）。

**第十九条 评估结果应用**
后评估结果纳入研发部门绩效考核，作为改进研发管理流程的依据。

## 第八章 监督与责任

**第二十条**
研发部对验收材料的真实性负责，研发管理委员会对验收评审的客观性负责，财务部对费用结算的准确性负责。

**第二十一条**
对未经验收即结项、归集费用与验收成果不匹配等情况，须补充验收手续后方可确认研发费用。情节严重的，按公司责任追究办法处理。
