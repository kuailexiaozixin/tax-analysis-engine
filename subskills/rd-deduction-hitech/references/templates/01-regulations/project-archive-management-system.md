## 第一章 总则

**第一条** 为规范公司研发项目档案管理，确保研发活动全过程可追溯、可核查，保障研发费用加计扣除、高新技术企业认定及IPO申报的证据链完整性，依据《中华人民共和国档案法》及公司研发管理制度，制定本制度。

**第二条** 本制度适用于公司全部研发项目从立项到结题全生命周期的档案收集、整理、归档、保管、借阅和销毁管理。

**第三条** 研发项目档案管理遵循"完整、真实、规范、可追溯"原则。

## 第二章 档案分类与归档范围

**第四条** 研发项目档案按以下分类归档：

| 档案类别 | 内容 | 对应证据链类别 |
|---------|------|-------------|
| 立项类 | 项目立项申报书、立项决议、可行性研究报告、技术需求说明 | 立项类 |
| 预算类 | 研发预算表、预算批复、预算调整审批单 | — |
| 人员类 | 研发人员名单、工时记录、人员认定审批表、薪酬分配表 | 投入类 |
| 投入类 | 材料领用单、设备使用登记表、采购合同、发票、检测报告 | 投入类 |
| 合同类 | 委托/合作研发合同、技术合同登记证明、知识产权合同 | 合同类 |
| 过程类 | 试验记录、测试报告、阶段评审报告、项目变更申请单 | 过程类 |
| 资本化类 | 资本化申请审批单、技术可行性论证、测试报告、6条件逐项判定 | 资本化类 |
| 验收类 | 阶段/结题验收报告、成果证明（专利/样品/样机/技术标准） | 验收类 |
| 财务类 | 研发支出辅助账、归集汇总表、加计扣除计算表、申报表 | 全类 |
| 核查类 | 科技鉴定意见、税务核查底稿、自查报告、整改记录 | 全类 |

## 第三章 档案形成与收集

**第五条** 档案形成责任：
- 项目组负责立项类、过程类、验收类档案的原始资料形成
- 人力资源部门负责人员类档案
- 财务部门负责预算类、财务类档案
- 科技创新部负责合同类、资本化类档案
- 各责任部门须在事件发生后 {{X}} 日内完成资料归档

**第六条** 归档文件要求：
- 文件须为原件或经核对的复印件
- 电子文件须为不可修改的格式（PDF/A或扫描件）
- 签字盖章完整，日期清晰
- 研发项目名称须与系统内项目名称一致

## 第四章 档案整理与保管

**第七条** 按"一项目一档案"原则立卷，卷内文件按形成时间排序。

**第八条** 档案保管期限：
- 研发项目档案：项目结题后 **不少于10年**（与加计扣除优惠期后10年一致）
- 涉及IPO申报的研发项目档案：永久保存
- 涉及高企认定的研发项目档案：认定通过后至少保存6年

**第九条** 保管方式：
- 纸质档案：存放于专用档案柜，防火、防潮、防虫、防遗失
- 电子档案：同步备份至公司服务器或云存储，定期检查完整性

## 第五章 档案借阅与使用

**第十条** 借阅流程：
```
申请人填写借阅申请单 → 部门负责人审批 → 档案管理员登记 → 借出/查阅
```

**第十一条** 借阅权限：
- 项目组成员：可查阅本项目的全部档案
- 非项目组成员查阅：须经科技创新部负责人审批
- 外部机构（审计/税务/中介）查阅：须经公司总经理审批并登记

## 第六章 档案销毁

**第十二条** 档案销毁须满足以下条件：
- 已超过保管期限
- 经鉴定无继续保存价值
- 经公司档案管理委员会审批

**第十三条** 销毁流程：
```
档案管理员提出销毁清单 → 部门负责人审核 → 档案管理委员会审批
→ 两人以上监督销毁 → 销毁记录存档
```

## 第七章 考核与责任追究

**第十四条** 档案管理纳入部门年度考核：
- 档案缺失、归档不及时、保管不善导致证据链断裂的，追究相关部门及责任人责任
- 档案借阅未登记、超期未归还、遗失的，按公司档案管理规定处理

## 第八章 附则

**第十五条** 本制度由科技创新部负责解释和修订。

**第十六条** 本制度自公司董事会审议批准后实施。

## 稽查风险警示

> **档案管理缺失 → 稽查认定的"研发活动不真实"**
> - 多家企业因无法提供研发项目过程文档（试验记录、测试报告、阶段评审），被税务机关直接认定为"研发活动不真实"，全额调减加计扣除额
> - 某IPO企业因研发项目档案缺失，保荐机构无法完成"五流合一"核查，导致上市进程受阻
> - 档案保管不足10年，被税务机关认定不符合留存备查要求，追缴已享受优惠
