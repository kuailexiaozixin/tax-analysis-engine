# 第四章 研发费用财务处理与研发内部控制

> **覆盖范围**：研发费用财务处理、研发支出辅助账、研发内部控制
> **⚠️ 时效提示**：2021版辅助账样式仍有效，会计准则未变。但高企认定管理已变更为工信部，内控制度需关注新规方向。详见 `policy-updates-2024-2026.md`。

## 第一节 研发费用财务处理

### 一、财务上研发费用的开支范围

根据财企〔2007〕194号，企业研发费用包括：

1. 研发活动直接消耗的材料、燃料和动力费用
2. 在职研发人员的工资、奖金、津贴、补贴、社会保险费、住房公积金等人工费用及外聘研发人员劳务费用
3. 用于研发活动的仪器、设备、房屋等固定资产的折旧费或租赁费及运行维护、维修费用
4. 用于研发活动的软件、专利权、非专利技术等无形资产的摊销费用
5. 用于中间试验和产品试制的模具、工艺装备开发及制造费，设备调整及检验费，样品样机购置费等
6. 研发成果的论证、评审、验收、评估及知识产权申请费等
7. 通过外包、合作研发等方式委托其他单位/个人进行研发的费用
8. 与研发活动直接相关的其他费用（技术图书资料费、翻译费、会议费、差旅费等）

> **注意**：财企〔2007〕194号是财务处理规定，纳税扣除按财税部门规定执行。财务口径 > 税务加计扣除口径。

### 二、研发准备金与研发费用的披露

#### 研发准备金

企业可建立研发准备金制度，根据研发计划提前安排资金，确保研发资金需要。研发费用按实际发生额列入成本（费用）。

#### 研发费用披露

企业应在年度财务会计报告中披露：
- 研发费用支出规模及其占销售收入的比例
- 集中收付研发费用情况

### 三、研发支出的费用化或资本化

| 阶段 | 定义 | 会计处理 |
|------|------|----------|
| 研究阶段 | 获取新知识而进行的独创性有计划调查 | **费用化**，计入当期损益 |
| 开发阶段 | 将研究成果应用于计划或设计，生产新产品 | **资本化**（需满足6项条件） |
| 无法区分 | 无法区分研究阶段和开发阶段 | **费用化**，全部计入当期损益 |

**开发阶段资本化条件**（企业会计准则第6号——无形资产）：
1. 完成该无形资产以使其能够使用或出售在技术上具有可行性
2. 具有完成该无形资产并使用或出售的意图
3. 无形资产产生经济利益的方式
4. 有足够的技术、财务资源和其他资源支持完成开发
5. 归属于该无形资产开发阶段的支出能够可靠地计量
6. 依法申请取得无形资产

## 第二节 研发支出辅助账

### 一、研发费用加计扣除的会计核算要求

1. **遵照国家统一会计制度**
2. **按研发项目设置研发支出辅助账**
3. **研发与生产经营费用应分别核算**（划分不清的不得加计扣除）
4. **研发费用归集核算需部门间协调配合**

### 二、2021版研发支出辅助账与汇总表

#### 2015版与2021版对比

| 项目 | 2015版 | 2021版 |
|------|--------|--------|
| 辅助账样式 | 4种（自主研发/委托研发/合作研发/集中研发） | 简化为1种通用样式 |
| 汇总表 | 1张汇总表 | 优化汇总表，增加明细列 |
| 填报口径 | 分形式填报 | 统一口径，更简化 |

#### 2021版辅助账核心列

| 列序 | 内容 |
|------|------|
| 1 | 人员人工费用 |
| 2 | 直接投入费用 |
| 3 | 折旧费用 |
| 4 | 无形资产摊销 |
| 5 | 新产品设计费等 |
| 6 | 前五项小计（1+2+3+4+5） |
| 7.1 | 其他相关费用合计 |
| 7.2 | 经限额调整后的其他相关费用 |
| 8.1 | 委托境内机构/个人研发费用 |
| 8.2 | 允许加计扣除的委托境内研发费用（8.1×80%） |
| 8.3 | 委托境外机构研发费用 |
| 8.4 | 经限额调整后的委托境外研发费用 |

#### 其他相关费用限额计算示例

```
甲公司A项目五项费用合计 = 1,700,000元
甲公司B项目五项费用合计 = 950,000元
甲公司C项目五项费用合计 = 0元（委托研发项目）

限额 = (1,700,000 + 950,000 + 0) × 10% / (1-10%) = 294,444.44元

实际发生额 = 350,000元（A项目300,000 + B项目50,000）
实际 > 限额，按限额计算

A项目分摊 = 294,444.44 × 300,000/350,000 = 252,380.95元
B项目分摊 = 294,444.44 × 50,000/350,000 = 42,063.49元
```

#### 委托研发费用计算示例

```
C项目委托境内研发费用 = 700,000 × 80% = 560,000元
C项目委托境外研发费用 = 300,000 × 80% = 240,000元
委托境外 ≤ 境内符合条件研发费用的2/3，可全额加计扣除
```

### 三、研发支出辅助账核算流程

1. 立项时设置研发支出辅助账
2. 研发活动中按凭证填制辅助账
3. 年末汇总计算各项目可加计扣除额
4. 填报研发支出辅助账汇总表
5. 留存备查

## 第三节 研发内部控制

### 一、研发业务流程

立项 → 研发过程管理 → 结题验收 → 研究成果开发 → 研究成果保护 → 研发活动评估

### 二、研发活动应当关注的风险

- 研发计划与战略不匹配
- 研发人员能力不足
- 研发过程管理不善
- 研发成果转化不足
- 知识产权保护不力

### 三、研发业务的主要风险及管控措施

#### （一）立项阶段

| 风险 | 管控措施 |
|------|----------|
| 研发计划与战略不匹配 | 结合企业战略制定研发计划 |
| 项目未经科学论证 | 开展可行性研究，组织第三方评估 |
| 审批把关不严 | 按权限审批，重大项目集体审议 |

#### （二）研发过程管理

| 风险 | 管控措施 |
|------|----------|
| 研发进度滞后 | 建立跟踪管理系统 |
| 研发费用超预算 | 建立预算控制机制 |
| 研发成果不达预期 | 阶段性评估和调整 |

#### （三）结题验收

| 风险 | 管控措施 |
|------|----------|
| 验收标准不明确 | 制定明确验收标准 |
| 验收流于形式 | 组织独立专家评审 |

#### （四）研究成果开发

| 风险 | 管控措施 |
|------|----------|
| 成果转化不足 | 建立成果转化机制 |
| 成果归属不清 | 明确知识产权归属 |

#### （五）研究成果保护

| 风险 | 管控措施 |
|------|----------|
| 知识产权流失 | 建立保密制度 |
| 专利申请不及时 | 建立专利预警机制 |

#### （六）研发活动评估

| 风险 | 管控措施 |
|------|----------|
| 评估机制缺失 | 建立定期评估制度 |
| 评估指标不合理 | 设定多维评估指标 |
