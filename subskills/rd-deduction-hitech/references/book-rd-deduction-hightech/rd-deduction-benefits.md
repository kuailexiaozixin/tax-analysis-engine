# 第二章 研发费用加计扣除优惠

> **覆盖范围**：加计扣除优惠内容、费用归集范围、不同研发形式税务处理、科技型中小企业优惠
> **⚠️ 时效提示**：2023年第7号公告已将全行业加计扣除比例统一提高至100%，本章部分关于75%比例的表述已失效。详见 `policy-updates-2024-2026.md`。

---

## 第一节 研发费用加计扣除优惠内容

### 一、一般行业企业研发费用加计扣除100%

**现行政策**（财政部 税务总局公告2023年第7号）：

- 未形成无形资产计入当期损益的：在按规定据实扣除的基础上，自2023年1月1日起，再按照实际发生额的**100%**在税前加计扣除
- 形成无形资产的：自2023年1月1日起，按照无形资产成本的**200%**在税前摊销
- **作为制度性安排长期实施**

> **⚠️ 失效内容提示**：关于"制造业100%、非制造业75%"的表述已失效。2023年第7号公告将100%比例扩展至全行业（负面清单行业除外）。

### 二、集成电路和工业母机企业研发费用加计扣除120%

**现行政策**（财政部 税务总局 国家发展改革委 工业和信息化部公告2023年第44号）：

| 项目 | 费用化 | 资本化 |
|------|--------|--------|
| 加计扣除比例 | 实际发生额的**120%** | 无形资产成本的**220%** |
| 执行期限 | 2023年1月1日至2027年12月31日 | 同左 |

**适用条件——集成电路企业**：
- 集成电路设计企业：符合特定技术人员占比、研发投入占比等条件
- 集成电路制造企业：符合特定工艺节点、生产线条件
- 集成电路封装、测试企业：符合特定条件

**适用条件——工业母机企业**：
- 生产符合技术规格要求的金属切削机床、金属成形机床等产品的企业
- 实行清单管理，需提交相关材料

**资本化费用适用时点**：以**摊销时点**判断是否适用120%政策（与其他提高比例政策口径一致）。

### 三、企业投入基础研究支出加计扣除100%

**政策依据**：财政部 税务总局公告2022年第32号

| 维度 | 优惠内容 |
|------|----------|
| 出资方 | 按实际发生额在税前扣除，并可按**100%**加计扣除 |
| 接收方 | 非营利性科研机构、高等学校接收基础研究资金收入，免征企业所得税 |
| 管理要求 | 需签订协议/合同，明确资金用于基础研究领域 |

**接收方条件**：
- 国家设立的科研机构和高等学校（取得《事业单位法人证书》）
- 民办非营利性科研机构和高等学校（民政部门登记+业务范围符合）

### 四、创意设计活动相关费用加计扣除100%

创意设计活动包括：多媒体软件/动漫游戏软件开发、数字动漫/游戏设计制作、房屋建筑工程设计（绿色建筑三星）、风景园林工程专项设计、工业设计、多媒体设计、动漫及衍生产品设计、模型设计等。

### 五、研发费用加计扣除政策的适用范围

#### （一）负面清单行业（不适用加计扣除）

| 序号 | 行业 |
|------|------|
| 1 | 烟草制造业 |
| 2 | 住宿和餐饮业 |
| 3 | 批发和零售业 |
| 4 | 房地产业 |
| 5 | 租赁和商务服务业 |
| 6 | 娱乐业 |
| 7 | 财政部和国家税务总局规定的其他行业 |

**行业判定方法**：以企业实际主营业务判断（非税务登记行业），主营业务收入占收入总额50%以上判定。

#### （二）其他不适用情形
- 核定征收企业
- 非居民企业
- 不能准确归集研发费用的企业

### 六、研发费用加计扣除需关注的疑难问题

1. **加计扣除可以形成或扩大企业亏损**：加计扣除额可增加亏损
2. **符合条件未享受可追溯3年享受**：可按规定追溯享受
3. **研发费用资本化的时点税收与会计处理一致**
4. **研发失败也可享受加计扣除优惠**
5. **加计扣除与其他企业所得税优惠可叠加享受**

## 第二节 允许加计扣除研发费用的归集范围

### 一、人员人工费用

| 项目 | 内容 |
|------|------|
| 直接研发人员 | 工资薪金、五险一金 |
| 外聘研发人员 | 劳务派遣人员的劳务费 |
| 股权激励支出 | 符合条件的可加计扣除 |
| 兼职研发人员 | 按实际工时占比分摊 |
| 非研发活动人员 | 需准确划分，划分不清的不得加计扣除 |

**证监会监管要求**（IPO场景）：研发人员认定需关注工时记录、股份支付合理性等。

### 二、直接投入费用

- 研发活动直接消耗的材料、燃料和动力费用
- 用于中间试验和产品试制的模具、工艺装备开发及制造费
- 不构成固定资产的样品、样机及一般测试手段购置费
- 试制产品的检验费
- 用于研发活动的仪器、设备的运行维护、调整、检验、维修等费用
- 通过经营租赁方式租入的用于研发活动的仪器、设备租赁费

**特殊处理**：研发与生产经营混用仪器、设备的租赁费需按合理方法分摊。

### 三、折旧费用

- 用于研发活动的仪器、设备的折旧费
- 研发与生产经营混用仪器、设备折旧费需按实际工时占比分摊
- 加速折旧费用的加计扣除：按税前加速折旧金额计算

### 四、无形资产摊销

- 用于研发活动的软件、专利权、非专利技术（含许可证、专有技术、设计和计算方法）的摊销费用
- 研发与生产经营混用无形资产需合理分摊
- 加速摊销费的加计扣除按加速摊销金额计算

### 五、新产品设计费等四项费用

1. 新产品设计费
2. 新工艺规程制定费
3. 新药研制的临床试验费
4. 勘探开发技术的现场试验费

### 六、其他相关费用

**归集范围**：
1. 技术图书资料费、资料翻译费、专家咨询费、高新科技研发保险费
2. 研发成果的检索、分析、评议、论证、鉴定、评审、评估、验收费用
3. 知识产权的申请费、注册费、代理费
4. 职工福利费、补充养老保险费、补充医疗保险费
5. 差旅费、会议费

**限额计算方法**（总额法）：

```
全部研发项目的其他相关费用限额 = 全部研发项目的人员人工等五项费用之和 × 10% / (1 - 10%)
```

即：限额 = 五项费用之和 × 10/（1-10%）= 五项费用之和 × 11.11%

实际发生数大于限额的，按限额计算；小于限额的，按实际发生数计算。各项目按实际发生数占比分摊。

### 七、不允许加计扣除的费用

- 不允许税前扣除的费用和支出
- 无形资产中不属于加计扣除范围的项目摊销
- 房屋折旧费（不属于加计扣除范围，但可计入高企认定口径）

### 八、应冲减研发费用的特殊情形

1. **与研发直接相关的特殊收入**应扣减研发费用（如下脚料、残次品、中间试制品收入）
2. **研发活动直接消耗的材料**销售处理时应冲减研发费用
3. **政府补助用于研发**：按总额法或净额法区别处理

### 九、研发费用归集口径差异比较

三种口径差异：会计核算口径 > 高企认定口径 > 加计扣除口径

主要差异点：
- 人员范围：会计（研发人员）vs 高企（科技人员）vs 加计扣除（直接研发人员+外聘）
- 折旧范围：会计含房屋折旧；高企含在用建筑物折旧+长期待摊费用；加计扣除仅仪器设备
- 其他费用：会计无限额；高企限额20%；加计扣除限额10%（总额法）

## 第三节 不同研发形式的税务处理

### 一、自主研发

企业自行组织研发活动，按实际发生额100%加计扣除（集成电路/工业母机120%）。

### 二、委托研发

| 类型 | 加计扣除规则 |
|------|-------------|
| 委托境内机构/个人 | 按实际发生额的**80%**计入委托方研发费用 |
| 委托境外机构 | 按实际发生额的**80%**计入，且不超过境内符合条件研发费用的**2/3** |
| 委托境外个人 | **不得**加计扣除 |

**要点**：
- 委托方与受托方存在关联关系的，受托方应向委托方提供研发项目费用支出明细
- 受托方不得再进行加计扣除
- 委托研发合同需经科技部门登记

### 三、合作研发

- 合作各方就自身实际承担的研发费用分别计算加计扣除
- 需签订合作研发合同并经科技部门登记
- 委托研发与合作研发的区别：成果归属、风险承担、合同性质不同

### 四、集中研发

- 企业集团集中研发的项目，实际发生的研发费用按权利义务相一致、费用支出和收益分享相配比的原则分摊
- 在受益成员企业间分摊，由各成员企业分别计算加计扣除
- 需进行关联申报

## 第四节 科技型中小企业研发费用加计扣除优惠与管理

### 一、科技型中小企业研发费用加计扣除优惠政策

> **⚠️ 更新提示**：2023年第7号公告将全行业加计扣除比例提高至100%后，科技型中小企业的特殊加计扣除比例优势已不再存在。但科技型中小企业评价入库仍有其他政策意义。

### 二、科技型中小企业应符合的条件

**基本条件**（须同时满足）：
1. 在中国境内注册的居民企业
2. 职工总数不超过500人、年销售收入不超过2亿元、资产总额不超过2亿元
3. 企业所在行业不属于国家限制和禁止行业
4. 企业未列入严重违法失信名单
5. 企业综合评价得分不低于60分，且科技人员指标得分不为0分

**"直通车"条件**（满足其一即可）：
- 拥有有效期内高新技术企业资格证书
- 拥有经认定的影响力以上的科技企业孵化器、众创空间推荐的在孵企业
- 近五年内获得国家级科技奖励
- 近五年内主导制定过国际标准、国家标准或行业标准

### 三、评价工作流程

注册登记 → 自主评价 → 信息确认 → 名单公示 → 入库登记编号

### 四、监督管理

- 信息更新：每年更新年度数据
- 集中抽查：省级科技管理部门组织
- 撤销编号：弄虚作假等情形

### 五、优惠的享受与停止

- 取得登记编号的年度起享受优惠
- 被撤销登记编号的企业不得享受优惠
