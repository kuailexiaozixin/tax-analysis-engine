# 研发费用加计扣除与高企认定案例汇编

> **覆盖范围**：研发活动鉴定案例、委托研发案例、辅助账填报案例、申报表填报案例
> **⚠️ 时效提示**：案例中加计扣除比例以2023年第7号公告（全行业100%）为准，早期案例按75%计算的部分已标注。2024-2026年政策变化详见 `policy-updates-2024-2026.md`。

## 一、研发活动鉴定案例

### 案例1：微信社群粉丝经营平台（不构成研发活动）

**项目内容**：企业开发微信社群管理平台，使用Kafka消息队列、ACS云技术、Redis等成熟技术框架，实现会话监测、引入AI客服。

**专家鉴定结论**：不属于研发活动

**理由**：
1. 项目目标是现有平台的简单应用开发，缺乏创新性
2. 核心技术均为现有成熟PAAS服务和软件框架，不存在技术风险
3. 研发结果事先具有确定性，未体现不确定性

**定性**：属于财税〔2015〕119号"对某项科研成果的直接应用"情形。

## 二、委托研发案例

### 案例2：委托境外研发费用限额计算（例2-44）

K公司2023年发生委托境外研发费用100万元，当年境内符合条件的研发费用为110万元。

**计算**：
```
委托境外研发费用 = 100 × 80% = 80万元
限额 = 境内符合条件的研发费用 × 2/3 = 110 × 2/3 = 73.33万元
可加计扣除的委托境外研发费用 = min(80, 73.33) = 73.33万元
```

### 案例3：委托关联方研发（例2-45）

A公司委托B关联企业研发，支付100万元。B公司实际发生费用90万元（其中按加计扣除口径归集85万元），利润10万元。

**计算**：
```
A公司可加计扣除金额 = 100 × 80% × 100% = 80万元
B企业需向A企业提供实际发生费用90万元的明细情况
```

### 案例4：资本化项目委托境外研发费计算

**四步法**：
1. 按当年全部费用化项目和已结束资本化项目统一计算委托境外研发费用限额
2. 比较限额与实际发生数，确定可加计扣除金额
3. 可加计扣除金额 ÷ 全部项目实际发生额 = 可加计扣除比例
4. 比例 × 每个资本化项目实际发生额 = 单个项目可加计扣除额（用于以后年度摊销）

## 三、研发支出辅助账填报综合案例

### 案例5：甲公司多项目辅助账填报（第四章）

**企业情况**：
- A项目：自主研发，费用化，人员人工100万+直接投入50万+折旧10万+摊销5万+设计费5万+其他相关费用30万
- B项目：自主研发，资本化，人员人工70万+直接投入10万+折旧5万+摊销5万+设计费5万+其他相关费用5万
- C项目：委托研发，委托境内70万+委托境外30万

**其他相关费用限额计算**：
```
五项费用之和 = A(170万) + B(95万) + C(0万) = 265万
限额 = 265 × 10% / (1-10%) = 294,444.44元
实际发生 = 350,000元（A:300,000 + B:50,000）
实际 > 限额 → 按限额计算

A项目分摊 = 294,444.44 × 300,000/350,000 = 252,380.95元
B项目分摊 = 294,444.44 × 50,000/350,000 = 42,063.49元
```

**委托研发费用计算**：
```
C项目委托境内 = 700,000 × 80% = 560,000元
C项目委托境外 = 300,000 × 80% = 240,000元
境内符合条件的研发费用2/3限额检查：
  境内费用 = A费用化 + B资本化 + C委托境内×80% = 1,702,380.95 + 992,063.49 + 560,000 = 3,254,444.44元
  2/3限额 = 2,169,629.63元 > 240,000元 → 可全额加计扣除
```

**汇总结果**：
| 项目 | 支出类型 | 允许加计扣除合计 |
|------|----------|-----------------|
| A项目 | 费用化 | 1,952,380.95元 |
| B项目 | 资本化 | 992,063.49元 |
| C项目 | 费用化 | 800,000.00元 |
| **合计** | — | **3,744,444.44元** |

本年费用化金额 = 2,752,380.95元
本年资本化金额 = 992,063.49元
B项目摊销额 = 992,063.49 / 10 / 2 = 49,603.17元（假设10年摊销，本年摊销半年）
本年允许加计扣除的研发费用 = 2,752,380.95 + 49,603.17 = 2,801,984.12元
**研发费用加计扣除总额 = 2,801,984.12 × 100% = 2,801,984.12元**

## 四、A107012申报表填报案例

### 案例6：甲公司前三季度预缴申报（例5-1，第五章）

**企业情况**：制造业企业，2023年前三季度三项研发活动（A/B/C），A/B为自主研发，C为委托研发。

**各项目费用明细**：

| 费用项目 | A项目 | B项目 | C项目（委托） |
|----------|-------|-------|--------------|
| 人员人工（工资+五险一金） | 40+10=50万 | 30+5=35万 | — |
| 直接投入（材料+燃料+动力） | 15+5+5=25万 | 2.5+1.5+1=5万 | — |
| 折旧费用 | 5万 | 2.5万 | — |
| 无形资产摊销 | 2.5万 | 2.5万 | — |
| 新产品设计费/新工艺设计费 | 2.5万 | 2.5万 | — |
| 五项费用小计 | 85万 | 47.5万 | 0万 |
| 其他相关费用 | 15万 | 2.5万 | — |
| 委托境内费用 | — | — | 35万 |
| 委托境外费用 | — | — | 15万 |

**计算过程**：

1. 其他相关费用限额：
```
限额 = (85 + 47.5 + 0) × 10% / (1-10%) = 14.7222万元
实际 = 15 + 2.5 = 17.5万元 > 限额 → 按限额14.7222万元
```

2. 委托研发费用：
```
委托境内 = 35 × 80% = 28万元
委托境外 = 15 × 80% = 12万元
境内2/3限额 = (85 + 47.5 + 28) × 2/3 = 107万元 > 12万元 → 可全额加计扣除
```

3. 年度研发费用小计：
```
= 自主研发五项费用 + 经限额调整的其他相关费用 + 委托境内×80% + 委托境外×80%
= (85 + 47.5) + 14.7222 + 28 + 12
= 187.2222万元
```

4. 加计扣除总额：
```
= 187.2222 × 100% = 187.2222万元
```

## 五、研发费用归集口径差异案例

### 案例7：D公司三口径混用（例7-7，第七章）

D公司将研发费用加计扣除口径与会计核算口径、高企认定口径混淆，将办公费、通信费、研发人员培训费、培养费等归集到其他相关费用加计扣除。

**问题分析**：
- 加计扣除口径采取**正列举方式**，未列举的项目不可加计扣除
- 办公费、通信费、培训费、培养费**不属于**加计扣除"其他相关费用"范围
- 但这些费用可计入会计核算口径和高企认定口径（在限额内）

**三口径"其他相关费用"对比**：

| 口径 | 范围 | 限额 |
|------|------|------|
| 加计扣除 | 技术图书资料费、资料翻译费、专家咨询费、高新科技研发保险费、研发成果检索/分析/评议/论证/鉴定/评审/评估/验收费、知识产权申请费/注册费/代理费、职工福利费/补充养老保险费/补充医疗保险费、差旅费/会议费 | ≤可加计总额的**10%**（总额法） |
| 高企认定 | 与加计扣除范围类似，另含办公费、通信费、培训费等 | ≤研发费用总额的**20%** |
| 会计核算 | 范围最广，含所有与研发活动直接相关的费用 | **无限额** |

## 六、高企认定相关案例

### 案例8：知识产权使用限制

甲公司2021-2023年间为高新技术企业，拥有2项发明专利、4项实用新型专利、5项计算机软件著作权。2024年需重新申请认定。

**分析**：
- 2项发明专利（Ⅰ类）：可继续使用
- 4项实用新型专利（Ⅱ类）：已使用过，**不能再用于申请认定**
- 5项软件著作权（Ⅱ类）：已使用过，**不能再用于申请认定**

> **⚠️ 2025-2026年政策动向**：工信部修订认定办法预计将进一步限制Ⅱ类知识产权的使用，提高Ⅰ类专利权重。

### 案例9：境内企业接受境外委托研发（例7-4）

境内企业接受境外企业委托研发某项目，运用自身技术在研发方面发生的支出能否作为高企研发费？

**结论**：可以。现有政策规定加计扣除研发费不含受托研发支出，但高企考核指标的研发费未明确排除。为鼓励境内企业承担境外研发项目，如符合研发活动条件，相关费用可计入高企研发费考核指标。

### 案例10：自主研发项目境外咨询费（例7-3）

境内企业自行立项研发，研发过程中向境外支付咨询费。

**判定**：
- 如企业是**自主研发项目**发生的境外咨询费 → 计入"其他相关费用"，在不超过可加计扣除研发费用总额的10%内加计扣除
- 如企业是**委托研发项目**发生的境外咨询费 → 按委托境外研发规则处理（80%计入，不超过境内2/3）

依据：研发项目立项时是自主研发还是委托研发来判定。
