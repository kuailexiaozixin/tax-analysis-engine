# 第一章 研发费用加计扣除概述

> **覆盖范围**：研发费用加计扣除政策沿革、研发活动界定、研发项目管理
> **⚠️ 时效提示**：本章部分政策表述截至2023年底，2024-2026年政策变化见 `policy-updates-2024-2026.md`

---

## 第一节 研发费用加计扣除政策概述

### 一、研发费用加计扣除政策历史沿革

研发费用加计扣除政策经历了从试点到全面推开、从低比例到高比例的演变过程：

| 时间节点 | 政策文件 | 核心内容 | 效力 |
|----------|----------|----------|------|
| 2008年 | 《企业所得税法》及实施条例 | 立法确认研发费用加计扣除 | 有效 |
| 2013年 | 财税〔2013〕70号 | 试点推广到全国 | 已被后续文件替代 |
| 2015年 | 财税〔2015〕119号 | 扩大优惠范围，首次明确负面清单制度 | 有效（核心文件） |
| 2015年 | 国家税务总局公告2015年第97号 | 简化归集核算及备案管理 | 有效 |
| 2017年 | 国家税务总局公告2017年第40号 | 完善研发费用归集范围执行口径 | 有效 |
| 2018年 | 财税〔2018〕64号 | 取消委托境外研发不得加计扣除限制 | 有效 |
| 2021年 | 财政部 税务总局公告2021年第13号 | 制造业加计扣除比例提高到100% | 已被2023年第7号公告替代 |
| 2023年 | 财政部 税务总局公告2023年第7号 | **全行业**加计扣除比例提高到100%（制度性安排） | **现行有效** |
| 2023年 | 财政部 税务总局 国家发展改革委 工业和信息化部公告2023年第44号 | 集成电路和工业母机企业加计扣除比例提高到120% | **现行有效**（执行至2027年12月31日） |

### 二、立法确认研发费用加计扣除政策

《企业所得税法》第三十条第（一）项规定，企业开发新技术、新产品、新工艺发生的研究开发费用，可以在计算应纳税所得额时加计扣除。《企业所得税法实施条例》第九十五条规定，研发费用未形成无形资产计入当期损益的，在按规定据实扣除的基础上，按照研究开发费用的50%加计扣除；形成无形资产的，按照无形资产成本的150%摊销。

> **⚠️ 注意**：实施条例规定的50%/150%比例已被后续规范性文件提高至100%/200%（全行业）和120%/220%（集成电路和工业母机企业）。

### 三、扩大可加计扣除研发费用归集范围

2015年财税〔2015〕119号文件大幅扩大了可加计扣除的研发费用归集范围：
- 人员人工费用（新增外聘研发人员劳务费）
- 直接投入费用
- 折旧费用
- 无形资产摊销
- 新产品设计费、新工艺规程制定费、新药研制的临床试验费、勘探开发技术的现场试验费
- 其他相关费用（限额内）
- 委托外部研发费用（按80%计入）

### 四、提高研发费用加计扣除比例

比例演变历程：
1. **2008-2015年**：50%加计扣除（费用化）/ 150%摊销（资本化）
2. **2015-2017年**：50%加计扣除（部分特定行业75%）
3. **2017-2021年**：科技型中小企业75%；2018年起提高至75%
4. **2021-2022年**：制造业100%；其他企业75%
5. **2023年至今**：**全行业100%**（制度性安排长期实施）；集成电路和工业母机企业**120%**

## 第二节 研发费用加计扣除政策的调整和完善

### 九大调整方向

1. **放宽研发活动适用范围限制**：取消"专项用于"要求，四个领域（信息技术、生物技术、航空航天、新材料）扩展到全部科技领域
2. **进一步扩大可加计扣除研发费用归集范围**：新增外聘人员劳务费、试制产品检验费等
3. **明确创意设计活动相关费用可税前加计扣除**：多媒体软件、动漫游戏、工业设计等
4. **取消委托境外机构研发不得加计扣除限制**：2018年起委托境外研发费用按80%计入，不超过境内符合条件研发费用三分之二
5. **简化对研发费用的归集和核算管理**：从专账核算改为辅助账核算
6. **减少享受优惠的审核程序**：从审批制改为自行申报、留存备查
7. **提高研发费用加计扣除比例**：详见上节
8. **调整其他相关费用限额计算方法**：从分项目计算改为总额计算法
9. **预缴申报可以享受研发费用加计扣除优惠**：2023年起可在7月、10月预缴和汇算清缴三个时点享受

> **⚠️ 2024-2026年更新**：预缴申报享受时点政策在2023年第11号公告基础上继续执行，企业可在每年7月申报期、10月申报期和年度汇算清缴期三个时点享受。

## 第三节 研发活动的界定

### 一、科技活动与研发活动

#### （一）科技活动的概念

科学技术活动简称科技活动，是指所有与各科学技术领域（自然科学、农业科学、医药科学、工程技术、人文与社会科学）中科技知识的产生、发展、传播和应用密切相关的系统的活动。

#### （二）科技活动的分类

我国科技统计将科技活动分为三类：
1. **研究与试验发展（R&D）**：包括基础研究、应用研究、试验发展
2. **R&D成果应用**：科技成果转化
3. **科技服务**：信息文献、技术咨询、测试标准化等

#### （三）R&D活动与科技活动的关系

R&D活动是科技活动的核心组成部分，最显著特征是**创造性**，体现新知识的产生、积累和应用。其他科技活动只涉及技术的一般性应用，本身不具有创造性。

### 二、研发活动的界定与类型

#### （一）研发活动的税法概念

根据财税〔2015〕119号文件，研发活动是指企业为获得科学与技术新知识，创造性运用科学技术新知识，或实质性改进技术、产品（服务）、工艺而持续进行的具有明确目标的系统性活动。

研发活动三种类型：

| 类型 | 主要目的 | 研发活动示例 | 非研发活动示例 |
|------|----------|-------------|---------------|
| 基础研究 | 获得基本原理新知识，不预设特定应用 | 自由探索性研究、目标导向基础研究 | 艺术/人文学研究 |
| 应用研究 | 针对特定应用目的获取新知识 | 辨别基础研究成果可应用性 | 对科研成果的直接应用 |
| 试验发展 | 利用现有知识生产新材料、新产品等 | 原型样机设计制造测试 | 市场调查、质量控制、常规测试 |

#### （二）研发活动判断的基本要点

| 要点 | 内涵 |
|------|------|
| 有明确创新目标 | 探索未发现的现象、突破技术瓶颈、成果不可预期 |
| 有系统组织形式 | 以项目/课题方式组织，有确定人财物支持，经立项-实施-结题过程 |
| 研发结果不确定 | 结果不能完全事先预期，需反复试验测试，存在失败可能 |

#### （三）不适用加计扣除政策的活动（研发活动负面清单）

1. 企业产品（服务）的常规性升级
2. 对某项科研成果的直接应用
3. 企业在商品化后为顾客提供的技术支持活动
4. 对现存产品、服务、技术、材料或工艺流程进行的重复或简单改变
5. 市场调查研究、效率调查或管理研究
6. 作为工业（服务）流程环节或常规的质量控制、测试分析、维修维护
7. 社会科学、艺术或人文学方面的研究

#### （四）研发活动与其他产业活动的边界

| 项目 | 处理方式 | 备注 |
|------|----------|------|
| 原型 | 计入R&D | 设计、制造和测试均属研发；批量生产的首批产品不是原型 |
| 小试 | 计入R&D | 验证新产品/新工艺能否正常运行 |
| 中试 | 计入R&D | 验证大规模投产前能否正常运行 |
| 中试工厂 | 区别对待 | 主要目的是研发活动则属研发 |
| 软件开发 | 区别对待 | 作为研发项目整体组成部分则属研发 |
| 试生产 | 区别对待 | 为全面测试及进一步设计工程化的试生产属研发 |
| 售后服务和故障排除 | 不属于R&D | "反馈"研发除外 |
| 常规测试 | 不属于R&D | 即使由R&D人员进行 |

### 三、研发项目管理

#### （一）研发项目的组织形式

企业研发项目一般分为：自主研发、委托研发、合作研发、集中研发。

#### （二）研发项目的流程管理

研发项目流程包括：立项申请 → 可行性研究 → 评审审批 → 实施管理 → 结题验收 → 成果管理。

#### （三）研发项目异议鉴定

税企双方对研发项目产生争议时，由税务机关转请科技部门提供鉴定意见（不再由企业自行找科技部门鉴定）。

#### （四）项目鉴定常见问题

- 项目目标没有体现创新性
- 核心技术属于现有成熟技术
- 研发结果没有体现不确定性
- 属于产品常规性升级
- 属于对科研成果的直接应用
- 属于受托研发项目
- 未按要求提供经科技部门登记的委托/合作研发合同

### 四、研发费用加计扣除项目鉴定案例

**案例：微信社群粉丝经营平台**

企业开发的微信社群管理平台，使用Kafka消息队列、ACS云技术、Redis等成熟技术框架，目标是实现会话监测、引入AI客服。专家鉴定结论：**不属于研发活动**。

理由：
1. 项目目标是现有平台的简单应用开发，缺乏创新性
2. 核心技术均为现有成熟技术，不存在技术风险
3. 研发结果事先具有确定性，未体现不确定性

属于财税〔2015〕119号第一条第（二）款"对某项科研成果的直接应用"的情形。
