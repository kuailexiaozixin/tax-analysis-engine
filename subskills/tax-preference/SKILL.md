# 减免税政策代码目录（tax-preference）查询式子技能

把总局每月发布的《减免税政策代码目录》xlsx 建成**本地索引**，之后离线查询。它补的是
**优惠的封闭枚举**这一层：五个在线检索源按关键词召回单份文件，给不出"某税种/某主体
名下所有现行优惠"这个去重、带官方减免性质代码的全集。

线上：`https://www.chinatax.gov.cn/chinatax/n810346/index.html` 上的《减免税政策代码目录》
直链（依据国家税务总局公告 2015 年第 73 号，每月定期更新）。

## 什么时候用 / 不用

**用**：`entitlement`（能不能享受某优惠）、`liability`（某主体实际可享哪些优惠）
这类要"列全"的问题；或要按 8 位减免性质代码反查优惠项目与文号。

**不用**：需要条文全文、施行/废止**日期**、政策解读的，回主线五源。本目录给的是
**优惠项目名 + 减免性质代码 + 文号 + 优惠条款**，正文与日期不在目录里。

## 与三个专业口径子技能的区别（重要）

`maodocs` / `chenyiwei-bbs` / `szse-lawrules` 答的是**专业口径**（会计/审计/证券），
**不进 ⑧ 位阶×时效定级**、不能当税收主依据。本子技能不同：目录里的条目就是**税收依据
本体**，取回文号后**回 ⑧ 正常定级、可作主依据**。

## 工作流

脚本在本目录 `preference.py`，三条子命令（`sync` / `query` / `list-types`）。索引落 `preference_index.json`（随技能分发不含，
用前 `sync` 一次）。同步的版本 diff、下载守卫、内容 SHA1 复用母技能 `scripts/tax_sync.py`。

```bash
python preference.py sync            # 抓目录直链 → 比版本 → 变了才下载重建
python preference.py sync --check    # 只报有无新版本，不下载
python preference.py sync --force    # 强制重下重建
python preference.py query 研发 加计  # 离线查询（多词 AND）
python preference.py query --code 01010503
python preference.py query 小微 --type 企业所得税 --status 有效
python preference.py list-types      # 列收入种类及条数
```

输出行首 `[有效]` / `[失效]`；`[失效]` 条目附「有效期：起 ~ 止」。查询命中即给出文号，
拿文号回主线精检正文、进 ⑧ 定级。

## 数据来源与新鲜度

- `sync` 现抓栏目页定位 xlsx 直链（不硬编码版本节点），与 `data/sync/tax-preference/state.json`
  记录的 URL 比对，**变了才下载重建**——比读日期可靠。
- 建成的 `preference_index.json` 顶部记 `版本日期 / 源文件SHA1 / 构建时间 / 文号抽取失败 N/总条数`。
  `源文件SHA1` 是就地算的原始 xlsx 字节指纹，让索引脱离 `state.json` 也能自证它建自哪份字节；
  `文号抽取失败` 是每次建库的覆盖率自检，该数较上次跳增多半是目录文号列改版。`sync` 与
  `list-types` 回显都带这两项（旧索引无此字段时 `list-types` 显示 `源文件SHA1 ?`，重新 `sync` 即补全）。
- 目录是**双栏结构**：`有效` 栏只放现行有效条目、**不录任何日期**（实测 912 条有效期起/止
  全空）；日期只出现在 `失效` 栏（实测填充率 99.4%）。所以**条目的时效由它所在的栏决定**，
  不能拿"有效期止为空"当"永不过期"，也不能指望从有效条目读出到期日。
- 版本日期写在文件名/表头，`sync` 成功后记进 `state.json` 的 `version`。

## 边界（沿用母技能）

1. **不编造**——政策名、文号、代码一律取自本地索引。
2. **只认官方源**——下载与链接解析只允许 `chinatax.gov.cn` 及其子域（`scripts/tax_cited.py:is_official`）。
3. **地方政策不在库内**——目录仅收中央层级；地方优惠问主管税务机关或 12366。
4. **标注时效**——答复带目录版本日期；`[失效]` 条目仅用于补充/更正申报历史业务。
5. **不做税务筹划建议**——只答"是什么/依据哪份文件/代码多少"，具体适用以主管税务机关口径为准。
