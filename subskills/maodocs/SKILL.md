# 审计文库（MaoDocs）原文检索

把 docs.maoyanqing.com 上成体系的会计 / 审计 / 内控 / 评估 / 证券监管**规范原文**
按关键词取回逐条全文。站点是 VuePress 静态站、EdgeOne 托管，**无前置 WAF**：直连
即返回带全文的 HTML，所以这里不需要浏览器过挑战，也不需要 Jina 兜底。

线上：https://docs.maoyanqing.com （公开匿名可访，无需 token）

## 什么时候用 / 不用

**用**：某一专业口径的"原文怎么说"是答案的前提，而五个税收源都不收这类条文。
覆盖五域（分类别名的完整表见 `maodocs.py categories`）：

| 域 | 别名 | 内容 |
|---|---|---|
| 会计（企业） | `cas` / `casg` / `casi` | 企业会计准则具体准则 / 应用指南 / 解释 |
| 会计（政府） | `gas` | 政府会计准则 |
| 会计（小企业） | `cass` | 小企业会计准则（财会〔2011〕17号） |
| 审计 | `csa` / `csag` / `csaq` | 注协审计准则 / 应用指南 / 问题解答 |
| 内控 | `icn` | 企业内部控制基本规范与应用指引 |
| 评估 | `aas` | 资产评估准则与职业道德准则 |
| 证券监管 | `garr` | 监管规则适用指引（会计类/审计类/评估类/发行类…） |

**不用**：只问税率、期限、单证这类与专业确认无关的税法规则；这类条文本站也不收。

## 工作流

脚本在本目录 `maodocs.py`，三条命令，全部 stdout 出 JSON。

### 1) 在某个分类里按关键词找条目标题

索引页 HTML 已把本分类全部子条目的「全名 + .html 链接 + 文号」SSR 出来，脚本只认
**本分类前缀下**的链接（站点全局导航项会被滤掉）。

```bash
python maodocs.py search cas "长期股权投资"
python maodocs.py search csa "舞弊"
python maodocs.py search icn "组织架构"
python maodocs.py search garr "会计类"
```

返回 `results[].href`（站内相对路径）与 `url`。

### 2) 取回该条目的逐条原文

```bash
python maodocs.py fetch "https://docs.maoyanqing.com/accounting/ent/cas/02.html"
# 或直接喂 search 拿到的 href
python maodocs.py fetch "/auditing/csa/1141.html"
```

返回 `title`、`content`（发文机关 / 发布日期 / 生效日期 / 时效性 / 文号 + 正文）、
`chars`。

> **Git Bash 注意**：喂相对路径（以 `/` 开头）时要么加 `MSYS_NO_PATHCONV=1`，要么直接
> 传完整 URL，否则 shell 会把 `/accounting/...` 改写成 `D:/Git/accounting/...`。

### 3) 列全部可用分类别名

```bash
python maodocs.py categories
```

## 取到之后放哪（给母技能主线看）

条文原文**不是税收法定依据**，不进位阶表打分，也不与税法条文并列。只占两个位置：
【适用边界】里当前提（"本结论假定会计/审计/评估上按 X 处理；该口径变了结论要重算"），
或【执行口径与实务认定】栏，写"规范名＋条款号"并标明它不是税收法定依据。

## 两条硬规矩

- **标题里的文号不等于该页文本就是现行版次**。实测 `cas/02.html` 标题带
  "（财会〔2014〕14号）"，正文确是 2014 修订后措辞，但同分类里 `cas/01.html` 仍带
  "（财会〔2006〕3号）"；文号是站方录入项，不保证跟修订同步。**版次以条文措辞自证**，
  引用写"规范名＋条款号"，别拿标题文号当版本依据。
- **"时效性：现行有效"是站方标注，不接进主线时效判定**。它不是接口状态位、无修订
  链，`tax_evidence.judge_validity` 不接管这一栏；答案里不要写"经接口判定现行有效"。
