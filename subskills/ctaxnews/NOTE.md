# ctaxnews 子技能：实测台账

本文件记的是**本机当日打出来的数**，不是站点的通用属性。判据写在同目录 `SKILL.md`，
这里只放逐项读数与它们的取样口径；数字对不上时以 `probe_ctaxnews.py` 当日输出为准，改这张表。

**取证请求数**：2026-10-19 这一天分轮量过，没有逐条记账，按批次给出的量级是——
检索契约与参数值域类单项探针约 120 次、栏目表重建 3 轮（每轮 91 次探测另加父栏目页取回）、
检索行字段与摘要长度复算约 45 次、正文页与栏目页存证约 30 次、可达性分界那一批按
`pageSize=5000` 整段取回 5 次。存证落在本机临时目录，之后两轮复算（检索行 15 枚键、
地址段数分布、路径日期与行内日期一致性、栏目页行形态）只读这些副本，**不发请求、不调模型，零额度消耗**。
复测入口：`python subskills/ctaxnews/probe_ctaxnews.py`（全项约 178 次请求，`--fast` 跳过栏目表重建那项后 60 次，逐项见「探针项与请求数」）。

## 站点底座与两个落点

| 项 | 实测值（2026-10-19） | 依据 |
|---|---|---|
| 建站系统 | 方正翔宇（`founder/`、`xy/` 两套路径前缀） | 首页表单 action 写 `founder/SearchServlet.do`，结果页 JS 打 `xy/Search.do` |
| 内容页形态 | 服务端静态渲染，文章页与栏目页零条 XHR | 取样的 4 篇文章页、3 份栏目页里没有任何 `fetch`/XHR 目标；正文与元信息直接写在 HTML 注释标记内 |
| 首页搜索框 | `POST http://120.132.80.188:8088/founder/SearchServlet.do`，字段 `content`、隐藏 `siteID=2` | 首页源码里的 `<form name="formsearch">`；这一路回的是 6,068 字节 HTML 壳（空词与有词两份同尺寸），壳内加载 `bootstrap/js/Search.js` |
| 真正出数据的一路 | `GET https://www.ctaxnews.com.cn/xy/Search.do` | `Search.js` 用 `$.post` 打同一条 URL，本层按 GET 提交同一批参数，实测出同一份 JSON；POST 那一法本层没用、没测 |
| 备用落点 | `http://120.132.80.188:8088/xy/Search.do` | 与域名那一路 `foundNum` 一字不差（同一枚词「增值税」两路都报 46,871） |
| 走不通的两式 | `http://www.ctaxnews.com.cn/…` 回 HTTP 500；`https://120.132.80.188:8088` TLS 握手失败 | 各打一次；所以 `SEARCH_ENDPOINTS` 里镜像只配 `http` |
| `robots.txt` | HTTP 500（nginx 默认错误页 170 字节） | 站点没有可爬声明，约束按 `SKILL.md` 第 9 条自加 |
| 防护 | 无 WAF、无挑战页、不校验 UA（UA 缺失也回 200） | 与税屋同批取样对照：这一站同一 URL 在裸 `requests` 下直接回正文 |
| 编码 | `/xy/Search.do` 声明 `charset=UTF-8`；文章页回 `Content-Type: text/html` **不带 charset** | 不带 charset 时 requests 按 ISO-8859-1 解，正文静默变 mojibake 而 HTTP 仍 200，`_http_get` 因此强制补 utf-8 |

## Search.do 的参数值域

取样集：站内检索的 4 枚词（增值税、留抵退税、出口退税、财政部 税务总局公告2026年第29号）与
空词全站；抽取形态：逐次只改一枚参数，读回 HTTP 状态、响应字节、JSON 的 `foundNum`、
`article` 长度与首行 `articleid`；比对规则：与"只改这一枚参数前"的 `foundNum` 与首行编号比。
首行编号必须一起取——排序类参数换序时 `foundNum` 一动不动，只比总数会把"站点收了这个值"
读成"这一档没生效"。探针第 2、3 项复跑这一张表。

| 参数 | 站点认的取值 | 越界的回法 |
|---|---|---|
| `pageNo` | 只认这一枚翻页参数；`0` 与 `1` 都是第一页（站点自己的 JS 从 0 起，本层从 1 起） | `start`、`page`、`pageNum`、`p`、`offset`、`currentPage` 六枚别名一律静默忽略，提交等于反复取第一页 |
| `pageSize` | 到 5,000 都照数给行（nodeID=63 一轮回 1,393 行 = 该栏全部） | 无报错；本层默认 50，取全时不放大到 5,000 而是按页翻 |
| `sort` | `date` 按发布日期倒序；`score` 站点也收（同一词 foundNum 不变、首行换成另一枚编号：基准 1123977 → 985745） | 陌生值 `relevance` 回 HTTP 500（228 字节）；本层只提交 `date`，不接 `score` |
| `siteID` | 只有 `2`（网站）出结果 | `1`、`3` 回空结构，不报错 |
| `channel` | `1` 网站、`2` 触屏端；省略 = 两端并集 | `0`、`3` 回 37 字节空结构；**这一条最容易被读成"这一词没命中"** |
| `startDate` / `endDate` | 只认 `yyyy-mm-dd`；**单给一侧也生效**（「增值税」只给 `startDate=2025-01-01` → 2,537、只给 `endDate=2025-12-31` → 45,739、成对 2025 全年 → 1,405，基准 46,871） | 毫秒时间戳（244 字节）、`yyyy/mm/dd`（241 字节）都回 HTTP 500；起止倒挂不报错，`foundNum` 直接 0 |
| `nodeID` | 只认**叶节点**，且不按子树收 | 父节点回 0 行而它下面确实挂着文章（实测父 24 回 0、其子叶 8215 回 23）；不存在的编号同样回 0 |
| 位置参数 | `q`（全文）、`title`、`content`（正文，比 `q` 窄）、`keyword`、`author` 五枚，各只认单独提交 | `q` 与 `title` 同发时 `foundNum` 仍等于只给 `q` 的那一份——`q` 盖掉位置参数，所以"只匹配标题"必须只发 `title=` |
| `paperID` | 未测 | 站点 JS 从 cookie `xy_search_paperID` 读它，看着是报纸版面那一路；本层没接、值域没量 |

五枚位置参数的同一枚词计数。两行的口径不同，`channel` 那一路差出十几行不是噪声而是并集：

| 词 | `channel` | `q` | `title` | `content` | `keyword` | `author` |
|---|---|---|---|---|---|---|
| 增值税 | 省略（两端并集） | 46,889 | 11,911 | 未单测 | 908 | 未单测 |
| 增值税 | `1`（网站） | 46,871 | 11,909 | 46,498 | 908 | 0 |
| 出口退税 | 省略 | 9,804 | 未单测 | 9,746 | 未单测 | 未单测 |

`content` 严格小于 `q`（同一词差 173 行），站点没说明 `q` 比 `content` 多匹配了哪一段；
本层 `match=content` 走的是 `q=`，这一档差异记在这里，不当成同一件事。
`author=增值税` 回 0 行，而检索行里 `author` 有值的 20/200 行装的是成文日期串
（见下节），这一段能提交、但站点自己的数据没往里放正文词。

`q` 不分词、按整串匹配：多词之间没有 AND 语义，一个概念一枚词（与税屋那一路的判据相反，
两边不能互相套用）。

被比的库：无（这一段只看站内地址形状，不比外部库）。

## 栏目页的行形态

取样集：5 份本地存证（`/zt/node_8131.html` 合规案例、`/csll/node_31_2.html` 财税理论第 2 页、
`/sswfaj/node_23.html` 税案通报第 1 页、首页、一处触屏端页）；抽取形态：`_page_rows` 的地址形状取行、
`_own_region` 切本栏段；比对规则：三种计数并排——`class="newsList-item"` 出现次数、
地址形状匹配次数、`_page_rows` 交回的行数。探针第 8 项复跑这一张表。

| 页面 | `newsList-item` 容器 | 地址形状命中 | 去重后地址 | `_page_rows` 交回 | 翻页控件 `pages` |
|---|---|---|---|---|---|
| `/zt/node_8131.html`（专题，tab 形态） | 200 | 622 | 121 | 100 | 无 |
| `/csll/node_31_2.html`（第 2 页） | 10 | 42 | 31 | 10 | 10 |
| `/sswfaj/node_23.html`（第 1 页） | 10 | 43 | 32 | 10 | 10 |
| 首页 | 0 | 117 | 107 | 10（切不出本栏段） | 无 |
| 触屏端一处页 | 0 | 0 | 0 | 0 | 无 |

三条读数的意思：

1. **只认 `newsList-item` 会漏**：行容器至少有五种形态（`div.newsList-item`、`ul.onlyTitleList`、
   `ul.ztNews-list-main`、`a.hsqj-list`、`ul.tabList`），九个取样栏目里有四个按第一种读出 0 行；
   所以取行按地址形状，不按容器类名。
2. **地址形状数出的比行多**：8131 那一页 622 次命中、121 枚不同地址、`_page_rows` 交回 100 行，
   差值是同一篇的配图链接与标题链接同址（按地址并成一行），以及页面把十个 tab 的行都写在同一份 HTML 里。
   容器类名那一路在这个页面上数出 200，也是同一件事（每个 tab 一份列表），不能当"这页有 200 行"。
3. **`column-header-1` 那道切分不总在场**：切不出本栏标题时（tab 形态与部分专题页），
   同一目录下的兄弟栏长得一样，就再拿本栏检索集（`_column_id_set`：一次空词 `nodeID` 检索、
   `pageSize=5000` 取最新 5,000 行）交一遍。实测 nodeID=8030（增值税）那一栏：页面铺出 12 行、
   检索集里只有 4 行，多出的 8 行属同目录的兄弟栏；`_status` 把扣掉的行数写明。
   检索集取不到时整页拒绝交出，不返回一批没核对过归属的行。
4. 翻页控件把总页数写在 `<ul pages='N' current='M' class='pages'>` 的属性上，**N 最大 10**：
   税案通报一栏空词检索报 1,648 行，栏目页第 11 页（`node_23_11.html`）起 HTTP 500，
   每页 10 行——所以"按栏目取全"只能走检索，栏目页只回答最新 100 行。

## 发布日期写在地址里

取样集：「增值税」检索 200 行 + 三份栏目页存证的行；抽取形态：`url` 路径里的

## 正文页形态

取样集：4 篇文章页存证（政策 1123898/1123866 等 11 篇、新闻与解读各若干）与 2 篇专题页；
抽取形态：`<!--enpcontent-->…<!--/enpcontent-->` 与 `<!--enpproperty<字段>值</字段>-->`；
比对规则：把两对标记的每一块按字节比。

- 政策页与专题页把这两对标记**各写两遍**（桌面版与移动版），取样 11 篇政策页与 2 篇专题页里
  两块逐字节相同 → 取第一份是去重；新闻与理论页只有一块。两块的差异是否会出现没跟过第二批样本，
  探针第 6 项每次都把这块量出来，两份不一致时 `fetch_ctax` 的 `_note` 写明只取了第一份。
- 探针第 6 项换了一批行池再量 5 篇：政策栏（其他税种）2 篇、`sssw` 1 篇、`zt` 专题 1 篇
  各 2 份且逐字节相同，`csxw` 财税新闻 1 份只有一块。目录段与块数的对应关系不成立——
  `sssw` 那一页是 2 份，同目录的新闻页可能是 1 份，只能逐页量。
- `enpproperty` 里取样可见 25 枚字段，`liability`（效力标注）与 `tag`（分号分隔标签）在其中。
- 附件在页面上只有名字加链接，`Search.do` 那一行的 `urlpad` 补不上正文（恒 `"null"`）。

## 触屏端与整站规模

- 空词全站 `foundNum` 349,177，`date` 跨度 1980-06-29 至 2026-10-19；
  `pageSize=5000` 时 `pageNo=70`（1 起算）一次取到末段 4,177 行，逐段累加与总数相等。

  （另有一行 nodesearchname 为「ice测试栏目」、标题写着「文章大标题」的建站遗留测试件），

## 限流与延迟

取样集：14 次检索（含 5 次 `pageSize=5000` 的整栏取回）+ 10 篇正文，零间隔连发；
抽取形态：HTTP 码与响应字节数；比对规则：看有没有 429、挑战页或体积骤减的行。
全部 200，没有限流表现。所以 `READ_INTERVAL = 1.0` 与 `SEARCH_MIN_GAP = 1.0` 是礼节性间隔，
不是站点逼出来的下限——写进代码是为了让复跑能对上，别当"站点只给这个速度"。
单轮耗时：`--fast` 一轮 60 次请求、每次 1 秒间隔，两分钟上下；栏目表重建那一轮再加约 118 次，
其中 91 次是逐节点空词探测、26 次是父栏目页取回。
