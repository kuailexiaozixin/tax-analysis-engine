# archive/ — 历史研究快照

这里放两类东西：项目**立项阶段**（2026-09-25）的研究资料（7 份研究文档 + 1 份接口探测数据），
以及**已停用、只为历史引用而保留的脚本**（见下面「已废弃的脚本」）。研究文档记录的是当时的
调研过程与决策依据，**不是当前实现说明**。

当前实现以仓库根目录的两份文档为准，它们是唯一的事实来源：

- `SKILL.md` — Agent 操作手册（怎么调、参数是什么、失败怎么办）
- `README.md` — 项目总览（模块构成、数据源、部署方式）

## 为什么保留而不是删掉

读这些文件能看清"为什么是现在这个设计"。比如：为什么最终没有接入各省市税局官网、
为什么把技能从"知识库 + 搜索"重定成"纯实时搜索"、为什么 `SKILL.md` 要按工业级技能的
模块化标准重排。这些取舍在现行文档里只剩结论，理由在这里。

## 为什么不能留在根目录

它们写于实现之前，里面的行数、目录树、接口名都是**当时的状态**，与现在的代码已经不符。
留在根目录，Agent 和人都会误当成现行说明去读。

## 约定

- 正文**保持归档时的原貌**，不作修正。行数、目录树、接口名都可能是旧的。
- 每份文件顶部有一段"历史研究快照"说明，标明它不是现行说明。
- 新东西放哪里：
  - 给 Agent 查询时查的资料（检索策略、税种映射、风险框架）→ `references/`
  - 面向使用者的操作说明 → `SKILL.md` / `README.md`
  - 决策过程留痕 → 本目录
